# 低功耗设计精通系列（Mastery Series）

本系列是在基础篇（Ch1-8）、进阶篇（Ch9-22）、补充篇（Ch23-26）、专家篇（Ch27-32）之上，
面向**希望突破技术天花板**的工程师的最终进阶内容。

聚焦于现有体系尚未覆盖的七个关键维度：物理实现、电源完整性、验证方法论、固件编程、
可靠性冲突、团队管理、以及未来计算范式。

## 与其他系列的关系

```
基础篇 (Ch1-8)    → 掌握核心概念（功耗原理、电源域、时钟门控、DVFS）
进阶篇 (Ch9-22)   → 掌握工具流程（UPF/EDA/先进工艺/系统软件）
补充篇 (Ch23-26)  → 掌握新兴领域（Chiplet/AI加速器/射频/安全）

```

## 适合读者

- **芯片架构师**：需要系统理解功耗设计的跨层约束（Ch34, Ch37, Ch38）
- **物理实现工程师**：希望深入功耗优化而不止于时序（Ch33, Ch34）
- **验证工程师**：希望建立完整的低功耗验证体系（Ch35）
- **固件/BSP工程师**：希望真正发挥硬件低功耗潜力（Ch36）
- **技术负责人**：需要领导跨职能团队完成功耗目标（Ch38）
- **对未来技术有兴趣的任何工程师**：了解计算范式的功耗本质（Ch39）
