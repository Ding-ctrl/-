# 第25章 射频与模拟电路低功耗设计

## 25.1 引言

射频（RF）与模拟电路是无线通信、感知探测、生物医疗、工业物联网等领域不可或缺的核心模块。与纯数字电路不同，模拟/射频电路的功耗优化面临独特的挑战：**性能（噪声、线性度、速度）与功耗之间存在基本的物理折中**，无法通过简单的时钟门控或电源门控来解决。

**模拟/射频低功耗设计的核心矛盾：**

```
噪声指数 (NF) ↓  ←→ 功耗 ↑
线性度 (IIP3) ↑  ←→ 功耗 ↑
速度 (GBW) ↑     ←→ 功耗 ↑
动态范围 ↑       ←→ 功耗 ↑

Friis公式揭示的本质：
  每降低1dB噪声系数，电流近似翻倍
  每提升1dB线性度（IIP3），电流增加约2-3倍
```

本章系统介绍射频收发器、模数转换器（ADC）、数模转换器（DAC）、低噪声放大器（LNA）、混频器、压控振荡器（VCO）/锁相环（PLL）等关键模拟/射频模块的低功耗设计方法，以及数模混合SoC中的协同优化策略。

## 25.2 射频收发器架构与功耗分析

### 25.2.1 收发器架构对比

```
三种主流收发器架构的功耗特征:

1. 超外差架构 (Superheterodyne):
┌──────────────────────────────────────────────────────┐
│  天线 → BPF → LNA → 混频器 → IF滤波 → 混频器 → ADC  │
│                 ↑                    ↑               │
│               本振1(LO1)           本振2(LO2)        │
│                                                      │
│  优点：灵敏度高，选择性好，镜像抑制佳               │
│  缺点：需要片外IF滤波器，功耗和成本高               │
│  典型应用：基站、毫米波雷达                          │
│  功耗特征：双本振功耗高（PLL占比~30-40%）           │
└──────────────────────────────────────────────────────┘

2. 直接转换架构 (Zero-IF / Homodyne):
┌──────────────────────────────────────────────────────┐
│  天线 → LNA → IQ混频器 → 低通滤波 → ADC             │
│                  ↑                                   │
│                 LO (同频)                            │
│                                                      │
│  优点：无需IF滤波，完全集成，成本低功耗低           │
│  缺点：DC偏移、IQ失配、1/f噪声问题                 │
│  典型应用：WiFi、蓝牙、LTE手机                      │
│  功耗特征：单本振，片上集成，功耗最低               │
└──────────────────────────────────────────────────────┘

3. 低中频架构 (Low-IF):
┌──────────────────────────────────────────────────────┐
│  天线 → LNA → IQ混频器 → 低中频滤波 → ADC           │
│                  ↑                                   │
│              LO (偏移几MHz)                         │
│                                                      │
│  优点：避免DC偏移，兼顾集成度和性能                 │
│  缺点：需要镜像抑制处理                              │
│  典型应用：蓝牙、Zigbee等低功耗短距通信             │
└──────────────────────────────────────────────────────┘

功耗分解典型值（蜂窝手机LTE收发器, 28nm）:
  LNA:        ~5 mW
  混频器:     ~8 mW
  IQ VGA:     ~6 mW
  低通滤波器: ~4 mW
  ADC:        ~15 mW
  LO/PLL:     ~25 mW
  发射路径:   ~50-200 mW（PA主导）
```

### 25.2.2 各子模块功耗占比

```
接收链路功耗分布（典型5G Sub-6GHz, 7nm工艺）:

                    ┌─────────────────┐
  总接收功耗        │  PA关闭时 ~80mW │
                    └────────┬────────┘
                             │
     ┌───────────┬───────────┼───────────┬───────────┐
     ↓           ↓           ↓           ↓           ↓
   LNA         混频器    基带滤波       ADC         PLL
  ~10%        ~15%       ~20%          ~25%        ~30%

关键观察：
  PLL/LO生成是最大的固定功耗（与调制无关）
  ADC功耗随信号带宽和分辨率快速增长
  LNA功耗受噪声约束无法大幅降低
  发射时PA功耗压倒其他所有模块（效率30-40%时>500mW）
```

## 25.3 低噪声放大器（LNA）低功耗设计

### 25.3.1 LNA基本性能折中

```
LNA核心性能指标与功耗的关系:

Friis噪声公式（级联系统）:
  NF_total = NF1 + (NF2-1)/G1 + (NF3-1)/(G1×G2) + ...

  结论：第一级（LNA）的噪声系数和增益最关键

噪声指数 vs 偏置电流（MOSFET, 典型5GHz LNA）:
  ID = 0.5 mA → NF ≈ 4.0 dB
  ID = 1.0 mA → NF ≈ 2.5 dB
  ID = 2.0 mA → NF ≈ 1.8 dB
  ID = 4.0 mA → NF ≈ 1.5 dB  ← 收益递减明显

设计目标：在满足NF规格的最低功耗点工作
  通常 NF目标 + 0.3dB 余量，在此约束下最小化IDS

线性度（IIP3）vs 功耗:
  IIP3 ≈ -10 ~ -5 dBm（低增益模式，省电）
  IIP3 ≈ -20 ~ -15 dBm（高增益模式，噪声优先）
```

### 25.3.2 电流复用LNA设计

```
电流复用（Current Reuse）LNA — 同等性能下减半功耗:

传统共源LNA（两级）:
  ┌────────────────────────────────────────┐
  │  VDD                                  │
  │   │                                   │
  │  [M2: 第二级放大管]  ← 独立偏置电流 I2│
  │   │                                   │
  │  [M1: 第一级放大管]  ← 独立偏置电流 I1│
  │   │                                   │
  │  GND                                  │
  │  总电流: I1 + I2                      │
  └────────────────────────────────────────┘

电流复用LNA（堆叠）:
  ┌────────────────────────────────────────┐
  │  VDD                                  │
  │   │                                   │
  │  [M2: PMOS第二级]   ← 与M1共享电流   │
  │   ├── 隔直耦合 ──→ 输出              │
  │  [M1: NMOS第一级]   ← 输入信号        │
  │   │                                   │
  │  GND                                  │
  │  总电流: I（只有一份！）               │
  └────────────────────────────────────────┘

收益：
  相同增益×噪声乘积下，功耗节省~50%
  电压裕度减小（叠加两个Vgs+Vds_sat）
  适用工艺：先进CMOS（低VDD下仍有足够裕度）

代表应用：
  超低功耗蓝牙LNA（< 1mW，NF < 5dB）
  IoT 900MHz LNA（0.5mW，NF 3.5dB）
```

### 25.3.3 自适应偏置LNA

```
自适应偏置（Adaptive Biasing）LNA — 动态调整功耗:

原理：根据接收信号强度（RSSI）动态调整LNA工作点

强信号时（高RSSI）:
  → 信噪比充裕，噪声要求宽松
  → 降低LNA偏置电流（降低增益，减少过载风险）
  → 功耗降低50-70%

弱信号时（低RSSI）:
  → 噪声敏感，需要低NF
  → 增加LNA偏置电流至最高增益模式
  → 功耗最大

实现方案：
  ┌───────────────────────────────────────────┐
  │  输入信号 → 包络检波 → RSSI估计           │
  │                           │               │
  │                      ┌────▼────┐          │
  │                      │ 偏置控制│          │
  │                      └────┬────┘          │
  │                           │               │
  │  天线 → LNA（自适应增益）→ 混频器         │
  └───────────────────────────────────────────┘

典型收益（WiFi 802.11n接收器）:
  强信号（>-40dBm）：电流降低60%，功耗~3mW
  弱信号（<-80dBm）：全功率运行，功耗~8mW
  平均功耗节省（实际使用场景）：~35%
```

## 25.4 混频器低功耗设计

### 25.4.1 混频器拓扑与功耗

```
主流混频器拓扑功耗对比:

1. 无源混频器（Passive Mixer）:
┌──────────────────────────────────────────────┐
│  特点：开关管作为混频器（无直流偏置！）       │
│  RF输入 → CMOS开关（M1-M4）→ IF输出         │
│                ↑                             │
│           LO驱动                            │
│                                              │
│  优点：零直流功耗，高线性度，低噪声          │
│  缺点：转换增益<0dB（约-3dB），需要缓冲驱动  │
│  典型应用：65nm以下CMOS直接转换接收机        │
│  功耗：接近0（开关本身），但LO驱动需要功耗   │
└──────────────────────────────────────────────┘

2. 有源混频器（Gilbert Cell）:
┌──────────────────────────────────────────────┐
│  VDD                                         │
│   ├── [负载] ── [负载]                       │
│   │                │                         │
│  [M3][M4][M5][M6]  ← LO差分开关对           │
│   │                │                         │
│  [M1]            [M2]  ← RF跨导对            │
│   │                │                         │
│  ISS（尾电流）                               │
│                                              │
│  优点：转换增益>0dB（约10-15dB），隔离性好   │
│  缺点：直流电流消耗（典型1-5mA@1.2V）        │
│  典型应用：超外差中频混频，需要增益的场景    │
└──────────────────────────────────────────────┘

3. 跨导注入无源混频器（Current-Mode Passive Mixer）:
  结合无源混频器的线性度和有源驱动的增益
  功耗比Gilbert Cell低~50%，线性度类似无源混频器
  是现代低功耗直接转换接收机主流方案
```

### 25.4.2 谐波混频器节省LO功耗

```
谐波混频（Subharmonic Mixer）— 降低LO频率要求:

标准混频：LO频率 = RF频率（如5GHz LO混5GHz RF）
谐波混频：LO频率 = RF频率/N（N=2时，LO只需2.5GHz）

2次谐波混频器原理（双平衡拓扑）:
  ┌──────────────────────────────────────┐
  │  LO以ω_LO/2驱动（频率减半）          │
  │  电路利用MOS管的偶次谐波非线性产生   │
  │  有效的2ω_LO混频                    │
  │                                      │
  │  优点：LO频率降一半                  │
  │  PLL生成低频LO：功耗降低~40%         │
  │  LO分配线缆损耗减少：降低驱动功耗   │
  │  缺点：转换增益约低3-5dB             │
  └──────────────────────────────────────┘

典型收益（60GHz毫米波收发器）:
  标准混频：LO需要60GHz PLL，功耗~100mW
  2次谐波：LO只需30GHz PLL，功耗~60mW（节省40%）
  代价：多消耗约3dB噪声指数
```

## 25.5 振荡器与锁相环（PLL）低功耗设计

### 25.5.1 VCO功耗与相位噪声折中

```
VCO相位噪声（Phase Noise）与功耗的基本关系:

Leeson公式:
  L(Δf) = 10·log[ (2FkT/P_diss) × (f₀/2QΔf)² × (1 + Δf_1/f / |Δf|) ]

  其中：
    P_diss = VCO消耗功率
    Q      = LC谐振回路品质因数
    f₀     = 振荡频率
    Δf     = 偏移频率

  关键结论：相位噪声与P_diss成反比
  功耗增加4× → 相位噪声改善6dB

相位噪声 vs 功耗设计点选择:
  过设计（超低相位噪声）：功耗远超规格要求
  欠设计（相位噪声不达标）：系统误码率超标
  最优设计：在规格边界运行，最小化功耗

LC-VCO功耗优化策略:
  1. 高Q值电感：晶圆顶层金属，厚铜工艺
     Q从5提升到10 → 功耗可降低4×（同等相位噪声）
  2. 互补NMOS+PMOS交叉对：能效约提升2-3×
  3. 变压器耦合双核VCO：每核功耗减半，相位噪声不变
  4. 电流复用技术：VCO与分频器共享偏置电流
```

### 25.5.2 小数分频PLL功耗优化

```
PLL各子模块功耗分析（典型5GHz CMOS PLL, 28nm）:

VCO:           ~5-10 mW  （主导，高Q电感可降低）
分频器链:      ~3-8 mW   （高速分频功耗大）
鉴频鉴相器:    ~0.5 mW   （数字电路，功耗小）
电荷泵+滤波器: ~0.5 mW
总计:          ~10-20 mW

低功耗PLL优化方向:

1. 注入锁定（Injection Locking）替代分频:
   ┌─────────────────────────────────────────┐
   │  传统：VCO(5GHz) → ÷2 → ÷2 → 312MHz参考│
   │  注入锁定：用参考信号直接锁定VCO        │
   │  去掉分频链功耗，节省~40%              │
   │  缺点：锁定范围窄（~5-10%）            │
   └─────────────────────────────────────────┘

2. 超低功耗数字PLL（ADPLL）:
   ┌─────────────────────────────────────────┐
   │  模拟环路滤波器 → 数字环路滤波器（DCO） │
   │  优点：可缩放（与CMOS工艺同步缩小）    │
   │  避免大模拟电容（节省面积）             │
   │  可实现Deep Sleep快速唤醒（< 10μs）    │
   │  典型功耗：<1mW（BLE应用）             │
   └─────────────────────────────────────────┘

3. 时间交织分频（Time-Interleaved Divider）:
   高速分频器改为多相位慢速时钟控制
   功耗降低~30-50%（慢速逻辑能效更高）
```

### 25.5.3 蓝牙/WiFi协议的PLL快速唤醒

```
低功耗无线协议的PLL功耗优化策略:

BLE（蓝牙低功耗）典型时序:
  ┌──────────────────────────────────────────────────┐
  │ 睡眠(uW级) │ PLL唤醒 │ 发/收 │ 睡眠 │ ...       │
  │           │ ~0.5ms  │~1-5ms │      │           │
  └──────────────────────────────────────────────────┘

  占空比：~0.1-1%（大部分时间睡眠）
  PLL快速锁定时间 < 500μs是关键指标

实现快速锁定的技术:
  1. 宽带锁定：初始用宽环路带宽快速锁定，
     锁定后切换窄带宽降低相位噪声
  2. 频率预设：存储上次工作频率字，减少搜索范围
  3. 数字校准：离线校准VCO增益和分频比，
     消除开环估计误差
  4. 注入锁定ADPLL：< 100μs锁定时间

功耗核算（BLE广播包，1%占空比）:
  PLL唤醒功耗：5mW × 0.5ms = 2.5 μJ/次
  发射功耗：   10mW × 1ms  = 10 μJ/次
  睡眠功耗：   10μW × 100ms = 1 μJ
  总能量/周期：13.5 μJ → 平均功耗 ~135 μW
```

## 25.6 模数转换器（ADC）低功耗设计

### 25.6.1 ADC功耗与性能基本关系

```
ADC能效指标—Walden品质因数（FoM）:

FoM = P / (2^ENOB × fs)  （单位：J/conversion-step）

  P     = 功耗（W）
  ENOB  = 有效位数（Effective Number Of Bits）
  fs    = 采样率（S/s）

典型ADC能效演进（历年ISSCC最佳ADC）:
  2005年：FoM ≈ 1 pJ/step
  2010年：FoM ≈ 50 fJ/step
  2015年：FoM ≈ 5 fJ/step
  2020年：FoM ≈ 0.5 fJ/step  ← 接近热力学极限

热力学极限（理论最小能耗）:
  每个采样量化的最小能量 ≈ kT × 4（约16 aJ @ 300K）
  现代ADC距理论极限还有约30-100×的差距

不同架构的适用场景（速度vs精度）:
  架构           │ 精度（bit） │ 速度        │ FoM
  ───────────────┼────────────┼────────────┼──────────
  Flash          │ 4-8         │ 极高(GS/s) │ 高（简单）
  SAR            │ 8-16        │ 中（MS/s） │ 最低（能效最佳）
  Pipeline       │ 10-16       │ 高（100MS/s）│ 中
  Sigma-Delta    │ 16-24       │ 低（kS/s）  │ 中（噪声整形）
  VCO-based      │ 10-14       │ 中          │ 低（新兴）
```

### 25.6.2 SAR ADC超低功耗设计

```
SAR ADC（逐次逼近型）— 能效最佳ADC架构:

基本工作原理:
  采样 → 比较 → DAC调整 → 再比较 → ... → 输出

  N位ADC需要N次比较，每次比较对应一个二进制决策
  所有操作均为开关电容操作，接近纯数字功耗特征

能量分析（典型12位、1MS/s SAR ADC）:
  电容DAC充放电:    ~10 fJ/次 × 12 = 120 fJ
  比较器功耗:       ~50 fJ/次 × 12 = 600 fJ
  数字逻辑:         ~100 fJ
  采样开关:         ~50 fJ
  总计:             ~870 fJ/step

超低功耗设计技巧:

1. 分裂电容阵列（Split-Capacitor DAC）:
   传统：2^N电容（12位需4096个单位电容）
   分裂：减少总电容量~50%，能耗减少~50%

2. 单调充电开关（Monotonic Switching）:
   传统DAC开关需要充放电（能量损耗大）
   单调开关：只充不放，减少能耗~81%（vs传统）

3. 动态比较器（Dynamic Comparator / StrongARM Latch）:
   无静态电流，仅在比较时消耗能量
   功耗正比于采样率（fs降低时功耗自动降低）

4. 异步SAR（Asynchronous SAR）:
   每次比较完成后自动触发下一次（无时钟等待）
   消除时钟功耗，提升速度，降低功耗~30%

5. 噪声形状SAR（Noise-Shaping SAR）:
   结合SAR的低功耗和Sigma-Delta的高精度
   通过残差积分实现高阶噪声整形
   在相同精度下功耗比传统Sigma-Delta低~3-5×
```

### 25.6.3 Sigma-Delta ADC高精度低功耗

```
Sigma-Delta ADC — 高精度传感器的首选:

工作原理（一阶Sigma-Delta调制器）:
                    ┌─────┐
  Vin ─→ (+) ─→ 积分器 ─→ 比较器 ─→ 数字输出
          ↑                          │
          └──────── DAC ─────────────┘（负反馈）

噪声整形原理：量化噪声被推向高频，低频信噪比提高
过采样比（OSR）越高 → 精度越高 → 功耗越高

功耗与精度的权衡（1阶调制器）:
  OSR=16  → ENOB ≈ 9位  → 低功耗
  OSR=64  → ENOB ≈ 13位 → 中等功耗
  OSR=256 → ENOB ≈ 17位 → 高功耗

低功耗连续时间Sigma-Delta（CT-Σ△）优势:
  离散时间（DT-Σ△）：需要高速运放，对电容采样
  连续时间（CT-Σ△）：RC积分器，无需高速充电
  CT-Σ△ 功耗比 DT-Σ△ 低约5-10×（相同精度）

超低功耗应用实例（可穿戴心电信号采集）:
  精度要求：16-18位
  带宽：     1kHz
  采用CT-Σ△ ADC：功耗 < 10μW
  同等精度流水线ADC：>500μW
  节省能耗：50×以上
```

## 25.7 数模转换器（DAC）低功耗设计

### 25.7.1 DAC架构选择

```
主流DAC架构功耗特征:

1. 电阻串（R-String）DAC:
   ┌─────────────────────────────────────────┐
   │  2^N个电阻串联从VDD到GND               │
   │  开关选择对应节点输出                   │
   │  优点：单调性保证，低功耗（几十μW）    │
   │  缺点：面积随位数指数增长               │
   │  适用：<10位，低速（音频DAC等）        │
   └─────────────────────────────────────────┘

2. 电流舵（Current Steering）DAC:
   ┌─────────────────────────────────────────┐
   │  2^N或NR个电流源，开关切换输出          │
   │  优点：高速（GS/s量级），高精度         │
   │  缺点：持续直流功耗（所有电流源常开）   │
   │  典型：10-16位，100MS/s-GS/s            │
   │  功耗主要来源：参考电流×2^N（固定）    │
   └─────────────────────────────────────────┘

3. 电容阵列（Capacitor Array）DAC:
   ┌─────────────────────────────────────────┐
   │  与SAR ADC中的DAC相同原理               │
   │  纯开关电容，无静态功耗                 │
   │  优点：超低功耗（与速度成正比）         │
   │  缺点：高速时驱动大电容功耗增加        │
   │  适用：低速高精度，如DAC for sensor     │
   └─────────────────────────────────────────┘

电流舵DAC低功耗设计关键点:
  动态偏置（Dynamic Biasing）：
    静态模式：关断大部分电流源，仅保留必要精度
    发射模式：开启全部电流源，提升线性度（SFDR）
  分段架构（Segmented DAC）：
    高位用Unary（1-of-N），低位用Binary
    减少毛刺（Glitch），间接降低数字滤波要求
```

### 25.7.2 发射机DAC功耗优化

```
5G NR发射机DAC的功耗优化（典型100MHz带宽）:

DAC分辨率与功耗权衡:
  12位DAC：满足EVM要求，功耗~50mW
  14位DAC：SFDR更好但功耗~200mW（4×）
  最优选择：12位+数字预失真（DPD）补偿非线性

Nyquist DAC vs 过采样DAC:
  Nyquist DAC（ fs = 2×BW）:
    低采样率 → 低时钟功耗
    需要锐截止模拟滤波器（高功耗）
  过采样DAC（fs = 8-16×BW）:
    高时钟功耗（DAC内核）
    模拟滤波器阶数大幅降低（宽松，低功耗）
    综合功耗：过采样通常更优（数字比模拟能效高）

实际设计：数字+模拟协同优化
  数字端：CORDIC、插值滤波（工艺缩放，功耗低）
  模拟端：DAC + 简单RC低通（省去高阶滤波器）
```

## 25.8 功率放大器（PA）低功耗设计

### 25.8.1 PA效率基本理论

```
PA效率与线性度的根本矛盾:

理论最大效率（不同工作类别）:
  A类放大器  : η_max = 50%   （线性度最好）
  AB类放大器 : η_max = 50-78%（通信系统主流）
  B类放大器  : η_max = 78.5%
  C类放大器  : η_max > 78.5%（非线性，需滤波）
  D/E/F类    : η_max → 100%  （开关模式，强非线性）

现实中的效率（OFDM调制，高PAPR信号）:
  A类PA：平均效率 ~5-15%
  AB类PA：平均效率 ~15-30%
  E类PA（with DPD）：平均效率 ~40-60%

PAPR（峰均功率比）是效率杀手:
  LTE OFDM：PAPR ≈ 8-10 dB
  为防止峰值削波，PA工作在回退（Back-off）状态
  回退越多，效率越低（每3dB回退，效率约减半）
```

### 25.8.2 包络跟踪（ET）技术

```
包络跟踪（Envelope Tracking, ET）— 大幅提升PA平均效率:

传统PA（固定VDD）:
  VDD = 固定值（对应峰值功率所需）
  低功率信号时：VDD远超需要 → 大量能量浪费

ET PA（动态VDD）:
  VDD跟随信号包络动态变化
  低功率信号时：VDD降低 → 漏极效率提升

  VDD(t) = f(|envelope(t)|)  ← 实时跟踪

效率对比（LTE, 1W平均输出）:
  固定VDD PA：η_avg ≈ 20-25%
  ET PA：      η_avg ≈ 40-50%  ← 几乎翻倍

ET系统的功耗挑战:
  包络调制器（Envelope Modulator）自身功耗
    高效包络调制器：η_modulator ≈ 85-90%
    低效时会抵消ET收益
  ET调制器带宽需求：5-10× 信号带宽
  ET系统整体：η_system = η_PA × η_modulator

应用：
  智能手机：5G Sub-6GHz PA（ET成标配）
  基站RRU：Massive MIMO PA阵列（ET+数字预失真）
```

### 25.8.3 数字预失真（DPD）降低功耗

```
数字预失真（DPD）— 允许PA更高效工作:

PA非线性导致的问题:
  PA工作在近饱和区（高效）→ 产生非线性失真
  非线性 → 带内失真（EVM恶化）+ 带外杂散
  为避免失真，传统上需要大回退 → 效率低

DPD原理:
  预先对数字基带信号进行"反向非线性"处理
  经过PA的非线性后，恰好抵消 → 输出线性
  PA可以工作在更高功率点（更小回退） → 效率更高

  数字基带 → DPD处理 → DAC → PA（近饱和）→ 天线
                                 ↑
                           反馈用于自适应DPD更新

功耗收益（典型5G基站PA）:
  无DPD：PA需回退6dB，效率~20%
  有DPD：PA只需回退3dB，效率~35%
  DPD功耗：~0.5-2W（数字处理）
  净收益：对于100W PA，节省~15W（>7×于DPD自身功耗）

DPD的计算功耗:
  Volterra级数展开：高精度但复杂度O(N³)
  神经网络DPD：精度高，适合FPGA实现
  MP-DPD（Memory Polynomial）：工业界主流，O(N)
```

## 25.9 数模混合SoC的协同低功耗设计

### 25.9.1 数字噪声对模拟电路的干扰

```
数字噪声干扰模拟/RF电路的机制:

主要噪声路径:
  1. 衬底噪声（Substrate Noise）:
     数字时钟边沿 → 衬底耦合 → VCO频率扰动
     → 相位噪声恶化（可达10-20dB劣化）

  2. 电源噪声（Supply Noise）:
     数字开关电流 → 共享电源 → VDD/GND波动
     → 模拟偏置点漂移 → 增益/NF恶化

  3. 电磁耦合（EM Coupling）:
     高速时钟线 → 近场辐射 → LNA输入串扰
     → 灵敏度降低

隔离策略（设计层面）:
  布局策略:
    模拟/RF模块集中在芯片一角
    数字模块与模拟模块保持最大距离
    模拟模块周围放置保护环（Guard Ring）

  电源策略:
    独立VDD域：VDD_ANA ≠ VDD_DIG
    LDO稳压（片上）：为模拟电路提供低噪声电源
    片上去耦电容：在模拟电源引脚附近大量布置

  时钟策略:
    ADC/DAC时钟路径远离LNA输入
    差分时钟走线减少辐射
    时钟边沿斜率控制（降低高频谐波）
```

### 25.9.2 LDO稳压器的功耗与噪声折中

```
LDO（低压差线性稳压器）在模拟SoC中的角色:

LDO的功耗来源:
  静态电流（IQ）：运放偏置电流，与负载无关
    低功耗LDO：IQ < 1μA
    高PSRR LDO：IQ ~10-100μA
  导通管压降（VDO × ILoad）：不可避免的损耗

PSRR（电源抑制比）与功耗的权衡:
  高PSRR LDO（>60dB @ 1MHz）:
    需要大增益运放 → 大电流偏置
    功耗高但噪声抑制好（适合VCO/LNA供电）
  低功耗LDO（IQ < 1μA）:
    PSRR通常 < 40dB @ 1MHz
    适合对噪声不敏感的数字逻辑

超低功耗LDO优化技术:
  1. 自适应偏置：负载重时增加运放电流，轻载时降低
  2. 弹冲式（Flipped Voltage Follower, FVF）拓扑：
     最小IQ，良好瞬态响应，适合IoT SoC
  3. 无电容LDO（Capless LDO）：
     集成大输出电容节省面积
     瞬态响应设计需特别关注

典型IoT SoC中的LDO策略:
  VDD_RF（1.8V）← LDO从3V供电：PSRR > 60dB，IQ=50μA
  VDD_DIG（1.0V）← DCDC效率优先：效率>85%，纹波可接受
  VDD_PLL（1.5V）← 高PSRR LDO：IQ=20μA，相位噪声优先
```

### 25.9.3 时钟与信号完整性

```
高速时钟对模拟性能影响的量化分析:

ADC采样时钟抖动（Jitter）对SNR的影响:
  SNR_jitter = -20×log(2π × fs × σ_t)

  fs = 100MHz，σ_t = 1ps（RMS抖动）:
  SNR_jitter = -20×log(2π × 100MHz × 1ps)
             = -20×log(6.28×10⁻⁴)
             ≈ 64 dB

  结论：14位ADC（理论SNR=86dB）需要时钟抖动<0.1ps RMS

低抖动时钟方案选择:
  方案1：晶振TCXO（直接使用参考时钟）
    抖动：<100fs RMS，但频率固定
  方案2：LC-VCO PLL
    抖动：<500fs，可调频，功耗~10mW
  方案3：整数分频PLL
    抖动：<200fs（参考无散杂），功耗~5mW
  方案4：小数分频（FRAC-N）PLL
    抖动：~1-2ps（量化噪声），功耗~15mW

针对不同ADC精度的时钟功耗最优化:
  ADC≤10位：普通数字PLL即可（低功耗优先）
  ADC 12-14位：LC-VCO PLL必要
  ADC≥16位：TCXO + 低倍频LC-PLL
```

## 25.10 超低功耗无线收发器设计实例

### 25.10.1 BLE收发器能效设计

```
蓝牙低功耗（BLE 5.0）收发器设计剖析:

规格要求:
  频率：2.4GHz ISM频段
  调制：GFSK（1Mbps）/ LE Coded（125kbps）
  RX灵敏度：-96dBm（1Mbps）
  TX输出功率：0~+10dBm
  目标功耗：RX < 5mW，TX(0dBm) < 8mW

接收链路架构（直接转换）:
  天线 → 片上匹配 → LNA → IQ无源混频 → TIA → 低通滤波 → ADC

低功耗优化要点:
  LNA：电流复用（NMOS+PMOS），2.4GHz，NF<3dB，IDD=1.5mA
  无源混频：零直流电流，高线性度
  跨阻放大器（TIA）：利用CT-Σ△ADC代替，消除独立放大器
  整合ADC：6-8位SAR ADC，功耗<1mW
  PLL：ADPLL（DCO），快速唤醒<50μs，功耗<2mW

发射链路:
  调制方式：直接调频（DCO内部调制）— 省去独立调制器
  PA：差分AB类，效率~40%（0dBm输出），IDD=4mA

典型功耗指标（先进工艺，如22nm FDX）:
  RX工作：3.5mW（含PLL）
  TX @ 0dBm：5mW
  TX @ +8dBm：15mW
  睡眠模式：< 1μW
  能效：~35TOPS/W（BLE单位：bps/W） → ~5Mbps/mW
```

### 25.10.2 5G毫米波收发器低功耗设计

```
5G毫米波（28GHz）相控阵收发器功耗挑战:

单通道收发器功耗分析:
  LNA（28GHz）:      ~20mW（高频器件gm低，需大电流）
  混频器（下变频）:   ~15mW
  IF放大器:           ~10mW
  VGA（可变增益）:    ~5mW
  LO分配（28GHz）:   ~30mW（高频布线损耗大）
  PLL（7GHz×4）:     ~50mW
  单通道RX合计:       ~130mW

相控阵系统（64天线，8×TX+RX通道）:
  64通道 × 130mW = 8.3W（RX阵列）
  发射时PA功耗 >> 其他（每通道~200-500mW）

毫米波低功耗关键技术:

1. SiGe BiCMOS替代纯CMOS:
   fT>300GHz，相同增益下电流降低~3×
   代价：工艺成本略高

2. 本振（LO）共享:
   8个通道共享一个LO（仅相位调整不同）
   PLL数量：64→8，节省7×PLL功耗

3. 相位调整精度vs功耗:
   5位移相器：精度11.25°，足够大部分波束成形
   更多位→更高精度但功耗指数增长
   折中：6位（5.6°精度），仅用于增益高信道

4. 休眠通道策略:
   低速场景：仅4-8通道工作
   高速场景：全部64通道
   功耗随速度需求动态调整：4× 范围
```

## 25.11 工艺对模拟/RF低功耗的影响

### 25.11.1 先进CMOS工艺的挑战与机遇

```
CMOS工艺缩放对模拟/RF的双面影响:

正面影响（有利于低功耗）:
  ✅ fT/fmax提升（7nm工艺 fT>350GHz）
     → 相同频率下可用更小电流驱动
     → 相同功耗下可工作在更高频率

  ✅ 数字辅助模拟（更多数字校准资源）
     → 降低模拟精度要求 → 减小模拟偏置
     例：数字背景校准ADC可减少50%模拟电流

  ✅ 更低VDD → 减小动态功耗（C×VDD²×f）

负面影响（不利于低功耗）:
  ❌ 更低VDD → 模拟电路动态范围缩小
     → 需要更低噪声基底 → 更大偏置电流

  ❌ 短沟道效应（CLM, DIBL）→ 输出阻抗降低
     → 运放增益下降 → 精度降低 → 更大面积/功耗

  ❌ 1/f噪声拐角频率升高（先进工艺更严重）
     → 近载波相位噪声恶化 → VCO功耗增加

  ❌ 更多金属层但更薄 → 电感Q值不增（有时更低）
     → VCO功耗无法从工艺缩放中获益

最优工艺选择策略:
  纯射频（LNA/PA/VCO）：22nm FDX 或 55nm RF CMOS最优
  数模混合SoC：7nm/5nm（数字能效优先，模拟勉强接受）
  超低功耗IoT：180nm/130nm（成熟工艺，低漏电，低成本）
```

```
全耗尽绝缘体上硅（FD-SOI）对RF/模拟低功耗的优势:

FD-SOI vs 体硅CMOS:
┌─────────────────────────────────────────────────────┐
│  FD-SOI特有能力:                                    │
│                                                     │
│  1. 背栅偏置（Back-Gate Biasing）:                  │

FD-SOI典型收益（28nm, vs 28nm LP体硅）:
```

```
1. 模拟/RF功耗优化需要系统视角：不能孤立优化单个模块
2. 数字辅助模拟（校准、自适应）是降低模拟功耗的最强手段
3. ET+DPD组合是5G时代最重要的发射机效率提升技术
4. SAR ADC + CT-Σ△ ADC覆盖大部分低功耗应用需求
5. 架构选择（无源混频、ADPLL、直接转换）比电路级优化效果更显著
```
