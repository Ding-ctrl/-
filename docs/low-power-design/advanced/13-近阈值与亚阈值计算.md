# 第13章 近阈值与亚阈值计算

## 13.1 引言

在传统 CMOS 设计中，供电电压 (VDD) 通常远高于晶体管阈值电压 (Vth)。然而，由于动态功耗与 VDD² 成正比，**将电压降低到接近甚至低于 Vth** 可以获得巨大的功耗节省。近阈值计算 (Near-Threshold Computing, NTC) 和亚阈值计算 (Sub-Threshold Computing, STC) 正是利用这一原理，在极低电压下运行电路，以极低功耗完成计算任务。本章系统介绍 NTC/STC 的原理、设计方法和应用场景。

## 13.2 电压区域划分

### 13.2.1 三个工作区域

```
CMOS电压工作区域:

               能效 (MOPS/mW)
                 ▲
                 │
            峰值 │     ╱╲
                 │    ╱  ╲
                 │   ╱    ╲
                 │  ╱      ╲
                 │ ╱        ╲──────
                 │╱                 ╲
                 ┼────┼────┼────┼────►  VDD
                 0   Vth  Vnom      Vmax
                      │    │
         ◄──────►◄───►◄────►◄──────►
          亚阈值  近阈值 标称  超标称
           STC    NTC   NOM   TURBO

区域定义:
┌──────────┬─────────────┬───────────┬──────────────┐
│ 区域     │ VDD 范围    │ 速度      │ 能效         │
├──────────┼─────────────┼───────────┼──────────────┤
│ 亚阈值   │ 0.2V~Vth   │ 极低(kHz) │ 高但速度受限 │
│ 近阈值   │ Vth~Vth+0.2│ 低(MHz)   │ 最佳能效点   │
│ 标称     │ Vnom ±10%  │ 高(GHz)   │ 中等         │
│ 超标称   │ >Vnom      │ 最高      │ 最低         │
└──────────┴─────────────┴───────────┴──────────────┘
```

### 13.2.2 能效与电压的关系

```
能效 (Energy per Operation) vs VDD:

E_op = C_eff × VDD² + (I_leak × VDD × T_op)
       ─────────────   ──────────────────────
        动态能量            漏电能量

在不同电压区域:

超标称区 (VDD > Vnom):
  ├── 动态功耗主导
  ├── E_op ∝ VDD²
  └── 能效随VDD增加急剧下降

标称区 (VDD ≈ Vnom):
  ├── 动态功耗主导
  └── 标准工作点

近阈值区 (VDD ≈ Vth):
  ├── 动态功耗大幅降低 (约10× vs 标称)
  ├── 漏电功耗开始显著
  ├── 两者平衡 → 最佳能效点!
  └── 典型能效提升: 3-10× vs 标称电压

亚阈值区 (VDD < Vth):
  ├── 动态功耗极低
  ├── 但速度极慢 → T_op很大
  ├── 漏电能量 = I_leak × VDD × T_op 开始增加
  └── 能效开始下降（因为速度太慢）

结论: 近阈值区域是最佳能效点!
```

## 13.3 亚阈值电路原理

### 13.3.1 亚阈值电流

```
亚阈值电流方程:

I_sub = I_0 × exp((VGS - Vth) / (n × VT)) × (1 - exp(-VDS/VT))

其中:
  I_0  : 工艺相关常数
  VGS  : 栅源电压 (= VDD in digital circuits)
  Vth  : 阈值电压
  n    : 亚阈值斜率因子 (typically 1.3-1.5)
  VT   : 热电压 = kT/q ≈ 26mV @300K
  VDS  : 漏源电压

关键特征:
  - 电流随VGS指数变化（不是平方关系）
  - 当VGS < Vth时，电流非零但很小
  - 每减少 n×VT ≈ 60-80mV，电流减少10×
  - 温度敏感性极高（VT与温度成正比）
```

### 13.3.2 亚阈值逻辑特性

```
亚阈值逻辑工作特性:

优势:
  ├── 极低功耗: 动态功耗降低 100-1000×
  ├── 最低能量操作: 每次运算能量极小
  └── 简单电路可以工作

挑战:
  ├── 速度极低: 频率通常 < 1 MHz
  │   └── 延迟 ∝ C×VDD/(I_on) → I_on极小
  │
  ├── 工艺变异敏感性极高:
  │   ├── Ion/Ioff比率极低 (< 100 in STC vs >10⁶ in NOM)
  │   ├── Vth变异 → 电流变化 10×
  │   └── 全局/局部变异都有严重影响
  │
  ├── 噪声裕度降低:
  │   ├── VDD/2 < Vth → 逻辑摆幅小
  │   └── 更容易受噪声干扰
  │
  └── 温度依赖性强:
      ├── 漏电流 ∝ exp(-Vth/(n×VT))
      ├── VT = kT/q 与温度成正比
      └── 温度变化 → 性能大幅波动
```

## 13.4 近阈值计算 (NTC) 设计方法

### 13.4.1 NTC 设计空间

```
近阈值设计点选择:

          频率 (MHz)
            ▲
       1000 │           ×  标称 (0.9V)
            │         ×
        500 │       ×
            │     ×
        200 │   ×  
        100 │  × ← 近阈值甜点 (0.5-0.6V)
         50 │ ×
         10 │×  亚阈值 (0.3V)
            └───┼───┼───┼───┼───► VDD (V)
               0.3  0.5  0.7  0.9

选择NTC工作点需要平衡:
  1. 功耗预算
  2. 性能需求
  3. 工艺变异容忍度
  4. 能效最优点
```

### 13.4.2 NTC 电路设计技术

```
NTC关键设计技术:

1. 宽裕度设计 (Wide-Margin Design)
   ├── 使用更大的时序裕度 (>30% vs 标称10%)
   ├── 关键路径加倍冗余
   └── 避免使用最小尺寸晶体管

2. 变异容忍设计 (Variation-Tolerant)
   ├── 使用较大晶体管 (>2× minimum)
   ├── 对称电路设计
   ├── 使用NAND/NOR而非复杂门
   └── 限制逻辑深度

3. 标准单元库优化
   ├── NTC专用标准单元库
   ├── 减少逻辑深度 (max 2-3 级)
   ├── 增加晶体管宽度
   └── 优化时钟树设计

4. 时钟设计
   ├── 低频时钟 (10-200 MHz)
   ├── 容忍更大的时钟偏斜
   ├── 使用延迟线/环振作为时钟源
   └── 可调节频率（应对PVT变化）
```

### 13.4.3 NTC 标准单元库特征

| 参数 | 标称电压库 (0.9V) | NTC 库 (0.5V) | 变化 |
|------|-------------------|---------------|------|
| 驱动能力 | 强 | 弱 (~10×) | ↓ |
| 延迟 | 快 | 慢 (~5-10×) | ↑ |
| 动态功耗 | 高 | 低 (~3×) | ↓ |
| 漏电功耗 | 中 | 低 (~2×) | ↓ |
| 能效 (E/op) | 中 | 最佳 (~5×) | ↓ |
| Vth变异影响 | 小 | 大 (~10×) | ↑ |
| 噪声裕度 | 好 | 差 (~50%) | ↓ |
| 最大频率 | GHz级 | 100 MHz级 | ↓ |

## 13.5 NTC/STC 电路实现

### 13.5.1 SRAM 在低电压下的挑战

```
SRAM低电压挑战:

标准6T SRAM在低电压下的问题:

     VDD (↓降低)
      │
    ┌─┴─┐   ┌─┴─┐
    │ P0 │   │ P1 │
    └─┬─┘   └─┬─┘
      │       │
      ├───┬───┤
      │   │   │
    ┌─┴─┐ │ ┌─┴─┐
    │ N0 │ │ │ N1 │      ← 读干扰: VDD低时N0无法
    └─┬─┘ │ └─┬─┘         保持状态（被BL拉高）
      │   │   │
     GND  BL  BLB

问题:
  1. 读稳定性 (Read Stability): VDD < 0.5V时6T极不稳定
  2. 写能力 (Write-ability): 弱上拉 → 难以写1
  3. Vmin很高: 6T SRAM的Vmin通常 > 0.6V

解决方案:

8T SRAM (读解耦):
  ├── 增加2个读端口晶体管
  ├── 读操作不干扰存储节点
  └── Vmin可降至 ~0.4V

10T SRAM:
  ├── 更强的读写解耦
  └── Vmin可降至 ~0.3V

代价: 面积增加 30-60%
```

### 13.5.2 NTC 处理器架构

```
NTC处理器架构设计原则:

1. 宽流水线，低频率
   ├── 传统: 窄流水 × 高频
   └── NTC:  宽流水 × 低频 → 同吞吐量，更低功耗
   
   示例:
   传统: 4-wide × 2GHz = 8 GOPS @ 500mW
   NTC:  16-wide × 200MHz = 3.2 GOPS @ 30mW
         (能效提升 ~6×)

2. 多核并行，单核简化
   ├── 很多简单核 (如 1000 个简单核)
   ├── 每核极低频率运行
   └── 总吞吐量 = 核数 × 单核吞吐量

3. 异构加速
   ├── 通用核: NTC运行（低频低功耗）
   ├── 加速器: 标称电压运行（偶尔需要高性能时）
   └── 动态切换工作模式

4. 简化微架构
   ├── 顺序执行 (In-Order) 而非乱序
   ├── 短流水线 (3-5级)
   ├── 小缓存 (减少SRAM面积/功耗)
   └── 简单分支预测
```

## 13.6 Adaptive Voltage Scaling (AVS)

### 13.6.1 AVS 原理

```
AVS (自适应电压缩放):

在NTC/STC区域, 工艺变异影响极大:
  - Fast corner芯片: VDD可以更低
  - Slow corner芯片: VDD需要更高

AVS的目标: 找到每颗芯片的最低可工作电压

      性能
        ▲
        │  ┌── Slow Die
        │  │ ┌── Typical Die  
        │  │ │ ┌── Fast Die
        │  │ │ │
   目标─│──┼─┼─┼───────────── 
        │  │ │ │
        │  │ │ │
        └──┴─┴─┴──────────► VDD
           S  T  F  
           │  │  │
        需要  标称  可以
        更高  电压  更低

AVS系统架构:

┌─────────────────────────────────────────┐
│  ┌───────────┐   ┌───────────────────┐  │
│  │ 关键路径   │   │ 电压控制器        │  │
│  │ 延迟监测器 │──►│ (Digital)         │  │
│  │ (CPM)     │   │ ┌───────┐         │  │
│  └───────────┘   │ │ 算法  │         │  │
│  ┌───────────┐   │ │ 逻辑  │         │  │
│  │ 温度传感器 │──►│ └───┬───┘         │  │
│  └───────────┘   │     │             │  │
│  ┌───────────┐   │     ▼             │  │
│  │ 漏电监测器 │──►│ ┌───────┐        │  │
│  └───────────┘   │ │ PMIC  │◄──VDD   │  │
│                  │ │ 接口  │──►VDD_opt│  │
│                  │ └───────┘         │  │
│                  └───────────────────┘  │
│                           SoC           │
└─────────────────────────────────────────┘
```

### 13.6.2 关键路径监测器 (CPM)

```
关键路径监测器类型:

1. 延迟线监测器 (Delay-Line Monitor)
   ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐
   │ INV ├─┤ INV ├─┤ INV ├─┤ INV ├──► 输出
   └─────┘ └─────┘ └─────┘ └─────┘
   ↑ 输入
   
   原理: 延迟链的延迟反映当前PVT条件
   输出延迟 > 阈值 → 电压偏低,需升压
   输出延迟 < 阈值 → 电压偏高,可降压

2. 环形振荡器监测器 (Ring Oscillator)
   ┌─────────────────────────────┐
   │    ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐  │
   └───►│ ├─┤ ├─┤ ├─┤ ├─┤ ├──┘
        └─┘ └─┘ └─┘ └─┘ └─┘
   
   原理: 振荡频率反映当前速度
   频率计数 → 判断电压是否足够

3. 时序错误检测器 (Timing Error Detector)
   ├── Razor: 双锁存器检测时序违反
   ├── TIMBER: 预警+检测双重机制
   └── 原理: 直接检测是否发生时序错误
```

## 13.8 NTC 设计中的 EDA 工具支持

### 13.8.1 NTC 设计流程特殊需求

```
NTC设计流程与标称设计的差异:

1. 库表征 (Liberty)
   ├── 需要在NTC电压点表征（如0.4V, 0.5V, 0.6V）
   ├── 更多的PVT角（变异影响大）
   ├── 蒙特卡洛统计表征
   └── 亚阈值区域的延迟模型精度

2. 综合
   ├── 更大的时序裕度（>30% guard band）
   ├── 全部使用HVT/uHVT单元
   ├── 减少逻辑深度
   └── 避免复杂门（限制为INV/NAND/NOR）

3. STA
   ├── 统计时序分析 (SSTA) 更为重要
   ├── 需要考虑局部变异
   ├── OCV (On-Chip Variation) derating更大
   └── 温度反转效应（NTC区域温度↑ → 速度↑）

4. 功耗分析
   ├── 漏电模型精度至关重要
   ├── 温度依赖性建模
   └── 变异对功耗的影响（统计功耗分析）
```

### 13.8.2 温度反转效应 (Temperature Inversion)

```
温度反转效应:

标称电压 (VDD >> Vth):
  温度↑ → 迁移率↓ → 速度↓ (正常行为)
  最差角: SS, High Temperature

近阈值/亚阈值 (VDD ≈ Vth):
  温度↑ → Vth↓ → Ion↑ → 速度↑ (反转!)
  最差角: SS, LOW Temperature  ← 与标称相反!

         延迟
           ▲
           │    ╲         标称电压: 高温→慢
           │     ╲
           │      ╲
     标称   │       ╲────────────
           │
           │       ╱────────────
           │      ╱
           │     ╱        NTC: 高温→快 (反转!)
     NTC   │    ╱
           └──────────────────► 温度
              -40°C        125°C

设计影响:
  NTC设计的时序约束需要包含低温角!
  传统设计忽略低温角可能导致NTC设计失败
```

## 13.10 实践指南

### 13.10.1 NTC 设计 Checklist

```
NTC项目设计检查清单:

□ 确认应用场景真正需要NTC（功耗 > 性能）
```

| NTC原理 | VDD降至接近Vth，能效提升3-10× |
| STC原理 | VDD < Vth，极低功耗但速度极慢 |
| 能效最优点 | 在近阈值区域，动态和漏电能量平衡 |
| 变异挑战 | NTC区域工艺变异影响放大10× |
| SRAM | 标准6T不工作，需要8T/10T |
| AVS | 自适应电压缩放，逐芯片优化 |
| 温度反转 | NTC区域低温反而更慢（与直觉相反） |
| 应用 | IoT传感器、医疗植入、可穿戴设备 |
