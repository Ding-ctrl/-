# 第19章 电源完整性分析

## 19.1 引言

电源完整性 (Power Integrity, PI) 是确保芯片在各种工作条件下获得稳定、清洁供电的关键。在先进工艺节点中，随着电压降低和电流增加，IR-Drop、电迁移 (EM) 和电源噪声问题日益严峻。本章系统介绍 IR-Drop、EM 和去耦电容分析的完整方法论。

## 19.2 电源完整性基础

### 19.2.1 电源分配网络 (PDN) 模型

```
电源分配网络等效电路:

VDD_ideal ── R_pkg ── L_pkg ── R_grid ── R_via ── VDD_cell
               │                  │                   │
             C_pkg              C_decap             C_gate
               │                  │                   │
              GND               GND                 GND

各级寄生参数:
┌──────────────┬──────────┬──────────┬──────────┐
│ 级别         │ R (mΩ)   │ L (pH)   │ C (nF)   │
├──────────────┼──────────┼──────────┼──────────┤
│ PCB          │ 1-5      │ 100-500  │ 100-1000 │
│ Package      │ 5-20     │ 50-200   │ 10-100   │
│ C4 Bump      │ 10-50    │ 10-50    │ -        │
│ Die PG (Top) │ 20-100   │ 5-20     │ 1-10     │
│ Die PG (Bot) │ 50-500   │ 1-5      │ 0.1-1    │
│ Std Cell     │ 100-1000 │ 0.1-1    │ 0.01-0.1 │
└──────────────┴──────────┴──────────┴──────────┘

VDD_cell = VDD_ideal - I × R_total - L × dI/dt
                        ─────────   ──────────
                        IR-Drop     Ldi/dt Drop
```

### 19.2.2 三大 PI 问题

```
电源完整性三大问题:

1. IR-Drop (电阻性压降)
   VDD_drop = I × R_pdn
   ├── 静态IR-Drop: 平均电流导致
   ├── 动态IR-Drop: 瞬态电流导致
   └── 影响: 延迟增加, 功能错误

2. Ldi/dt (感性压降)
   VDD_noise = L_pdn × dI/dt
   ├── 大量门同时翻转时
   ├── 电流急剧变化 (dI/dt大)
   └── 影响: 电源噪声, 时钟抖动

3. 电迁移 (Electromigration, EM)
   ├── 高电流密度导致金属原子迁移
   ├── 最终导致断路或短路
   └── 影响: 芯片寿命降低
```

## 19.3 IR-Drop 分析

### 19.3.1 静态 IR-Drop 分析

```
静态IR-Drop分析:

输入:
  ├── 电源网络拓扑 (PG mesh from DEF)
  ├── 标准单元功耗分布 (from SAIF/平均功耗)
  ├── Bump/Pad位置
  └── 金属层RC参数

分析方法:
  将电源网络建模为电阻网络
  I_cell = P_cell / VDD  (每个单元的电流)
  求解 KCL/KVL方程组 → 得到各节点电压

结果呈现:
  ┌────────────────────────────────────┐
  │  IR-Drop 分布热力图               │
  │                                    │
  │  ████████░░░░░░████████           │
  │  ████████░░░░░░████████           │
  │  ░░░░░░░░░░░░░░░░░░░░            │
  │  ████████████████████████         │
  │  ████████████████████████         │
  │                                    │
  │  ████ = 高IR-Drop (>30mV)        │
  │  ░░░░ = 低IR-Drop (<10mV)        │
  └────────────────────────────────────┘

判定标准:
  VDD_min = VDD - IR_drop_max
  要求: IR_drop_max < 5% × VDD (典型)
  
  例: VDD=0.9V → IR_drop < 45mV
```

### 19.3.2 动态 IR-Drop 分析

```
动态IR-Drop分析:

与静态分析的区别:
  静态: 使用平均电流, 稳态分析
  动态: 使用瞬态电流波形, 时域分析

输入 (额外需要):
  ├── VCD/FSDB波形 (信号翻转信息)
  ├── 时钟边沿时刻
  └── 去耦电容模型

最差场景 (Worst-Case):
  大量寄存器在同一时钟边沿翻转
  → 瞬间电流尖峰
  → 电压骤降

┌────────────────────────────────────────────┐
│  动态IR-Drop波形:                           │
│                                             │
│  VDD ═════╗     ╔═══════╗     ╔═════       │
│           ║     ║       ║     ║             │
│           ╚═════╝       ╚═════╝             │
│           ◄────►        ◄────►              │
│           ~1ns           ~1ns               │
│         时钟边沿处       下一个时钟边沿      │
│                                             │
│  电流                                       │
│      ▲  ┌─┐         ┌─┐                    │
│      │  │ │         │ │                     │
│      │──┘ └─────────┘ └──────               │
│      └─────────────────────────► 时间        │
└────────────────────────────────────────────┘

动态IR-Drop标准: < 10% VDD (典型)
```

### 19.3.3 IR-Drop 修复策略

```
IR-Drop修复方法:

级别1: 电源网络优化 (效果最大)
  ├── 增加电源条宽度 (降低R)
  ├── 增加电源条密度 (更多并联路径)
  ├── 增加VIA数量 (降低层间电阻)
  ├── 在高IR区域增加电源条
  └── 优化Bump/Pad分布

级别2: 去耦电容 (对付动态IR-Drop)
  ├── 插入去耦电容单元 (decap cell)
  ├── 在IR-Drop热点附近放置
  ├── 利用空白区域放置填充decap
  └── 典型覆盖目标: 5-15% 核心面积

级别3: 设计层面
  ├── 降低同时翻转率 (stagger clock edges)
  ├── 减少峰值电流 (spread switching activity)
  ├── 关键路径避开高IR-Drop区域
  └── 使用门控减少不必要的翻转

级别4: 封装级
  ├── 增加电源Bump数量
  ├── 优化Bump分布 (电源/地交替)
  └── 降低封装寄生参数
```

## 19.4 电迁移 (EM) 分析

### 19.4.1 EM 原理

```
电迁移原理:

高电流密度 → 电子与金属原子碰撞 → 原子迁移
                                         │
                              ┌──────────▼──────────┐
                              │  材料堆积 + 空洞形成  │
                              └──────────┬──────────┘
                                         │
                              ┌──────────▼──────────┐
                              │  开路 (void)        │
                              │  短路 (hillock)     │
                              └─────────────────────┘

Black方程 (EM寿命预测):
  MTF = A × (J)^(-n) × exp(Ea / kT)
  
  MTF: 平均失效时间 (Mean Time to Failure)
  A:   材料常数
  J:   电流密度 (A/cm²)
  n:   电流密度指数 (通常 1-2)
  Ea:  激活能 (eV)
  T:   温度 (K)

关键结论:
  电流密度 × 2 → 寿命 ÷ 4 (n=2时)
  温度 +10°C → 寿命 ÷ 2 (近似)
```

### 19.4.2 EM 检查标准

```
EM 检查标准 (典型值):

┌──────────────┬──────────────┬──────────────┐
│ 金属层       │ DC Jmax      │ AC Jmax      │
│              │ (mA/μm)     │ (mA/μm)     │
├──────────────┼──────────────┼──────────────┤
│ M1 (Cu)      │ 1.0          │ 5.0          │
│ M2-M4 (Cu)   │ 1.5          │ 7.5          │
│ M5-M8 (Cu)   │ 2.0          │ 10.0         │
│ M9-M10 (Cu)  │ 3.0          │ 15.0         │
│ AP (Al)       │ 4.0          │ 20.0         │
│ Via          │ 0.5          │ 2.5          │
└──────────────┴──────────────┴──────────────┘

DC vs AC:
  DC: 单方向持续电流 (电源网络)
  AC: 交变电流 (信号线, 时钟线)
  AC允许更大电流密度 (原子来回迁移，净迁移小)

EM裕度:
  设计目标: J_actual < 80% × Jmax
  签核标准: J_actual < 100% × Jmax
```

### 19.4.3 EM 修复

```
EM违反修复策略:

1. 电源网络EM
   ├── 加宽电源金属线 (最直接)
   ├── 增加并联电源条
   ├── 增加Via数量和尺寸
   └── 优化电流分布

2. 信号线EM
   ├── 加宽信号线 (non-default rule)
   ├── 减少单元驱动强度 (减少电流)
   ├── 添加缓冲器分散负载
   └── 缩短连线长度 (重新布局)

3. 时钟网络EM
   ├── 时钟线通常电流密度最高
   ├── 使用宽金属规则
   ├── 增加时钟树缓冲器
   └── 使用更高层金属
```

## 19.5 去耦电容设计

### 19.5.1 去耦电容原理

```
去耦电容工作原理:

没有Decap:                 有Decap:
  VDD ───R_grid─── Cell      VDD ───R_grid─── Cell
                     │                          │
                    ═══                   Cdecap═══
                     │                          │
                    GND                        GND

  电流从远处VDD供应           Cdecap本地供应瞬态电流
  → 经过长距离PG mesh        → 减少PG mesh上的瞬态电流
  → 大IR-Drop               → 降低动态IR-Drop

去耦电容类型:
  1. 标准单元Decap: 利用NMOS/PMOS栅电容
     面积: 小, 分散放置
     容值: ~1-5 fF/μm²
  
  2. MOM电容: Metal-Oxide-Metal
     面积: 中, 密度高
     容值: ~5-10 fF/μm²
  
  3. MIM电容: Metal-Insulator-Metal
     面积: 大, 需要额外工艺层
     容值: ~10-20 fF/μm²
```

### 19.5.2 去耦电容放置策略

```
Decap放置策略:

1. 填充式 (Filler-based)
   ├── 利用标准单元行间空白区域
   ├── 放置Decap Filler单元
   └── 覆盖率: 5-15% 核心面积

2. 热点定向 (Hotspot-targeted)
   ├── 在IR-Drop热点附近集中放置
   ├── 效果最好
   └── 需要迭代: 分析→放置→再分析

3. 时钟驱动附近 (Clock-driven)
   ├── 时钟缓冲器消耗大量瞬态电流
   ├── 在CTS驱动附近放置Decap
   └── 有效降低时钟相关的动态IR-Drop

放置命令 (ICC2):
  # 自动填充Decap
  create_stdcell_fillers \
      -lib_cells {DECAP_X1 DECAP_X2 DECAP_X4} \
      -mode decap
  
  # 在特定区域增加Decap
  add_decap \
      -cells {DECAP_X4 DECAP_X8} \
      -area {100 100 500 500} \
      -target_cap 10pF
```

## 19.6 电源噪声分析

### 19.6.1 SSN (Simultaneous Switching Noise)

```
同时开关噪声 (SSN):

原因: 大量I/O或内部门同时翻转
  → 地弹 (Ground Bounce): GND电压瞬时上升
  → 电源塌陷 (Supply Droop): VDD电压瞬时下降

SSN = L_total × N × dI/dt

其中:
  L_total: 总封装电感
  N: 同时翻转的驱动器数量
  dI/dt: 单个驱动器的电流变化率

缓解策略:
  ├── 减少同时翻转: 信号skew, 时钟分散
  ├── 增加去耦电容: 本地供电瞬态电流
  ├── 增加电源/地引脚: 降低L_total
  └── 控制I/O开关速率: slew rate control
```

## 19.8 本章小结

| 分析类型 | 关键指标 | 典型限制 | 主要修复方法 |
|----------|----------|----------|-------------|
| 静态IR-Drop | 最大电压降 | <5% VDD | 加宽/加密电源条 |
| 动态IR-Drop | 瞬态电压降 | <10% VDD | 去耦电容+分散翻转 |
| DC EM | 电流密度 | <Jmax | 加宽金属线+增加Via |
| AC EM | 峰值电流密度 | <5×Jmax | 增加缓冲器+加宽线 |
| SSN | 地弹/电源塌陷 | <100mV | 增加P/G引脚+Decap |
