# 第11章 低功耗仿真与验证实操

## 11.1 引言

低功耗设计的功能正确性不能仅靠传统仿真来保证。电源开关导致的信号未知态 (X)、隔离单元的钳位行为、保持寄存器的保存/恢复时序——这些都需要**电源感知 (Power-Aware)** 的仿真和验证手段来检查。本章介绍 PA-Sim、低功耗形式化验证和功耗回归测试的实际操作方法。

## 11.2 Power-Aware 仿真 (PA-Sim) 概述

### 11.2.1 PA-Sim 与传统仿真的区别

```
传统仿真 vs PA-Sim:

传统仿真:
┌─────────────────────────────────────────────┐
│  所有信号始终有效                             │
│  不感知电源域状态                             │
│  无法检测跨域信号问题                         │
│  结果: 功能可能"通过"但实际硅片上失败          │
└─────────────────────────────────────────────┘

PA-Sim:
┌─────────────────────────────────────────────┐
│  ✓ 电源域关断时，域内信号变为 X              │
│  ✓ 隔离单元在使能时钳位输出                  │
│  ✓ 保持寄存器保存/恢复状态                   │
│  ✓ 电平转换器处理跨域信号                    │
│  ✓ 检测电源状态转换序列正确性                │
│  结果: 真实反映芯片上的行为                   │
└─────────────────────────────────────────────┘
```

### 11.2.2 PA-Sim 检查的关键场景

| 场景 | PA-Sim 行为 | 检查内容 |
|------|------------|----------|
| 域关断 | 域内所有信号变 X | X 不会传播到其他域 |
| 隔离使能 | 跨域输出被钳位 | 钳位值正确 (0/1/锁存) |
| 状态保存 | retention 寄存器锁存当前值 | save 时序正确 |
| 状态恢复 | retention 寄存器恢复保存值 | restore 后值正确 |
| 电源恢复 | 域内信号从 X 恢复 | 恢复后功能正确 |
| 电压切换 | DVFS 电压变化 | 电平转换器工作正确 |

### 11.3.3 Testbench 中的电源控制

```systemverilog
///////////////////////////////////////////////
// Power-Aware Testbench 关键代码
///////////////////////////////////////////////

module tb_top;

    // DUT 实例化
    top u_dut (...);

    // ============================================
    // 电源控制序列 (使用 UPF 供电控制)
    // ============================================

    // 方式1：通过 PMU 控制信号驱动
    task power_down_cpu();
        $display("[%0t] Starting CPU power-down sequence", $time);

        // Step 1: 停止CPU时钟
        force u_dut.u_pmu.cpu_clk_en = 1'b0;
        #10;

        // Step 2: 使能隔离
        force u_dut.u_pmu.iso_cpu_en = 1'b1;
        #5;

        // Step 3: 保存状态
        force u_dut.u_pmu.ret_cpu_save = 1'b1;
        #5;
        force u_dut.u_pmu.ret_cpu_save = 1'b0;
        #5;

        // Step 4: 关断电源
        force u_dut.u_pmu.cpu_pwr_en = 1'b0;
        #100;

        $display("[%0t] CPU power-down complete", $time);
    endtask

    task power_up_cpu();
        $display("[%0t] Starting CPU power-up sequence", $time);

        // Step 1: 打开电源开关（等待稳定）
        force u_dut.u_pmu.cpu_pwr_en = 1'b1;
        #200;  // 等待电压稳定

        // Step 2: 恢复状态
        force u_dut.u_pmu.ret_cpu_restore = 1'b1;
        #5;
        force u_dut.u_pmu.ret_cpu_restore = 1'b0;
        #5;

        // Step 3: 关闭隔离
        force u_dut.u_pmu.iso_cpu_en = 1'b0;
        #5;

        // Step 4: 恢复时钟
        force u_dut.u_pmu.cpu_clk_en = 1'b1;
        #10;

        $display("[%0t] CPU power-up complete", $time);
    endtask

    // ============================================
    // 方式2：使用 supply 控制 API (UPF 2.0+)
    // ============================================
    `ifdef UPF_SUPPLY_CONTROL
    // 直接控制供电状态
    initial begin
        // 设置供电网络状态
        $supply_on("VDD_CPU_SW", 0.9);   // 打开并设置电压
        #1000;
        $supply_off("VDD_CPU_SW");        // 关闭
        #500;
        $supply_on("VDD_CPU_SW", 0.7);   // 以低电压重新打开
    end
    `endif

    // ============================================
    // 电源状态检查断言
    // ============================================

    // 检查：隔离必须在电源关断前使能
    property iso_before_power_off;
        @(negedge u_dut.u_pmu.cpu_pwr_en)
        u_dut.u_pmu.iso_cpu_en == 1'b1;
    endproperty
    assert property (iso_before_power_off)
        else $error("ISO not enabled before power-off!");

    // 检查：保持保存必须在电源关断前完成
    property save_before_power_off;
        @(negedge u_dut.u_pmu.cpu_pwr_en)
        $past(u_dut.u_pmu.ret_cpu_save, 1);
    endproperty
    assert property (save_before_power_off)
        else $error("Retention save not done before power-off!");

    // 检查：电源恢复后隔离才能关闭
    property iso_after_power_on;
        @(negedge u_dut.u_pmu.iso_cpu_en)
        u_dut.u_pmu.cpu_pwr_en == 1'b1;
    endproperty
    assert property (iso_after_power_on)
        else $error("ISO disabled before power is on!");

    // ============================================
    // 功能验证：电源循环后数据完整性
    // ============================================

    reg [31:0] saved_pc;
    reg [31:0] saved_sp;

    task verify_retention();
        // 记录关断前的寄存器值
        saved_pc = u_dut.u_cpu.pc_reg;
        saved_sp = u_dut.u_cpu.sp_reg;

        // 执行关断-恢复序列
        power_down_cpu();
        #500;
        power_up_cpu();

        // 验证恢复后的值
        #10;
        if (u_dut.u_cpu.pc_reg !== saved_pc)
            $error("PC register not retained! Expected: %h, Got: %h",
                   saved_pc, u_dut.u_cpu.pc_reg);
        if (u_dut.u_cpu.sp_reg !== saved_sp)
            $error("SP register not retained! Expected: %h, Got: %h",
                   saved_sp, u_dut.u_cpu.sp_reg);

        $display("[%0t] Retention verification PASSED", $time);
    endtask

endmodule
```

## 11.5 低功耗形式化验证

### 11.5.1 概述

形式化验证可以**穷举检查**低功耗设计规则，覆盖仿真难以到达的边角情况：

```
低功耗形式化验证检查项:

┌──────────────────────────────────────────────────────┐
│  结构性检查 (Structural Checks)                       │
│  ├── 所有跨域信号都有隔离                              │
│  ├── 所有可关断域寄存器都有保持策略                     │
│  ├── 所有跨电压域路径都有电平转换                       │
│  ├── 隔离/保持控制信号来自Always-On域                   │
│  └── 电源开关控制信号不来自被控域                       │
├──────────────────────────────────────────────────────┤
│  协议性检查 (Protocol Checks)                         │
│  ├── 电源关断序列正确（先隔离→保存→关断）              │
│  ├── 电源恢复序列正确（上电→恢复→去隔离）              │
│  ├── 隔离使能窗口覆盖整个关断周期                      │
│  └── 保持save/restore时序满足要求                     │
├──────────────────────────────────────────────────────┤
│  功能性检查 (Functional Checks)                       │
│  ├── 电源循环后功能等价                                │
│  ├── 保持寄存器恢复值正确                              │
│  └── 隔离输出值与UPF定义一致                           │
└──────────────────────────────────────────────────────┘
```

### 11.5.4 自定义低功耗断言

```systemverilog
///////////////////////////////////////////////
// SVA低功耗断言库 (可复用)
///////////////////////////////////////////////

// 1. 隔离时序断言
// 隔离必须在电源关断前至少N个周期使能
property iso_timing_check(iso_en, pwr_en, min_cycles);
    @(negedge pwr_en)
    $past(iso_en, min_cycles) == 1'b1;
endproperty

// 2. 保持save时序
// save信号必须在电源关断前脉冲
property retention_save_check(save, pwr_en);
    @(negedge pwr_en)
    $past($rose(save) && $fell(save));
endproperty

// 3. 保持restore时序
// restore必须在电源恢复后脉冲
property retention_restore_check(restore, pwr_en);
    @(posedge restore)
    pwr_en == 1'b1;
endproperty

// 4. 无X传播检查
// 被隔离的信号不应有X值传到其他域
property no_x_propagation(signal, iso_en);
    @(posedge clk)
    iso_en |-> !$isunknown(signal);
endproperty

// 5. 电源域互斥检查
// 某些域不应同时处于特定状态
property power_state_mutex(pwr_a, pwr_b);
    @(posedge clk)
    not (pwr_a == 1'b0 && pwr_b == 1'b0);
endproperty
```

### 11.6.2 自动化回归测试框架

```python
#!/usr/bin/env python3
###############################################
# 低功耗回归测试框架 (概念示例)
###############################################

import subprocess
import json
from pathlib import Path

class LowPowerRegressionRunner:
    """低功耗回归测试运行器"""

    def __init__(self, config_file):
        with open(config_file) as f:
            self.config = json.load(f)
        self.results = []

    def run_pa_sim(self, test_name, plusargs=""):
        """运行单个PA-Sim测试"""
        cmd = (
            f"./simv_pa "
            f"+testname={test_name} "
            f"+power+check_isolation "
            f"+power+check_retention "
            f"{plusargs} "
            f"-l logs/{test_name}.log"
        )
        result = subprocess.run(cmd, shell=True,
                              capture_output=True, text=True)
        passed = "TEST PASSED" in result.stdout
        self.results.append({
            "test": test_name,
            "passed": passed,
            "log": f"logs/{test_name}.log"
        })
        return passed

    def run_power_cycle_tests(self):
        """电源循环测试集"""
        tests = [
            ("pwr_cycle_cpu_basic",    "+domain=PD_CPU"),
            ("pwr_cycle_gpu_basic",    "+domain=PD_GPU"),
            ("pwr_cycle_modem_basic",  "+domain=PD_MODEM"),
            ("pwr_cycle_multi_domain", "+domain=ALL"),
            ("pwr_cycle_rapid",        "+domain=PD_CPU +cycles=100"),
            ("pwr_cycle_with_traffic", "+domain=PD_CPU +bg_traffic=1"),
        ]
        for test_name, args in tests:
            self.run_pa_sim(test_name, args)

    def run_retention_tests(self):
        """状态保持测试集"""
        tests = [
            ("ret_cpu_all_regs",     "+domain=PD_CPU +check_all_regs"),
            ("ret_cpu_arch_state",   "+domain=PD_CPU +check_arch_state"),
            ("ret_gpu_context",      "+domain=PD_GPU +check_context"),
            ("ret_partial_save",     "+domain=PD_CPU +partial_retention"),
        ]
        for test_name, args in tests:
            self.run_pa_sim(test_name, args)

    def run_dvfs_tests(self):
        """DVFS切换测试集"""
        tests = [
            ("dvfs_cpu_all_opp",     "+dvfs_sweep=CPU"),
            ("dvfs_gpu_all_opp",     "+dvfs_sweep=GPU"),
            ("dvfs_rapid_switch",    "+dvfs_rapid=1"),
            ("dvfs_under_load",      "+dvfs_with_load=1"),
        ]
        for test_name, args in tests:
            self.run_pa_sim(test_name, args)

    def generate_report(self):
        """生成回归测试报告"""
        total = len(self.results)
        passed = sum(1 for r in self.results if r["passed"])
        failed = total - passed

        print(f"\n{'='*60}")
        print(f" Low-Power Regression Report")
        print(f"{'='*60}")
        print(f" Total: {total}  Passed: {passed}  Failed: {failed}")
        print(f" Pass Rate: {passed/total*100:.1f}%")
        print(f"{'='*60}")

        if failed > 0:
            print(f"\n Failed Tests:")
            for r in self.results:
                if not r["passed"]:
                    print(f"   ✗ {r['test']}  (log: {r['log']})")

# 使用示例
if __name__ == "__main__":
    runner = LowPowerRegressionRunner("lp_regression.json")
    runner.run_power_cycle_tests()
    runner.run_retention_tests()
    runner.run_dvfs_tests()
    runner.generate_report()
```

### 11.6.3 覆盖率收集

```systemverilog
///////////////////////////////////////////////
// 低功耗覆盖率模型
///////////////////////////////////////////////

covergroup cg_power_states @(posedge clk);

    // 电源状态覆盖
    cp_cpu_power: coverpoint cpu_pwr_en {
        bins on  = {1};
        bins off = {0};
    }

    cp_gpu_power: coverpoint gpu_pwr_en {
        bins on  = {1};
        bins off = {0};
    }

    cp_modem_power: coverpoint modem_pwr_en {
        bins on  = {1};
        bins off = {0};
    }

    // 组合状态覆盖
    cx_multi_domain: cross cp_cpu_power,
                           cp_gpu_power,
                           cp_modem_power {
        // 排除非法组合
        ignore_bins illegal = binsof(cp_cpu_power) intersect {0} &&
                              binsof(cp_gpu_power) intersect {1};
    }

    // 电源状态转换覆盖
    cp_cpu_transition: coverpoint cpu_pwr_en {
        bins power_on  = (0 => 1);
        bins power_off = (1 => 0);
    }

    // DVFS OPP 覆盖
    cp_cpu_opp: coverpoint cpu_voltage_sel {
        bins opp_high    = {3'b100};
        bins opp_nominal = {3'b010};
        bins opp_low     = {3'b001};
    }

    // OPP 转换覆盖
    cp_opp_transitions: coverpoint cpu_voltage_sel {
        bins up_transition   = (3'b001 => 3'b010),
                               (3'b010 => 3'b100);
        bins down_transition = (3'b100 => 3'b010),
                               (3'b010 => 3'b001);
        bins skip_transition = (3'b001 => 3'b100),
                               (3'b100 => 3'b001);
    }

endgroup

covergroup cg_isolation @(posedge clk);

    // 隔离使能时机覆盖
    cp_iso_timing: coverpoint {iso_cpu_en, cpu_pwr_en} {
        bins iso_on_pwr_on   = {2'b11};  // 隔离使能且电源开
        bins iso_on_pwr_off  = {2'b10};  // 隔离使能且电源关 (正常)
        bins iso_off_pwr_on  = {2'b01};  // 隔离关闭且电源开 (正常)
        illegal_bins bad     = {2'b00};  // 隔离关闭且电源关 (违规!)
    }

endgroup
```

## 11.7 低功耗 Debug 方法

### 11.7.1 常见 PA-Sim 错误与解决

| 错误信息 | 原因 | 解决方案 |
|----------|------|----------|
| `X-propagation from powered-off domain` | 关断域的X传播到活动域 | 检查隔离策略是否完整 |
| `Isolation cell not enabled during power-off` | 电源关断时隔离未使能 | 修复PMU控制序列时序 |
| `Retention save signal not asserted` | 关断前未触发保存 | 确保save在关断前脉冲 |
| `Retention restore value mismatch` | 恢复值与保存值不一致 | 检查retention供电是否稳定 |
| `Level shifter input from off domain` | 电平转换器输入来自关断域 | 需要在LS前加隔离 |
| `Supply net not connected` | 供电网络未正确连接 | 检查UPF connect_supply_net |

### 11.7.2 调试工作流

```
PA-Sim调试工作流:

1. 编译运行 PA-Sim
   │
2. 检查编译 Warning/Error
   │  └── UPF 语法/一致性问题 → 修改 UPF
   │
3. 检查运行日志
   │  ├── X-propagation → 检查隔离
   │  ├── Retention fail → 检查保持时序
   │  └── 功能错误 → 检查电源控制序列
   │
4. 查看波形
   │  ├── 电源信号 (pwr_en, iso_en, save, restore)
   │  ├── 跨域信号 (隔离前后对比)
   │  └── 保持寄存器 (save前后值对比)
   │
5. 定位修复
   │  ├── UPF 问题 → 修改 UPF
   │  ├── RTL 问题 → 修改 RTL (PMU逻辑)
   │  └── TB 问题 → 修改 Testbench
   │
6. 回归验证
```
