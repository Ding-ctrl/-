# 第14章 新兴存储与计算架构

## 14.1 引言

传统冯·诺依曼架构中，数据在处理器与存储器之间频繁搬运，产生了巨大的**"存储墙"**功耗开销。在AI/ML时代，这一问题更为突出——神经网络推断中超过70%的能量消耗在数据搬运而非实际计算上。**存算一体 (Processing-In-Memory/Compute-In-Memory)** 和新型非易失存储器 (MRAM/RRAM/FeRAM) 等新兴技术，正在从根本上改变低功耗计算的范式。本章介绍这些前沿技术的原理与低功耗应用。

## 14.2 存储墙问题与数据搬运能耗

### 14.2.1 存储墙 (Memory Wall)

```
存储墙问题:

处理器与存储器性能差距持续扩大:

     性能提升
        ▲
   10000│          CPU
    1000│        ╱
     100│      ╱
      10│    ╱
       1│──╱─────────── DRAM
        └──────────────────► 年份
         1990    2000   2020

数据搬运能耗:

操作类型                 能耗 (pJ)      对比
──────────────────────────────────────────────
32-bit INT Add           0.03           1×
32-bit FP Multiply       3.7            ~120×
读取 32KB SRAM           5              ~170×
读取 L2 Cache            ~25            ~830×
DRAM 读取                ~640           ~21000×
片外DDR4读取             ~1300          ~43000×

结论: 数据搬运的能耗 >> 计算能耗!
      尤其在AI推断中，这是主要功耗瓶颈
```

### 14.2.2 数据移动开销分析

```
AI推断中的数据移动:

典型CNN推断能量分布:

┌─────────────────────────────────────┐
│ ██████████████████████████████ 70%  │  数据搬运
│ ██████████████ 25%                  │  MAC计算
│ ███ 5%                              │  控制/其他
└─────────────────────────────────────┘

ResNet-50 单帧推断:
  总MAC运算: ~4 GOPS
  总数据量:  ~100 MB (权重+激活)
  
  计算能量: ~4G × 0.03pJ = 0.12 mJ
  数据搬运: ~100M × 640pJ/B = 64 mJ  ← 535× !
  
  结论: 减少数据搬运是降低AI功耗的最有效方法
```

## 14.3 存算一体 (PIM/CIM) 架构

### 14.3.1 PIM vs CIM

```
存算一体分类:

1. PIM (Processing-In-Memory / Near-Memory Computing)
   ├── 在存储器旁边放计算单元
   ├── 数据不出存储阵列
   ├── 数字计算，精度高
   └── 与现有存储技术兼容性好

2. CIM (Compute-In-Memory / In-Memory Computing)
   ├── 利用存储阵列本身执行计算
   ├── 存储单元同时充当计算元素
   ├── 模拟计算，面积/功耗极低
   └── 精度受限，需要ADC/DAC

架构对比:

PIM:                          CIM:
┌──────────────────┐         ┌──────────────────┐
│ ┌──────┐┌──────┐ │         │                  │
│ │Memory││ ALU  │ │         │  Memory Array    │
│ │Array ││      │ │         │  = 存储 + 计算   │
│ └──┬───┘└──┬───┘ │         │  (模拟MAC)       │
│    └───┬───┘     │         │                  │
│        │ 短距搬运│         │     ┌────┐       │
│   ┌────▼────┐    │         │     │ADC │       │
│   │ 输出缓冲│    │         │     └────┘       │
│   └─────────┘    │         │                  │
└──────────────────┘         └──────────────────┘
```

### 14.3.2 SRAM-CIM 原理

```
SRAM-CIM 基本原理 (模拟MAC):

存储权重的SRAM阵列:

     BL0  BL1  BL2  BL3    (输入激活值)
      │    │    │    │
    ┌─┴──┬─┴──┬─┴──┬─┴──┐
WL0─┤ w00│ w01│ w02│ w03│──► 模拟累加线
    ├────┼────┼────┼────┤
WL1─┤ w10│ w11│ w12│ w13│──► 模拟累加线
    ├────┼────┼────┼────┤
WL2─┤ w20│ w21│ w22│ w23│──► 模拟累加线
    └────┴────┴────┴────┘
                              │
                              ▼
                          ┌──────┐
                          │ ADC  │
                          └──────┘
                              │
                              ▼
                          数字输出

工作原理:
1. 权重预存在SRAM单元中 (1-bit/多bit)
2. 输入激活值加载到位线 (BL)
3. 同时激活多行字线 (WL)
4. 位线电流 = Σ(输入 × 权重) → 模拟MAC!
5. ADC将模拟结果转为数字

优势:
  - 单周期完成矩阵向量乘法
  - 无需数据搬运（原地计算）
  - 功耗: 仅 0.1-1 TOPS/W vs 传统5-20 TOPS/W
```

### 14.3.3 CIM 能效优势

```
CIM vs 传统架构能效对比:

              传统加速器    SRAM-CIM     RRAM-CIM
──────────────────────────────────────────────────
面积效率      10 GOPS/mm²  100 GOPS/mm²  500 GOPS/mm²
能效          5 TOPS/W     20 TOPS/W     50 TOPS/W
精度          FP16/INT8    INT8/INT4     INT4/Binary
适用模型      全部          CNN/RNN       简单CNN
成熟度        产品级        早期产品      研究阶段
```

## 14.4 MRAM (磁性随机存取存储器)

### 14.4.1 STT-MRAM 原理

```
STT-MRAM (Spin-Transfer Torque MRAM):

结构 - 磁性隧道结 (MTJ):

    ┌─────────────────┐
    │  自由层 (FL)    │ ← 磁化方向可改变
    ├─────────────────┤
    │  隧道势垒层     │ ← MgO (~1nm)
    │  (Tunnel Barrier)│
    ├─────────────────┤
    │  固定层 (RL)    │ ← 磁化方向固定
    └─────────────────┘
    
    平行态 (P):  低电阻 → 存储 "0"
    反平行态(AP): 高电阻 → 存储 "1"

    TMR = (R_AP - R_P) / R_P × 100%
    典型TMR: 150-250%

写入: 通过电流的自旋转矩翻转自由层磁化方向
读取: 感测MTJ电阻判断状态
```

### 14.4.2 MRAM 低功耗特性

```
MRAM低功耗优势:

1. 非易失性 → 零待机漏电
   ├── 断电数据不丢失
   ├── 瞬时开关机 (Instant-On)
   └── 待机功耗: ~0 (vs SRAM漏电)

2. 读取能耗低
   ├── 读取: ~1 pJ/bit (与SRAM相当)
   └── 读取速度: ~1-5 ns

3. 无需刷新
   ├── DRAM需要每~64ms刷新一次
   ├── 刷新功耗占DRAM总功耗 ~30%
   └── MRAM完全不需要刷新

MRAM vs 其他存储器对比:

指标        SRAM    DRAM    Flash   STT-MRAM
───────────────────────────────────────────────
速度(读)    0.5ns   10ns    50μs    2ns
速度(写)    0.5ns   10ns    100μs   10ns
待机功耗    高(漏电) 中(刷新) ~0      ~0
写入能耗    低      低      高      中
耐久性      >10¹⁶   >10¹⁶   10⁵    >10¹²
面积(bit)   100-150F² 6-8F²  4F²    20-40F²
非易失性    否      否      是      是
```

### 14.4.3 MRAM 在低功耗 SoC 中的应用

```
MRAM替代策略:

场景1: MRAM替代SRAM (L2/L3 Cache)
  ├── 优势: 零漏电 → 待机功耗大幅降低
  ├── 挑战: 写入延迟和能耗较高
  └── 方案: 写优化策略(write-back cache)

场景2: MRAM替代DRAM (嵌入式)
  ├── 优势: 无需刷新, 面积小
  ├── 挑战: 密度不如DRAM
  └── 方案: IoT/边缘设备少量内存

场景3: MRAM + SRAM 混合
  ├── L1 Cache: SRAM (速度优先)
  ├── L2 Cache: MRAM (功耗优先)
  └── 常驻数据: MRAM (零漏电)

场景4: 非易失处理器 (NVP)
  ├── 所有寄存器和缓存用MRAM
  ├── 断电瞬间保存状态
  ├── 上电瞬间恢复运行
  └── 适合能量收集供电的间歇计算
```

## 14.5 RRAM (阻变随机存取存储器)

### 14.5.1 RRAM 原理

```
RRAM (Resistive RAM) 结构:

    ┌─────────────────┐
    │  顶电极 (TE)    │
    ├─────────────────┤
    │  阻变层         │ ← 金属氧化物 (HfO₂, TaO₂)
    │  (Switching)    │
    ├─────────────────┤
    │  底电极 (BE)    │
    └─────────────────┘

工作原理:
  SET:   施加正电压 → 形成导电丝 → 低电阻态 (LRS)
  RESET: 施加负电压 → 断开导电丝 → 高电阻态 (HRS)
  
  R_HRS / R_LRS > 10 (典型值: 10-1000)

存储密度: 4F² (最小, 1T1R结构)
          甚至 4F² (Crossbar结构, 无晶体管)
```

### 14.5.2 RRAM-CIM 用于 AI 推断

```
RRAM Crossbar CIM:

      V1    V2    V3    V4  (输入电压)
       │     │     │     │
    ┌──┼─────┼─────┼─────┼──┐
    │  ●─────●─────●─────●  │──► I1 = Σ(Vi×Gij)
    │  G11   G12   G13   G14│
    ├──●─────●─────●─────●──┤──► I2
    │  G21   G22   G23   G24│
    ├──●─────●─────●─────●──┤──► I3
    │  G31   G32   G33   G34│
    └───────────────────────┘
    
    ● = RRAM器件 (电导 G = 1/R 编码权重)
    
    计算原理 (基尔霍夫电流定律):
    I_j = Σ_i (V_i × G_ij)  ← 天然执行MAC!

优势:
  - 单步完成矩阵-向量乘法 (O(1) 时间复杂度!)
  - 极高的并行度 (阵列大小 = 并行度)
  - 能效: 50-200 TOPS/W (潜力)
  - 面积效率极高 (Crossbar密度)

挑战:
  - 器件变异大 → 计算精度受限
  - 耐久性有限 (~10⁶-10⁹ 次写入)
  - 写入能耗相对较高
  - 大阵列的IR-Drop和线电阻问题
```

## 14.6 FeRAM (铁电随机存取存储器)

### 14.6.1 FeRAM 原理与特性

```
FeRAM 特性:

结构: 铁电电容器 + 晶体管 (1T1C)

铁电材料: PZT (传统) / HfO₂ (新型, CMOS兼容)

特性:
  ├── 非易失性 (铁电极化保持)
  ├── 低电压操作 (~1.0V)
  ├── 快速写入 (~10ns, 远快于Flash)
  ├── 低功耗写入 (~100 fJ/bit)
  ├── 高耐久性 (>10¹² 次)
  └── CMOS工艺兼容 (HfO₂)

HfO₂ FeRAM 的低功耗优势:
  ├── 替代SRAM: 零漏电, 面积缩小50%
  ├── 替代Flash: 速度快1000×, 低电压
  └── 嵌入逻辑: 非易失逻辑 (NV-Logic)
```

## 14.8 非易失处理器 (Non-Volatile Processor)

### 14.8.1 间歇计算 (Intermittent Computing)

```
间歇计算场景:

能量收集设备的供电是间歇性的:

   电压
     ▲
     │    ╱╲    ╱╲    ╱╲    ╱╲
  Von│───╱──╲──╱──╲──╱──╲──╱──╲───
     │  ╱    ╲╱    ╲╱    ╲╱    ╲
  Voff│╱──────────────────────────
     └──────────────────────────► 时间
       活 休 活  休 活  休  活
       跃 眠 跃  眠 跃  眠  跃

传统处理器: 每次断电丢失全部状态 → 重头开始
非易失处理器: 断电前自动保存 → 来电恢复继续

非易失处理器架构:

┌────────────────────────────────────┐
│  NV-Processor                      │
│  ┌──────────────────────────────┐  │
│  │  处理器核心                    │  │
│  │  ├── NV 寄存器 (MRAM/FeRAM)  │  │
│  │  ├── NV Cache (MRAM)         │  │
│  │  ├── NV 流水线寄存器          │  │
│  │  └── 标准组合逻辑              │  │
│  └──────────────────────────────┘  │
│  ┌──────────────────────────────┐  │
│  │  电源管理                     │  │
│  │  ├── 电压检测: Vsupply < Vth │  │
│  │  ├── → 触发紧急保存            │  │
│  │  ├── → 保存 PC, SP, Flags     │  │
│  │  └── → 来电后自动恢复          │  │
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

### 14.9.2 功耗优化策略

```
CIM系统功耗优化:

1. 阵列级优化
   ├── 稀疏计算: 跳过零值输入 → 节省30-50%能耗
   ├── 精度自适应: 简单任务用低精度(INT4/Binary)
   └── 阵列分时: 不活跃Tile关断供电

2. ADC/DAC优化
   ├── ADC占CIM总功耗的30-50%
   ├── 使用SAR ADC而非Flash ADC
   ├── 降低ADC精度（4-6bit通常够用）
   └── 共享ADC减少数量

3. 数据流优化
   ├── 权重固定(Weight-Stationary): 权重预加载,输入流动
   ├── 输出固定(Output-Stationary): 累加在本地完成
   └── 减少中间结果搬运

4. 系统级优化
   ├── 早期退出: 简单输入提前得出结果
   ├── 动态精度: 根据输入难度调节计算精度
   └── 模型压缩: 剪枝/量化减少计算量
```

## 14.11 本章小结

| 主题 | 关键要点 |
|------|----------|
| 存储墙 | 数据搬运能耗 >> 计算能耗，是AI功耗瓶颈 |
