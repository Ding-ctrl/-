# 第1章 功耗基础知识

## 1.1 引言

随着半导体工艺持续演进至纳米级别，功耗已成为芯片设计中与性能、面积同等重要的核心指标。在移动设备、物联网（IoT）、数据中心等应用场景中，功耗直接决定了电池续航、散热需求和运营成本。理解功耗的基本原理与构成，是进行有效低功耗设计的基础。

## 1.2 功耗的基本分类

芯片功耗主要由三部分组成：**动态功耗**、**静态功耗**和**短路功耗**。

### 1.2.1 动态功耗 (Dynamic Power)

动态功耗是CMOS电路在逻辑翻转时产生的功耗，是传统工艺节点中的主要功耗来源。

**计算公式：**

```
P_dynamic = α × C_L × V_DD² × f
```

其中：
- **α (Activity Factor)**：信号翻转率，表示每个时钟周期内节点发生翻转的概率，典型值为0.1~0.3
- **C_L (Load Capacitance)**：负载电容，包括栅电容、线电容和扩散区电容
- **V_DD (Supply Voltage)**：供电电压，动态功耗与其平方成正比，是最关键的优化参数
- **f (Frequency)**：工作频率

**关键特征：**
- 与电压的平方成正比 → 降低电压是最有效的功耗优化手段
- 与频率成线性关系 → 降低频率可线性降低动态功耗
- 与翻转率成正比 → 减少不必要的信号翻转可降低功耗

**动态功耗优化方向：**

| 优化参数 | 方法 | 功耗改善效果 | 副作用 |
|----------|------|-------------|--------|
| V_DD | 电压缩放/多电压域 | 平方级改善 | 速度降低 |
| f | 频率调整/DVFS | 线性改善 | 性能降低 |
| α | 时钟门控/操作数隔离 | 线性改善 | 设计复杂度增加 |
| C_L | 工艺优化/布局优化 | 线性改善 | 受工艺限制 |

### 1.2.2 静态功耗 (Static/Leakage Power)

静态功耗是芯片在未进行逻辑翻转时（包括待机状态）消耗的功耗，主要由晶体管漏电流引起。

**主要漏电流来源：**

#### (1) 亚阈值漏电流 (Sub-threshold Leakage)

```
I_sub ∝ e^((V_GS - V_th) / (n × V_T))
```

- 当 V_GS < V_th 时，晶体管并非完全关断，仍有电流流过沟道
- 随着工艺缩小、阈值电压降低，亚阈值漏电流指数级增长
- 在先进工艺节点（7nm及以下）中，这是最主要的漏电来源
- 温度敏感：温度每升高10°C，漏电流约增加2倍

#### (2) 栅极漏电流 (Gate Leakage)

```
I_gate ∝ e^(-t_ox / α)
```

- 栅极氧化层极薄（<2nm）时，电子可隧穿氧化层形成漏电
- High-K金属栅极（HKMG）工艺可有效抑制此漏电
- 在28nm及以下工艺中通过HKMG基本得到控制

#### (3) 结漏电流 (Junction Leakage)

- PN结反向偏置时产生的反向饱和电流
- 在大多数应用中占比较小
- 随温度升高而增加

**静态功耗优化方向：**

| 优化方法 | 原理 | 适用场景 |
|----------|------|----------|
| 多阈值电压 (Multi-Vt) | 非关键路径使用高Vt单元 | RTL/综合阶段 |
| 电源关断 (Power Gating) | 关断空闲模块电源 | 架构/物理设计 |
| 衬底偏置 (Body Biasing) | 调节阈值电压 | 高级工艺节点 |
| 栈效应 (Stack Effect) | 串联晶体管降低漏电 | 电路级设计 |

### 1.2.3 短路功耗 (Short-Circuit Power)

```
P_sc = I_sc × V_DD × f
```

- 在CMOS反相器翻转瞬间，PMOS和NMOS同时导通，形成从VDD到GND的短路电流
- 短路功耗通常占总动态功耗的5%~15%
- 通过合理的信号翻转斜率匹配可以控制短路功耗
- 输入信号的上升/下降时间越长，短路窗口越大，短路功耗越高

## 1.3 功耗与工艺节点的关系

### 1.3.1 工艺演进对功耗的影响

| 工艺节点 | 动态功耗趋势 | 静态功耗趋势 | 主要特征 |
|----------|-------------|-------------|----------|
| 65nm | 较高 | 中等 | 传统平面MOSFET |
| 40/28nm | 中等 | 较高 | HKMG引入 |
| 16/14nm | 较低 | 中等 | FinFET引入，漏电改善 |
| 7/5nm | 低 | 中等偏低 | EUV光刻，更多FinFET鳍 |
| 3nm | 很低（单晶体管）| 需关注 | GAA/Nanosheet晶体管 |

### 1.3.2 Dennard缩放定律及其终结

**经典Dennard缩放定律（1974年）：**
- 晶体管尺寸缩小 κ 倍，电压缩小 κ 倍
- 功耗密度保持不变，芯片总功耗随面积缩小而降低

**Dennard缩放的终结（约2005年后）：**
- 电压无法继续按比例缩小（受阈值电压限制）
- 漏电流指数增长
- 功耗密度不再恒定，形成"功耗墙"
- 推动了多核架构和异构计算的发展

### 1.3.3 暗硅效应 (Dark Silicon)

在后Dennard时代，芯片上可同时活跃工作的晶体管比例受限于功耗预算：

- **定义**：在给定功耗预算下，芯片上不能同时被使用的晶体管区域
- **比例**：在先进节点中，暗硅比例可达50%~80%
- **应对策略**：
  - 异构架构（CPU + GPU + NPU + DSP）
  - 专用加速器设计
  - 动态电源管理（按需激活功能模块）

## 1.4 功耗分析与度量方法

### 1.4.1 功耗分析层次

```
系统级 (System Level)
  ├── 架构级 (Architecture Level)
  │     ├── RTL级 (RTL Level)
  │     │     ├── 门级 (Gate Level)
  │     │     │     └── 晶体管级 (Transistor Level)
```

| 分析层次 | 精度 | 速度 | 典型工具 | 应用阶段 |
|----------|------|------|----------|----------|
| 系统级 | ±30% | 最快 | PowerArtist, Docea | 架构探索 |
| RTL级 | ±15~20% | 快 | Synopsys PTPX (RTL), Joules | RTL设计 |
| 门级 | ±10% | 中等 | PrimeTime PX, Voltus | 综合后 |
| 版图级 | ±5% | 慢 | PrimeTime PX, Voltus (SPEF) | 后端设计 |
| 晶体管级 | 最高 | 最慢 | SPICE仿真 | 关键模块 |

### 1.4.2 功耗分析方法

#### (1) 基于仿真的功耗分析 (Simulation-based)

- 运行功能仿真，生成信号翻转活动（SAIF/VCD文件）
- 将翻转活动反标到网表进行功耗计算
- **优点**：精度较高，反映真实工作负载
- **缺点**：依赖仿真激励的代表性，耗时较长

典型流程：
```
RTL仿真 → 生成VCD/SAIF → 读入网表 → 反标活动 → 功耗报告
```

#### (2) 基于统计的功耗分析 (Statistical/Vectorless)

- 无需完整仿真激励，基于统计翻转概率估算
- 适合早期设计探索和大规模模块分析
- **优点**：速度快，不依赖激励
- **缺点**：精度较低，无法反映真实场景

#### (3) 硬件实测功耗分析

- 芯片流片后的实际功耗测量
- 使用电流探针、功率分析仪等设备
- 结合片上功耗监测电路（Power Monitor）
- 用于验证设计阶段的功耗估算

### 1.4.3 关键功耗指标

| 指标名称 | 英文 | 说明 |
|----------|------|------|
| 总功耗 | Total Power | 动态 + 静态 + 短路功耗之和 |
| 峰值功耗 | Peak Power | 最大瞬时功耗，影响供电网络设计 |
| 平均功耗 | Average Power | 一段时间内的平均功耗，影响散热与电池 |
| 待机功耗 | Standby Power | 系统空闲时的功耗，主要为漏电 |
| 功耗效率 | Power Efficiency | 每瓦特性能 (Performance/Watt) |
| 能量效率 | Energy Efficiency | 完成特定任务的总能量消耗 |
| 功耗密度 | Power Density | 单位面积功耗 (W/mm²)，影响散热 |

## 1.5 功耗预算与约束

### 1.5.1 功耗预算的制定

功耗预算需要综合考虑以下因素：

1. **应用场景约束**
   - 移动设备：电池容量 → 续航时间要求 → 平均功耗上限
   - 数据中心：机柜功耗预算 → 单芯片功耗上限
   - IoT设备：能量采集能力 → 极低功耗约束

2. **封装散热约束**
   - 封装的热阻 (θ_JA) 决定结温
   - 结温 = 环境温度 + 功耗 × 热阻
   - 最大结温通常为105°C~125°C

3. **供电约束**
   - 电源轨的最大供电能力
   - IR-drop约束（通常<5% VDD）
   - 电源完整性要求

### 1.5.2 功耗预算分配策略

```
总芯片功耗预算
├── CPU核心: 30~40%
├── GPU/加速器: 20~30%
├── 存储子系统: 15~20%
├── IO子系统: 10~15%
├── 时钟网络: 5~10%
└── 其他（PLL, 模拟等）: 5~10%
```

功耗预算分配原则：
- 性能关键模块分配更多功耗预算
- 非关键模块尽量压缩功耗
- 预留10~15%的功耗裕量（margin）
- 根据典型使用场景进行加权分配

## 1.6 功耗与性能、面积的权衡 (PPA Trade-off)

### 1.6.1 PPA三角关系

```
       Performance (性能)
          /\
         /  \
        /    \
       /  PPA \
      /________\
Power (功耗)    Area (面积)
```

- **性能 vs 功耗**：提高频率和电压可增加性能，但功耗显著上升
- **功耗 vs 面积**：低功耗技术（如多电压域、电源门控）增加面积开销
- **性能 vs 面积**：并行化提升性能但增加面积

### 1.6.2 常见PPA权衡决策

| 设计决策 | 性能影响 | 功耗影响 | 面积影响 |
|----------|----------|----------|----------|
| 提高供电电压 | ↑ 提升 | ↑↑ 显著增加 | — 不变 |
| 增加流水线级数 | ↑ 频率提升 | ↑ 增加 | ↑ 增加 |
| 使用高Vt单元 | ↓ 速度降低 | ↓ 漏电减少 | — 不变 |
| 添加时钟门控 | — 不变 | ↓ 显著降低 | ↑ 略增 |
| 电源关断 | ↓ 唤醒延迟 | ↓↓ 大幅降低 | ↑ 增加 |
| 并行化设计 | ↑↑ 吞吐量 | ↑ 总功耗增加 | ↑↑ 大幅增加 |

## 1.7 本章小结

本章介绍了低功耗芯片设计的基础知识，核心要点包括：

1. **功耗三要素**：动态功耗（翻转功耗）、静态功耗（漏电功耗）、短路功耗
2. **关键公式**：P_dynamic = α × C_L × V_DD² × f，电压是最敏感的优化参数
3. **工艺趋势**：Dennard缩放终结后，漏电功耗占比增大，暗硅效应凸显
4. **分析方法**：从系统级到晶体管级，不同层次有不同精度和速度的分析手段
5. **功耗预算**：需综合考虑应用场景、散热约束和供电能力
6. **PPA权衡**：低功耗设计始终需要在性能、功耗、面积之间找到最优平衡点
