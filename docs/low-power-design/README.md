## 适用对象

- 数字IC设计工程师
- SoC架构师
- 低功耗设计专项工程师
- ASIC/FPGA开发人员
- 芯片验证工程师

## 技术范围

- **工艺节点**: 覆盖28nm至3nm先进工艺
- **设计方法**: RTL级、门级、架构级低功耗技术
- **EDA工具**: Synopsys、Cadence、Mentor等主流工具链
- **标准规范**: IEEE 1801 (UPF)、CPF等低功耗标准

## 使用说明

建议按章节顺序阅读，每章内容相对独立但又有逻辑递进关系。第1-2章为基础理论与策略概览，第3-7章为具体技术深入，第8章为系统级集成总结。
