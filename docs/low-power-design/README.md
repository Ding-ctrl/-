## 适用对象

- 数字IC设计工程师
- SoC架构师
- 低功耗设计专项工程师
- ASIC/FPGA开发人员
- 芯片验证工程师

## 技术范围

- **工艺节点**: 覆盖28nm至3nm先进工艺
- **设计方法**: RTL级、门级、架构级低功耗技术
- **EDA工具**: Synopsys、Cadence、Mentor等主流工具链
- **标准规范**: IEEE 1801 (UPF)、CPF等低功耗标准
