# 第5章 低功耗存储器架构

## 5.1 引言

存储器子系统是现代SoC中面积占比最大的组成部分，通常占据芯片总面积的**50%~70%**，其功耗贡献同样不可忽视，占芯片总功耗的**25%~45%**。随着AI/ML、高清视频处理等数据密集型应用的兴起，片上存储需求持续增长，存储器功耗优化已成为低功耗SoC设计的关键挑战。

存储器的功耗来源与通用逻辑不同，涉及预充电、灵敏放大器、字线驱动、位线翻转等特有的电路操作。本章系统性地介绍片上存储器（主要是SRAM）的低功耗设计技术、存储器层次结构优化、存储器电源管理策略，以及新兴存储器技术在低功耗设计中的应用。

## 5.2 存储器功耗基础

### 5.2.1 SRAM功耗构成

SRAM是片上存储的主力，其功耗主要由以下部分构成：

```
SRAM 总功耗
├── 动态功耗 (Active Power)
│   ├── 读操作功耗
│   │   ├── 字线 (Wordline) 驱动          ← 15~20%
│   │   ├── 位线 (Bitline) 预充电与放电    ← 25~35%
│   │   ├── 灵敏放大器 (Sense Amplifier)   ← 10~15%
│   │   └── 输出驱动与解码器              ← 5~10%
│   └── 写操作功耗
│       ├── 字线驱动                      ← 15~20%
│       ├── 位线驱动（写入数据）           ← 20~30%
│       └── 存储单元翻转                  ← 5~10%
├── 静态功耗 (Leakage Power)
│   ├── 存储单元阵列漏电                  ← 主要贡献
│   ├── 外围电路漏电                      ← 次要
│   └── 位线/字线漏电                     ← 与阵列大小相关
└── 外围电路功耗
    ├── 地址解码器                        ← 5~8%
    ├── 时钟分配                          ← 3~5%
    └── 控制逻辑                          ← 2~3%
```

### 5.2.2 SRAM功耗模型

**读操作功耗：**

```
P_read = (C_WL × N_cols + C_BL × N_rows × ΔV_BL + C_SA + C_out) × V_DD² × f_access

其中：
- C_WL: 字线电容（与列数成正比）
- C_BL: 位线电容（与行数成正比）
- ΔV_BL: 位线摆幅（通常50~200mV）
- C_SA: 灵敏放大器输入电容
- C_out: 输出驱动电容
```

**写操作功耗：**

```
P_write = (C_WL × N_cols + C_BL_full_swing × N_bits_toggled + C_cell) × V_DD² × f_access

写操作位线通常需要全摆幅驱动（0到VDD），功耗高于读操作
```

**静态功耗：**

```
P_leakage = N_cells × I_leak_per_cell × V_DD + I_leak_peripheral × V_DD

先进工艺（7nm及以下）中，SRAM单元漏电可达：
- 标准Vt单元: ~10nA/cell
- 高Vt单元: ~1nA/cell
```

### 5.2.3 存储器功耗与面积的关系

| 存储器容量 | 典型面积(7nm) | 动态功耗(每次访问) | 静态功耗 | 访问延迟 |
|-----------|-------------|------------------|---------|---------|
| 4KB | ~0.003mm² | ~0.5pJ/bit | ~0.01mW | <0.5ns |
| 32KB | ~0.02mm² | ~1.0pJ/bit | ~0.08mW | ~0.5ns |
| 256KB | ~0.15mm² | ~2.0pJ/bit | ~0.6mW | ~0.8ns |
| 1MB | ~0.5mm² | ~3.5pJ/bit | ~2.0mW | ~1.2ns |
| 4MB | ~2.0mm² | ~5.0pJ/bit | ~8.0mW | ~1.8ns |
| 16MB | ~8.0mm² | ~8.0pJ/bit | ~30mW | ~2.5ns |

**关键趋势：** 存储器容量增大时，每比特访问能耗和漏电都显著增加，这是因为更大的阵列意味着更长的位线/字线和更多的漏电晶体管。

## 5.3 SRAM低功耗电路技术

### 5.3.1 位线功耗优化

位线充放电是SRAM读操作的主要功耗来源。

#### (1) 分层位线架构 (Hierarchical Bitline)

```
传统单层位线：                    分层位线：

BL (全长)                        GBL (全局位线, 金属层)
│                                │
├── Cell                         ├── [MUX]── LBL (局部位线, 短)
├── Cell                         │           ├── Cell
├── Cell                         │           ├── Cell
├── Cell                         │           └── Cell
├── Cell                         │
├── Cell                         ├── [MUX]── LBL
...                              │           ├── Cell
├── Cell                         │           ├── Cell
│                                │           └── Cell
SA (灵敏放大器)                   SA

位线长度减少 → 电容降低 → 功耗降低
典型改善：位线功耗降低40~60%
```

**工作原理：**
- 将长位线分割成多段短的局部位线(LBL)
- 每段通过选择开关连接到全局位线(GBL)
- 每次读操作仅激活一段LBL，减少位线电容
- 同时改善读速度（更短位线，更快信号发展）

#### (2) 位线摆幅限制

```
全摆幅读取：                      限制摆幅读取：
BL  VDD ──┐                     BL  VDD ──┐
           │                              │
           │    ΔV = VDD                  │  ΔV = 50~200mV
           │                              │
    GND ───┘                     GND      └── (提前触发SA)

功耗 ∝ C × ΔV²
限制摆幅可将读功耗降低 (ΔV_small/VDD)² 倍
例如：ΔV=100mV, VDD=0.8V → 功耗降低至 (0.1/0.8)² ≈ 1.6% 
```

**实现方法：**
- 使用高灵敏度的灵敏放大器，在小摆幅时即可检测
- 通过偏置电路控制位线放电时间
- 需要仔细平衡灵敏度与噪声裕量

#### (3) 位线预充电优化

| 技术 | 原理 | 功耗改善 | 复杂度 |
|------|------|---------|--------|
| 半摆幅预充(VDD/2) | 预充到VDD/2而非VDD | ~50% | 中等 |
| 部分预充 | 仅预充被访问的位线对 | ~30% | 低 |
| 自适应预充 | 根据访问模式调整预充 | ~20% | 高 |
| 延迟预充 | 减少不必要的预充周期 | ~15% | 低 |

### 5.3.2 字线功耗优化

#### (1) 分段字线 (Divided Wordline)

```
传统全长字线：
WL ──────────────────────────────── (高电容, 高功耗)
     Cell Cell Cell ... Cell Cell

分段字线：
MWL (主字线) ────────────────────── (少量负载)
              │         │
           [AND]     [AND]
              │         │
SWL0 ─────────      SWL1 ─────── (短, 低电容)
  Cell Cell Cell      Cell Cell Cell

功耗改善：字线功耗降低50~70%
```

#### (2) 分块激活 (Block Activation)

将大型SRAM分成多个独立块，每次仅激活被访问的块：

```
┌──────────┬──────────┬──────────┬──────────┐
│ Block 0  │ Block 1  │ Block 2  │ Block 3  │
│ (活跃)   │ (睡眠)   │ (睡眠)   │ (睡眠)   │
│ 读/写中   │          │          │          │
└──────────┴──────────┴──────────┴──────────┘

地址解码 → 仅Block 0的字线、位线、SA被激活
其他Block保持预充电状态或低功耗模式
```

**分块策略的功耗影响：**

| 分块数量 | 每块容量(1MB总) | 动态功耗 | 漏电(活跃块) | 面积开销 |
|---------|---------------|---------|-------------|---------|
| 1块 | 1MB | 100% (基准) | 100% | 0% |
| 4块 | 256KB | ~40% | ~25% | ~3% |
| 8块 | 128KB | ~25% | ~12.5% | ~6% |
| 16块 | 64KB | ~18% | ~6.25% | ~10% |

### 5.3.3 存储单元优化

#### (1) 多阈值电压SRAM单元

```
标准6T SRAM单元使用不同Vt组合：

Pull-up (PU): PMOS    → 使用标准Vt (保证写入能力)
Pull-down (PD): NMOS  → 使用低Vt (保证读稳定性)
Access (AX): NMOS     → 使用高Vt (降低漏电)

效果：漏电降低40~60%，同时保持足够的稳定性裕量
```

#### (2) 8T/10T SRAM单元

在需要超低电压运行的场景（如近阈值计算），标准6T单元的读稳定性不足：

| 单元类型 | 晶体管数 | 面积(vs 6T) | 最低工作电压 | 漏电 | 应用场景 |
|---------|---------|------------|------------|------|---------|
| 6T | 6 | 1.0× | 0.6~0.7V | 基准 | 通用缓存 |
| 8T | 8 | 1.3~1.5× | 0.3~0.4V | +20% | 近阈值运算 |
| 10T | 10 | 1.6~1.8× | 0.25~0.35V | +30% | 超低压IoT |

**8T单元的优势：**
- 分离读端口和写端口，读操作不干扰存储节点
- 允许在更低电压下可靠读取
- 支持单端读取，进一步降低位线功耗

#### (3) Schmitt-Trigger SRAM单元

```
通过在交叉耦合反相器中加入施密特触发器结构：
- 增强噪声裕量（提高20~40%）
- 允许更低的工作电压
- 面积开销约10~15%
- 特别适合高可靠性、低电压应用
```

### 5.3.4 灵敏放大器优化

| SA类型 | 功耗 | 速度 | 灵敏度 | 适用场景 |
|--------|------|------|--------|---------|
| 锁存型(Latch) | 低 | 快 | 中等 | 高速缓存 |
| 电流镜型 | 中等 | 中等 | 高 | 低摆幅位线 |
| 差分电压型 | 较高 | 快 | 高 | 通用 |
| 动态偏移补偿型 | 低 | 中等 | 很高 | 低电压SRAM |

**低功耗灵敏放大器设计要点：**
- 使用自时序(Self-timed)机制，在检测到足够信号差时立即触发
- 减少SA激活时间窗口
- 采用局部SA + 全局SA两级结构，降低全局位线驱动需求

## 5.4 存储器电源管理

### 5.4.1 SRAM电源状态

与逻辑电路类似，SRAM也支持多种电源状态：

```
┌────────────┐    ┌────────────┐    ┌────────────┐    ┌────────────┐
│   Active   │───▶│   Standby  │───▶│  Retention │───▶│  Shutdown  │
│  (正常读写) │◀───│  (保持供电)  │◀───│  (低压保持) │◀───│  (完全关断) │
└────────────┘    └────────────┘    └────────────┘    └────────────┘

功耗:  100%         30~50%          5~15%            <1%
数据:  读写正常      数据保持         数据保持          数据丢失
延迟:  正常访问      快速恢复(~ns)   需恢复(~100ns)    需重新加载
```

### 5.4.2 SRAM低功耗模式实现

#### (1) Standby模式 — 外围电路关断

```
Active模式:                        Standby模式:
┌──────────────────────┐          ┌──────────────────────┐
│ 解码器: ON           │          │ 解码器: OFF (门控)     │
│ SA: ON               │          │ SA: OFF              │
│ 预充电路: ON          │          │ 预充电路: OFF         │
│ 写驱动器: ON          │          │ 写驱动器: OFF         │
│ 存储阵列: VDD        │          │ 存储阵列: VDD (保持)  │
│ 时钟: ON             │          │ 时钟: OFF (门控)      │
└──────────────────────┘          └──────────────────────┘
```

**功耗节省：** 关断外围电路可降低30~50%的总SRAM功耗

#### (2) Retention模式 — 降低阵列电压

```
正常供电:                          Retention供电:

    VDD (0.8V)                        VDD_RET (0.3~0.5V)
     │                                 │
  ┌──┴──┐                           ┌──┴──┐
  │Cell │  正常读写                   │Cell │  仅保持数据
  │Array│  全速度                     │Array│  不可读写
  └──┬──┘                           └──┬──┘
     │                                 │
    GND                               GND

漏电降低：由于 I_leak ∝ V_DD，降压可降低漏电60~80%
注意：需要确保保持电压高于数据保持最低电压(Data Retention Voltage, DRV)
```

**数据保持电压(DRV)与工艺的关系：**

| 工艺节点 | 典型DRV | 标准VDD | DRV/VDD比 |
|---------|---------|---------|-----------|
| 28nm | 0.35V | 0.9V | 39% |
| 14nm | 0.30V | 0.8V | 38% |
| 7nm | 0.28V | 0.75V | 37% |
| 5nm | 0.25V | 0.70V | 36% |
| 3nm | 0.22V | 0.65V | 34% |

#### (3) Shutdown模式 — 完全关断

- 存储器完全断电，数据丢失
- 漏电几乎为零
- 恢复时需要重新加载数据
- 适用于长时间不使用的存储器块

#### (4) Light Sleep与Deep Sleep

许多SRAM编译器(Memory Compiler)提供精细的低功耗模式控制：

| 模式 | 控制信号 | 阵列电压 | 外围电路 | 漏电降低 | 唤醒延迟 |
|------|---------|---------|---------|---------|---------|
| Active | — | VDD | ON | 0% | 0 |
| Light Sleep | LS=1 | VDD | 部分OFF | 20~40% | 1~2 cycle |
| Deep Sleep | DS=1 | VDD_RET | OFF | 60~80% | 5~20 cycle |
| Shutdown | SD=1 | OFF | OFF | ~99% | 需重加载 |

### 5.4.3 存储器电源岛设计

大容量SRAM通常需要独立的电源管理：

```
┌─────────────────────────────────────────┐
│              SoC 电源管理                 │
│                                          │
│  ┌──────────┐  ┌──────────┐             │
│  │ L1 Cache │  │ L1 Cache │  ← 跟随CPU   │
│  │ (32KB)   │  │ (32KB)   │    电源状态   │
│  └──────────┘  └──────────┘             │
│                                          │
│  ┌─────────────────────────┐            │
│  │      L2 Cache (512KB)    │ ← 独立电源域 │
│  │  ┌──────┬──────┬──────┐ │   可分块管理 │
│  │  │Way 0 │Way 1 │Way 2 │ │            │
│  │  │(ON)  │(RET) │(OFF) │ │            │
│  │  └──────┴──────┴──────┘ │            │
│  └─────────────────────────┘            │
│                                          │
│  ┌─────────────────────────┐            │
│  │      L3 Cache (4MB)      │ ← 多块独立  │
│  │  ┌────┬────┬────┬────┐  │   电源控制  │
│  │  │Blk0│Blk1│Blk2│Blk3│  │            │
│  │  │ON  │ON  │OFF │OFF │  │            │
│  │  └────┴────┴────┴────┘  │            │
│  └─────────────────────────┘            │
└─────────────────────────────────────────┘
```

**分块电源管理策略：**
- 根据工作负载动态调整活跃块数量
- 访问频率低的块进入Deep Sleep
- 长时间未访问的块完全关断
- Cache Way可独立控制，实现按需分配

## 5.5 Cache低功耗架构

### 5.5.1 Cache功耗特征

Cache是SoC中最大的片上存储消费者，其功耗优化对系统整体功耗至关重要。

**Cache访问功耗分解：**

```
Cache访问总功耗
├── Tag Array访问          ← 20~30%
│   ├── Tag读取
│   ├── Tag比较
│   └── 有效位/脏位检查
├── Data Array访问         ← 50~60%
│   ├── 数据读取(所有Way)
│   └── MUX选择命中Way
├── 替换逻辑               ← 5~10%
│   └── LRU/PLRU更新
└── 控制逻辑与总线         ← 10~15%
    └── 请求仲裁、流水线控制
```

### 5.5.2 Cache低功耗技术

#### (1) Way预测 (Way Prediction)

```
传统并行访问（高功耗）：              Way预测（低功耗）：

同时读取所有Way:                     仅读取预测的Way:
┌──────┐                            ┌──────┐
│Way 0 │──read──┐                   │Way 0 │ (不读取)
├──────┤        │                   ├──────┤
│Way 1 │──read──┼── MUX → Hit?     │Way 1 │──read──→ Hit? ✓
├──────┤        │                   ├──────┤
│Way 2 │──read──┤                   │Way 2 │ (不读取)
├──────┤        │                   ├──────┤
│Way 3 │──read──┘                   │Way 3 │ (不读取)
└──────┘                            └──────┘
                                    预测命中率>90%时,
读取4个Way的功耗                     功耗仅为传统方案的25~30%
```

**预测错误时：** 重新读取正确Way，增加1个周期延迟（但概率<10%）

#### (2) 串行Tag-Data访问

```
并行访问（高性能，高功耗）：
Cycle 1: [Tag读取 + Data读取(所有Way)] → MUX选择
延迟: 1 cycle, 功耗: 高

串行访问（低功耗，多一拍延迟）：
Cycle 1: [Tag读取] → 确定命中Way
Cycle 2: [仅Data读取(命中Way)]
延迟: 2 cycles, 功耗: 低（仅读一个Way）
```

| 方案 | 延迟 | 功耗 | 适用场景 |
|------|------|------|---------|
| 并行Tag+Data | 1 cycle | 高 | L1 Cache (性能优先) |
| 串行Tag→Data | 2 cycles | 低 | L2/L3 Cache (功耗优先) |
| Way预测+并行 | 1 cycle (命中) | 中 | L1 Cache (平衡) |

#### (3) 动态Cache容量调整 (Dynamic Cache Resizing)

根据工作负载动态调整活跃Cache大小：

```
高负载场景：所有Way活跃
┌────┬────┬────┬────┐
│Way0│Way1│Way2│Way3│  4-Way, 全容量
│ ON │ ON │ ON │ ON │  命中率: 95%
└────┴────┴────┴────┘

低负载场景：部分Way关断
┌────┬────┬────┬────┐
│Way0│Way1│Way2│Way3│  2-Way, 半容量
│ ON │ ON │OFF │OFF │  命中率: 88% (足够)
└────┴────┴────┴────┘  漏电降低50%
```

**调整策略：**
- 监测Cache命中率
- 命中率高于阈值时尝试减少Way数
- 命中率下降低于阈值时增加Way数
- 关断的Way数据需先写回（如果是脏数据）

#### (4) 数据压缩缓存 (Compressed Cache)

通过压缩存储数据，用更少的SRAM容量存储相同的数据量：

| 压缩技术 | 压缩比 | 解压延迟 | 适用数据 |
|---------|--------|---------|---------|
| BDI (Base-Delta-Immediate) | 1.5~2× | 1 cycle | 整数数据 |
| FPC (Frequent Pattern) | 1.5~2× | 1 cycle | 通用数据 |
| DISH (Dictionary Sharing) | 2~3× | 2 cycles | 重复模式多的数据 |

**功耗收益：** 等效容量不变时，物理SRAM可缩小→减少漏电；或物理容量不变，提高命中率→减少DRAM访问

### 5.5.3 Scratchpad Memory (SPM)

对于确定性强的应用（如DSP、AI加速器），SPM比Cache更节能：

| 特性 | Cache | Scratchpad Memory |
|------|-------|-------------------|
| 地址映射 | 硬件自动 (Tag比较) | 软件显式管理 |
| Tag开销 | 有 (面积+功耗) | 无 |
| 替换策略 | 硬件LRU等 | 无需 |
| 每次访问功耗 | 高 (Tag+全Way读取) | 低 (直接寻址) |
| 编程复杂度 | 低 (透明) | 高 (需DMA管理) |
| 适用场景 | 通用处理器 | DSP、AI加速器 |

**功耗对比：** 同等容量下，SPM的每次访问功耗仅为Cache的**30~50%**

## 5.6 DRAM低功耗技术

### 5.6.1 DRAM功耗构成

```
DRAM功耗
├── 激活(Activate)功耗       ← 25~35%
│   └── 行地址选通、感应放大
├── 读写(Read/Write)功耗     ← 20~30%
│   └── 列选通、数据传输
├── 刷新(Refresh)功耗        ← 15~25%
│   └── 定期刷新保持数据
├── 待机(Standby)功耗        ← 10~15%
│   └── 背景漏电
└── IO驱动功耗               ← 10~15%
    └── 高速数据接口
```

### 5.6.2 LPDDR低功耗特性

移动端使用的LPDDR标准专为低功耗设计：

| 特性 | LPDDR4X | LPDDR5 | LPDDR5X |
|------|---------|--------|---------|
| IO电压 | 0.6V | 0.5V | 0.5V |
| 核心电压 | 1.1V | 1.05V | 1.0V |
| 频率范围 | 1600~4266MHz | 2133~6400MHz | 2133~8533MHz |
| Bank数量 | 8 per channel | 16 per channel | 16 per channel |
| 低功耗模式 | SR, DSPD | SR, DSPD, WCK停止 | SR, DSPD, WCK停止 |
| 功耗改善(vs前代) | 基准 | -20~30% | -10~20% |

**LPDDR低功耗模式：**

| 模式 | 说明 | 功耗 | 退出延迟 |
|------|------|------|---------|
| Active | 正常读写 | 100% | 0 |
| Active Standby | 行打开但无读写 | 30~40% | ~ns |
| Precharge Standby | 所有行关闭 | 15~25% | ~ns |
| Self-Refresh (SR) | 自主刷新,时钟停 | 3~8% | ~μs |
| Deep Sleep (DSPD) | 最低功耗保持 | 1~3% | ~10μs |
| Power Down | 数据丢失 | <0.5% | ~ms |

### 5.6.3 DRAM刷新优化

刷新是DRAM独有的功耗负担。温度越高，刷新频率越高，功耗越大。

**智能刷新策略：**

| 策略 | 原理 | 功耗改善 | 实现复杂度 |
|------|------|---------|-----------|
| 温度自适应刷新 | 低温时降低刷新频率 | 20~50% | 低 |
| 部分阵列刷新(PASR) | 仅刷新有数据的Bank/行 | 30~60% | 中 |
| 按需刷新 | 跟踪已刷新行,仅刷新即将失效的行 | 40~70% | 高 |
| 行地址自刷新 | 让DRAM自主优化刷新顺序 | 10~20% | 内置于DRAM |

**温度与刷新周期：**

```
刷新间隔 (tREFI):
- 85°C以下: 7.8μs (标准)
- 85°C~95°C: 3.9μs (2×频率)
- 95°C以上: 1.95μs (4×频率)

→ 温度管理直接影响DRAM刷新功耗
```

## 5.7 新兴存储器技术

### 5.7.1 非易失性存储器(NVM)概览

新兴NVM技术有望从根本上改变存储器功耗格局：

| 技术 | 读延迟 | 写延迟 | 读能耗 | 写能耗 | 耐久性 | 密度 |
|------|--------|--------|--------|--------|--------|------|
| SRAM | <1ns | <1ns | ~pJ | ~pJ | ∞ | 低 |
| DRAM | ~10ns | ~10ns | ~10pJ | ~10pJ | ∞ | 中 |
| STT-MRAM | ~3ns | ~10ns | ~0.1pJ | ~10pJ | 10⁹~10¹² | 中 |
| ReRAM | ~10ns | ~50ns | ~0.1pJ | ~1pJ | 10⁶~10⁹ | 高 |
| PCM | ~50ns | ~100ns | ~1pJ | ~10pJ | 10⁶~10⁹ | 高 |
| FeRAM | ~10ns | ~10ns | ~pJ | ~pJ | 10¹⁰~10¹⁴ | 中 |

### 5.7.2 STT-MRAM在低功耗设计中的应用

STT-MRAM（自旋转矩磁性随机存取存储器）是最接近商用的NVM替代方案：

**低功耗优势：**

```
SRAM vs STT-MRAM (作为LLC/L2替代):

SRAM:
├── 待机漏电: 高 (6T单元持续漏电)
├── 读功耗: 低
├── 写功耗: 低
└── 面积: 大 (6T/8T)

STT-MRAM:
├── 待机漏电: 极低 (非易失,近零漏电)  ★
├── 读功耗: 低 (与SRAM相当)
├── 写功耗: 较高 (磁化翻转)           ✗
└── 面积: 小 (~1T1MTJ)               ★
```

**适用场景评估：**

| 场景 | SRAM优势 | STT-MRAM优势 | 推荐选择 |
|------|---------|-------------|---------|
| L1 Cache | 高速写入 | — | SRAM |
| L2 Cache | 高速读写 | 低漏电, 小面积 | 混合/视场景 |
| L3/LLC | — | 低漏电, 高密度 | STT-MRAM |
| 配置寄存器 | — | 非易失, 即时启动 | STT-MRAM |
| IoT (低占空比) | — | 零待机漏电 | STT-MRAM |

### 5.7.3 存算一体(Processing-in-Memory, PIM)

存算一体架构将计算单元嵌入存储器中，消除数据搬运的能量开销：

```
传统架构 (冯·诺依曼):
┌──────────┐      数据搬运      ┌──────────┐
│ 处理单元  │ ←──────────────→ │  存储器   │
│  (CPU)   │   功耗主要消耗     │ (DRAM)   │
└──────────┘   在数据搬运上     └──────────┘

存算一体架构:
┌─────────────────────────────┐
│        存储器阵列             │
│   ┌────┐┌────┐┌────┐        │
│   │计算││计算││计算│  计算   │
│   │单元││单元││单元│  就在   │
│   └────┘└────┘└────┘  数据   │
│                       旁边   │
└─────────────────────────────┘
```

**功耗收益：**
- 数据搬运能耗 >> 计算能耗（通常10~100倍）
- PIM消除了大量数据搬运
- 对AI推理等数据密集型任务，功耗可降低**5~10倍**

## 5.8 存储器层次的系统级功耗优化

### 5.8.1 存储器层次结构优化

```
┌─────────────────────────────────────────┐
│              访问频率 / 容量 / 功耗       │
│                                          │
│  ┌─────┐  频率最高, 容量最小, 每次访问功耗最低│
│  │ Reg │  寄存器堆                        │
│  └──┬──┘                                 │
│  ┌──▼──┐                                 │
│  │ L1  │  32~64KB, ~0.5ns, ~0.5pJ/bit   │
│  └──┬──┘                                 │
│  ┌──▼──┐                                 │
│  │ L2  │  256KB~1MB, ~2ns, ~2pJ/bit     │
│  └──┬──┘                                 │
│  ┌──▼──┐                                 │
│  │ L3  │  2~16MB, ~5ns, ~5pJ/bit        │
│  └──┬──┘                                 │
│  ┌──▼──┐                                 │
│  │DRAM │  GB级, ~50ns, ~50pJ/bit         │
│  └──┬──┘                                 │
│  ┌──▼──┐  频率最低, 容量最大, 每次访问功耗最高│
│  │Flash│  GB~TB级, ~μs, ~nJ/bit          │
│  └─────┘                                 │
└─────────────────────────────────────────┘
```

**系统级能量优化原则：**
- 最大化片上命中率，减少对外部存储的访问
- 每次DRAM访问的能量约为L1访问的**100倍**
- 合理配置各级缓存大小，在命中率和漏电间找平衡
- 使用预取(Prefetch)提前加载数据到高层缓存

### 5.8.2 数据局部性优化

从软硬件协同角度优化数据访问模式：

| 优化技术 | 层次 | 原理 | 功耗改善 |
|---------|------|------|---------|
| 循环分块(Tiling) | 软件 | 数据适配Cache大小 | 减少30~50% DRAM访问 |
| 数据布局优化 | 软件 | 结构体拆分/合并 | 提高Cache行利用率 |
| 硬件预取 | 硬件 | 提前加载即将访问的数据 | 减少停顿和带宽浪费 |
| 数据复用缓冲 | 硬件 | 专用缓冲重用中间数据 | 大幅减少外部访问 |

### 5.8.3 带宽与功耗的权衡

```
存储器带宽 vs 功耗:

带宽翻倍的功耗代价：
- 更宽的数据通路: 面积和功耗线性增加
- 更高的频率: 功耗超线性增加(含时钟树)
- 更多Bank/通道: 面积和漏电增加

最优策略：
1. 优先通过提高数据复用减少带宽需求
2. 使用压缩减少实际传输数据量
3. 在满足带宽需求的前提下使用最低频率
4. 根据负载动态调整带宽(通道开/关)
```

## 5.9 实际案例

### 5.9.1 移动SoC存储子系统低功耗设计

**目标：** 旗舰手机SoC存储子系统，功耗预算800mW

**架构设计：**

| 存储层级 | 配置 | 低功耗技术 | 功耗贡献 |
|---------|------|-----------|---------|
| L1 I-Cache | 64KB, 4-Way | Way预测, 分块激活 | 80mW |
| L1 D-Cache | 64KB, 4-Way | 串行Tag-Data | 100mW |
| L2 Cache | 512KB/核 | 动态容量调整, Deep Sleep | 150mW |
| L3 Cache | 4MB共享 | 分块电源管理(8块) | 200mW |
| DRAM控制器 | LPDDR5×2 | PASR, 温度自适应刷新 | 270mW |

**各场景功耗：**

| 场景 | 全速 | 日常 | 待机 | 深睡 |
|------|------|------|------|------|
| L1 Cache | 180mW | 80mW | 5mW | 0.5mW |
| L2 Cache | 150mW | 60mW | 8mW (Retention) | 0mW (Off) |
| L3 Cache | 200mW | 80mW | 15mW (部分Ret) | 0mW (Off) |
| DRAM | 270mW | 100mW | 20mW (Self-Ref) | 5mW (DSPD) |
| **总计** | **800mW** | **320mW** | **48mW** | **5.5mW** |

### 5.9.2 AI加速器存储架构优化

**目标：** 边缘AI推理芯片，存储功耗预算200mW

**关键策略：**
- 使用SPM替代Cache，消除Tag查找开销
- 大容量片上SRAM（2MB）覆盖典型模型权重
- 权重数据采用INT8/INT4量化，减少存储量和带宽
- DMA驱动的双缓冲机制，重叠计算和数据搬运
- 存储器分块管理，未使用的块进入Shutdown

**功耗分解：**

```
AI加速器存储功耗 (200mW预算):
├── 权重SPM (1MB): 60mW
│   └── 分8块,按需激活,INT4压缩
├── 激活值SPM (512KB): 40mW
│   └── 双缓冲,ping-pong操作
├── 输出缓冲 (256KB): 25mW
├── DMA引擎: 15mW
├── 外部DRAM访问: 50mW
│   └── 预取+压缩,减少70%外部访问
└── 控制逻辑: 10mW
```

## 5.10 本章小结

本章系统性介绍了低功耗存储器架构设计，核心要点包括：

1. **SRAM功耗构成**：位线充放电是主要功耗来源，分层位线和摆幅限制可显著降低
2. **电路级优化**：分段字线、分块激活、多Vt单元和8T/10T单元提供多维度优化手段
3. **SRAM电源管理**：Light Sleep/Deep Sleep/Shutdown多级模式平衡漏电和唤醒延迟
4. **Cache低功耗**：Way预测、串行Tag-Data、动态容量调整是Cache功耗优化的关键技术
5. **SPM优势**：在确定性强的应用中，SPM比Cache每次访问功耗低30~50%
6. **DRAM优化**：LPDDR标准、智能刷新策略和温度管理是片外存储功耗优化的核心
7. **新兴NVM**：STT-MRAM等NVM技术通过近零待机漏电为低功耗存储提供新方向
8. **存算一体**：PIM架构从根本上减少数据搬运能量，适合数据密集型应用
