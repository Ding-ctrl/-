# 第4章 通信与网络子系统

## 4.1 子系统总览

座舱SoC的通信与网络子系统可分为**车内总线通信**和**车外无线通信**两大类：

```
通信与网络子系统全景

  ┌───────────────────────────────────────────────────────┐
  │                   座舱SoC                              │
  │                                                       │
  │  车内有线总线                  车外无线通信              │
  │  ├── CAN-FD（×4路）            ├── Wi-Fi 6E（802.11ax）│
  │  ├── LIN（×4路）               ├── Bluetooth 5.3       │
  │  ├── FlexRay（部分车型）        ├── GNSS（GPS/北斗）     │
  │  ├── 车载以太网（100/1000BASE-T1）└── 5G/LTE（外挂基带）│
  │  ├── MOST（部分豪华车型）                                │
  │  ├── A2B（汽车音频总线）                                 │
  │  └── USB（Type-C × 2）                                 │
  └───────────────────────────────────────────────────────┘
```

## 4.2 车内有线总线

### 4.2.1 CAN-FD（Controller Area Network Flexible Data Rate）

**CAN-FD** 是传统CAN总线的升级版，是目前汽车内部最主流的控制总线：

| 参数 | CAN 2.0 | CAN-FD |
|------|---------|--------|
| 仲裁段速率 | 最高 1 Mbps | 最高 1 Mbps |
| 数据段速率 | 最高 1 Mbps | 最高 **8 Mbps** |
| 帧数据长度 | 最大 8 字节 | 最大 **64 字节** |
| CRC | 15bit | 17/21bit（增强） |
| 典型应用 | 全部ECU | 座舱域控与其他域控通信 |

```
座舱SoC CAN-FD配置（典型4路）

  CAN-FD 0：车身总线（车门/车窗/灯光控制信号接收）
  CAN-FD 1：动力总线（车速/转速/档位/SOC信号接收）
  CAN-FD 2：底盘总线（ABS/ESP/转向信号接收，ASIL-B通路）
  CAN-FD 3：诊断总线（OBD-II诊断，ISO 14229/UDS协议）

⚠️ 安全相关的CAN信号（车速、制动等）通过硬件安全过滤器
   直接路由到安全岛MCU，不经过Android/Linux主处理器
```

### 4.2.2 车载以太网（Automotive Ethernet）

车载以太网是座舱域内部高速通信的主干网络：

| 标准 | 速率 | 线缆 | 应用场景 |
|------|------|------|---------|
| 100BASE-T1（IEEE 802.3bw） | 100 Mbps | 单对非屏蔽双绞线 | 低速ECU互联 |
| 1000BASE-T1（IEEE 802.3bp） | 1 Gbps | 单对非屏蔽双绞线 | 域控之间主干 |
| 10GBASE-T1（IEEE 802.3ch） | 10 Gbps | 单对屏蔽线 | Zonal架构中央计算节点 |
| 2.5GBASE-T1 | 2.5 Gbps | 单对 | 摄像头高速视频流 |

```
车载以太网在座舱中的应用

  ┌──────────────────────────────────────────┐
  │           座舱域控制器（含座舱SoC）         │
  │                                          │
  │  1000BASE-T1 × 2────►车身域控（BCM）      │
  │  1000BASE-T1 × 1────►ADAS域控            │
  │  100BASE-T1  × 4────►T-BOX（车联网盒）   │
  │  100BASE-T1  × 2────►摄像头（部分方案）   │
  └──────────────────────────────────────────┘

以太网协议栈：
  ├── AUTOSAR SOME/IP：服务化通信（SOA架构）
  ├── DoIP（ISO 13400）：以太网OBD诊断
  ├── AVB/TSN（802.1AS/Qav/Qbv）：音视频同步传输
  └── SecOC（Secure On-board Communication）：消息认证
```

### 4.2.3 LIN总线（Local Interconnect Network）

**LIN** 为低速、低成本辅助总线（20 kbps），主要用于连接低速传感器/执行器：

```
LIN总线典型节点
  ├── 座椅记忆/调节控制器
  ├── 雨刮传感器
  ├── 方向盘按键模块
  ├── 氛围灯控制器
  └── 空调出风口位置传感器
```

### 4.2.4 USB接口

| 接口类型 | 版本 | 带宽 | 用途 |
|---------|------|------|------|
| USB Type-C | USB 3.2 Gen2 | 10 Gbps | CarPlay/Android Auto有线连接 |
| USB Type-A | USB 2.0 | 480 Mbps | 充电 + 大容量存储 |
| USB Type-C | USB PD 3.1 | 支持45W快充 | 手机快充 |

## 4.3 无线通信模块

### 4.3.1 Wi-Fi 6E（802.11ax）

| 参数 | 规格 |
|------|------|
| 频段 | 2.4GHz + 5GHz + **6GHz** |
| 最高速率 | 2×2 MIMO：~2.4 Gbps（6GHz频段） |
| 信道宽度 | 最大 160 MHz |
| 多用户支持 | MU-MIMO + OFDMA |
| 典型场景 | CarPlay/Android Auto无线、OTA热点、车内Wi-Fi |

```
Wi-Fi应用场景优先级

  优先级1（高）：无线CarPlay / Android Auto（实时性要求高）
  优先级2（中）：OTA软件升级下载（大带宽，低延迟要求）
  优先级3（中）：乘客上网（流量共享）
  优先级4（低）：后台地图/内容预下载

  Wi-Fi 6E优势：
  └── 6GHz频段：无干扰，低延迟，CarPlay体验媲美有线
```

### 4.3.2 蓝牙5.3（Bluetooth 5.3 / BLE）

| 参数 | 规格 |
|------|------|
| 版本 | 5.3（向下兼容5.x/4.x） |
| 经典蓝牙 | A2DP（音乐）、HFP（免提电话）、PBAP（联系人同步） |
| BLE | 低功耗数字钥匙（UWB+BLE）、传感器数据 |
| 数字钥匙 | Car Connectivity Consortium（CCC）Digital Key 3.0 |

```
蓝牙座舱应用

  手机配对（HFP + A2DP + PBAP）
  └── 免提通话 + 蓝牙音乐 + 通讯录同步

  数字车钥匙（BLE + UWB）
  ├── 精确测距：UWB <10cm精度，感知手机位置
  ├── 解锁：手机靠近自动解锁（无需掏出手机）
  └── 分享：数字钥匙授权给家人（临时/永久）

  BLE IoT
  └── 胎压传感器（TPMS）、健康监测设备接入
```

### 4.3.3 GNSS（全球卫星导航系统）

| 参数 | 规格 |
|------|------|
| 支持系统 | GPS（L1/L2） + 北斗（B1/B2）+ GLONASS + Galileo |
| 定位精度（单点） | < 2.5m（CEP50，开阔天空） |
| 精度（RTK辅助） | < 10cm（需要差分修正数据） |
| 首次定位时间（TTFF） | 冷启动 < 30s，热启动 < 5s |
| 重捕获时间 | < 1s（隧道出口） |
| 海拔/速度精度 | 海拔 < 5m，速度 < 0.1 m/s |

```
车载GNSS增强技术

  DR（Dead Reckoning，航位推测）
  ├── 输入：轮速传感器 + IMU（加速度/陀螺仪）
  └── 作用：隧道、地库等无卫星信号时继续定位

  V2X定位融合
  └── 结合HD Map（高精地图）和V2X信号提升精度

  RTK辅助
  └── T-BOX接收网络RTK修正，厘米级精度
```

### 4.3.4 蜂窝通信（5G/LTE-V）

座舱SoC通常通过**外挂基带芯片（Modem）**实现5G通信，或集成LTE基带（部分方案）：

```
5G/LTE连接架构

  座舱SoC
      │ PCIe / USB3.0
      ▼
  5G Modem（独立芯片，如高通SDX65/SDX75）
      │ RF前端
      ▼
  5G天线（车顶鲨鱼鳍天线）

5G座舱应用：
  ├── T-BOX车联网（TSP服务）
  ├── OTA整车/座舱软件远程升级
  ├── 高清地图实时下载/更新
  ├── 车载热点（Hotspot，5路以上设备接入）
  ├── 远程诊断（RDE）
  └── V2X（C-V2X，Uu接口，RSU通信）

5G关键指标：
  ├── 下行峰值：> 1 Gbps（Sub-6GHz，N78频段）
  ├── 上行峰值：> 100 Mbps
  ├── 延迟：< 10ms（eMBB），< 1ms（URLLC理论）
  └── 连接密度：> 10⁶ 设备/km²（mMTC）
```

### 4.3.5 V2X（Vehicle-to-Everything）通信

```
V2X通信类型

  V2V（Vehicle-to-Vehicle）：车车通信
  └── 前车紧急刹车预警、盲区提醒

  V2I（Vehicle-to-Infrastructure）：车路通信
  ├── 红绿灯信息（SPAT信号）
  ├── 路况/施工预警
  └── ETC电子收费

  V2P（Vehicle-to-Pedestrian）：车行人通信
  └── 行人闯红灯预警

  V2N（Vehicle-to-Network）：车网通信
  └── 云端TSP服务、高精地图更新

技术标准：
  ├── DSRC（802.11p / WAVE）：美国/欧洲
  └── C-V2X（LTE-V2X / NR-V2X）：中国主流
```

## 4.4 网络安全要求

⚠️ 通信子系统需满足**UN R155**（车辆网络安全法规）和**ISO/SAE 21434**：

```
通信安全措施

  外部接口防护
  ├── 5G/Wi-Fi/BT：防火墙 + TLS 1.3加密
  ├── OTA升级：数字签名验证（X.509证书链）
  └── 诊断接口（OBD）：认证授权，防未经授权访问

  内部总线防护
  ├── CAN-FD：SecOC（AUTOSAR消息认证码MAC）
  ├── 以太网：MACsec（802.1AE）点对点加密
  └── LIN：访问控制（低风险，监控异常报文）

  入侵检测
  └── IDS/IPS（In-Vehicle Intrusion Detection System）
      ├── 异常流量检测
      ├── 非法命令过滤
      └── 安全事件上报（云端VSOC）
```

## 小结

本章介绍了座舱SoC通信与网络子系统的完整体系：
- **车内总线**：CAN-FD（控制）、以太网（高速主干）、LIN（低速辅助）、USB（用户设备）
- **无线通信**：Wi-Fi 6E（高速）、蓝牙5.3（短距）、GNSS（定位）、5G（广域）
- **V2X**：C-V2X车路协同，支持V2V/V2I/V2P/V2N
- **网络安全**：UN R155合规，全链路加密与认证
