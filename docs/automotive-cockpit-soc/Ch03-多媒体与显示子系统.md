# 第3章 多媒体与显示子系统

## 3.1 子系统总览

多媒体与显示子系统（Multimedia & Display Subsystem）是座舱SoC与用户交互最密集的部分，涵盖视频采集、图像处理、视频编解码、显示驱动及音频输出等功能模块。

```
多媒体与显示子系统架构

  输入侧                处理层                 输出侧
  ─────────            ─────────────           ─────────
  摄像头（MIPI CSI）──►ISP（图像信号处理）      ─►显示控制器──►LCD/OLED
  视频流（USB/以太网）──►VPU（视频解码器）       ─►DSI/LVDS/eDP
  麦克风（PDM/I2S）  ──►音频DSP               ─►I2S→功放→扬声器
  录像文件（UFS）    ──►JPU（JPEG/HEIF解码）   ─►HDMI/DP（扩展屏）
```

## 3.2 图像信号处理器（ISP）

### 3.2.1 ISP处理流水线

**ISP**（Image Signal Processor）将摄像头传感器的原始RAW数据转换为人眼友好的RGB或YUV图像：

```
ISP处理流水线（Pipeline）

  RAW输入（Bayer格式）
      │
      ▼
  ┌─────────────────────────────────────────────────┐
  │  黑电平校正（Black Level Correction, BLC）        │
  │  ↓                                              │
  │  镜头阴影校正（Lens Shading Correction, LSC）     │
  │  ↓                                              │
  │  坏点修正（Defective Pixel Correction, DPC）      │
  │  ↓                                              │
  │  降噪（Noise Reduction）：3D-NR / TNR / BNR       │
  │  ↓                                              │
  │  去马赛克（Demosaic / Debayer）：RAW→RGB           │
  │  ↓                                              │
  │  自动白平衡（Auto White Balance, AWB）             │
  │  ↓                                              │
  │  自动曝光（Auto Exposure, AE）控制                 │
  │  ↓                                              │
  │  颜色校正（Color Correction Matrix, CCM）          │
  │  ↓                                              │
  │  色调映射（Tone Mapping）：HDR合并（多帧曝光）      │
  │  ↓                                              │
  │  Gamma校正（Gamma Correction）                    │
  │  ↓                                              │
  │  色彩空间转换（CSC）：RGB→YUV                      │
  │  ↓                                              │
  │  锐化（Sharpening / Edge Enhancement）            │
  └──────────────────────────────┬──────────────────┘
                                 │
                         YUV输出（供VPU/NPU/显示器使用）
```

### 3.2.2 ISP支持的摄像头接口

| 接口类型 | 典型带宽 | 适用场景 |
|---------|---------|---------|
| MIPI CSI-2 (2lane) | 2.5 Gbps | 前向摄像头、DMS |
| MIPI CSI-2 (4lane) | 5 Gbps | 高分辨率前视摄像头 |
| MIPI CSI-3 (CPHY) | 6 Gbps/trio | 高速摄像头 |
| DVP (Parallel) | < 200 Mbps | 老款传感器，兼容 |
| GMSL2（经SerDes） | 6 Gbps | 长距离（线束超过1m） |

### 3.2.3 多路ISP并行处理

高端座舱SoC支持 **6～12路** 摄像头并行处理：

```
多路摄像头部署方案（典型8路配置）

  前视摄像头（高分辨率，200万像素+）────┐
  后视摄像头（泊车，130万像素）─────────┤
  左前侧视摄像头（环视，鱼眼）──────────┤
  右前侧视摄像头（环视，鱼眼）──────────┤──► ISP Multi-Pipeline ──► NPU/显示
  左后侧视摄像头（环视，鱼眼）──────────┤
  右后侧视摄像头（环视，鱼眼）──────────┤
  DMS摄像头（近红外，驾驶员监控）───────┤
  OMS摄像头（乘员监控）────────────────┘
```

## 3.3 视频处理单元（VPU）

### 3.3.1 支持的编解码标准

| 编解码格式 | 编码 | 解码 | 典型用途 |
|-----------|------|------|---------|
| H.264 / AVC | ✓ | ✓ | 行车记录仪录像、视频通话 |
| H.265 / HEVC | ✓ | ✓ | 4K流媒体、蓝光级画质 |
| AV1 | — | ✓ | YouTube 4K，开源免版税 |
| VP9 | — | ✓ | Chrome浏览器视频 |
| MJPEG | ✓ | ✓ | 倒车影像实时预览 |
| JPEG / HEIF | ✓ | ✓ | 照片拍摄与浏览 |

### 3.3.2 VPU性能规格

| 参数 | 规格 |
|------|------|
| 最高解码分辨率 | 8K（7680×4320）@ 30fps 或 4K @ 120fps |
| 同时解码路数 | 8路 1080p @ 30fps |
| 编码最高分辨率 | 4K @ 60fps（H.265） |
| 最低编码码率 | 128 kbps（语音视频通话） |
| 最高编码码率 | 200 Mbps（行车记录仪高品质） |
| 硬件加速 | 独立VPU硬件，CPU占用率 < 5% |

## 3.4 显示控制器（Display Controller）

### 3.4.1 功能模块

显示控制器（DC）负责将GPU渲染输出或视频帧缓冲区的内容通过各类接口输出到屏幕：

```
显示控制器内部模块

  ┌─────────────────────────────────────────────────────┐
  │                    显示控制器                         │
  │                                                     │
  │  帧缓冲区DMA引擎─────────────────────────────────────┤
  │  多图层合成器（Compositor / Overlay Engine）          │
  │  ├── 最多支持8个独立图层                              │
  │  ├── Alpha混合（ARGB8888/RGBA1010102）               │
  │  ├── 旋转/缩放（硬件实现，0°/90°/180°/270°）          │
  │  └── 色度键（Chroma Keying）                         │
  │                                                     │
  │  色彩管理单元（Color Management Unit, CMU）           │
  │  ├── Gamma LUT（1D/3D）                              │
  │  ├── 色域转换（sRGB / P3 / Rec.2020）                │
  │  └── HDR10 / HLG 元数据处理                          │
  │                                                     │
  │  显示接口驱动器                                       │
  │  ├── MIPI DSI（4K OLED中控屏）                       │
  │  ├── LVDS（传统液晶仪表屏）                            │
  │  ├── eDP（数字仪表/HUD投影仪）                         │
  │  └── HDMI 2.1 / DisplayPort 1.4（外接扩展屏）         │
  └─────────────────────────────────────────────────────┘
```

### 3.4.2 多屏驱动方案

典型高端座舱支持 **4～6块屏幕** 同时工作：

```
多屏拓扑示意

  ┌─────────────────────────────────────────┐
  │             座舱SoC                      │
  │  DC0──MIPI DSI0────►仪表盘屏（1920×720） │
  │  DC1──MIPI DSI1────►中控屏（2560×1440） │
  │  DC2──eDP──────────►HUD投影仪（1920×540）│
  │  DC3──MIPI DSI2────►副驾屏（1920×1080） │
  │  DC4──LVDS─────────►后排娱乐屏×2（可选） │
  └─────────────────────────────────────────┘

屏幕时序要求：
  ├── 仪表盘：开机点亮时间 < 2s（冷启动），< 200ms（热唤醒）
  ├── 中控屏：< 4s冷启动
  └── 安全相关显示（倒车影像）：< 2s（法规FMVSS 111要求）
```

### 3.4.3 安全显示路径（Safety Display Path）

⚠️ 仪表盘上的车速、转速、警告灯等安全相关信息需通过 **专用安全显示路径** 传输，不受GPU/非安全操作系统影响：

```
安全显示路径（ASIL-B保证）

  安全岛（ASIL-D MCU）
      │ 安全帧缓冲区（ECC SRAM）
      ▼
  安全显示控制器（独立硬件）
      │ 专用MIPI DSI通道
      ▼
  仪表盘驱动芯片（带BIST自检）
      │
      ▼
  屏幕显示（车速/警告/仪表指针）

  隔离机制：
  ├── 安全显示控制器与普通GPU输出硬件隔离
  ├── 安全帧缓冲区只有安全岛MCU可写
  └── 显示驱动芯片支持像素CRC校验（逐帧）
```

## 3.5 360环视系统（Surround View System）

### 3.5.1 处理流程

```
360环视处理流程

  4路鱼眼摄像头（前/后/左/右）
      │ MIPI CSI
      ▼
  ISP畸变校正（逐路）
      │
      ▼
  GPU / 专用2D加速器
  ├── 鱼眼去畸变（Undistortion）
  ├── 透视变换（Birds-Eye View投影）
  ├── 多路图像拼接（Stitching）
  └── 接缝融合（Seam Blending）
      │
      ▼
  显示输出（中控屏/流媒体后视镜）
  └── 叠加AR泊车辅助线

  关键技术：
  ├── 标定（Calibration）：出厂时摄像头外参标定
  ├── 动态标定：行驶中自动修正
  └── 光照一致性：接缝处亮度统一处理
```

## 3.6 HUD（抬头显示）渲染

### 3.6.1 HUD类型对比

| 类型 | 投影方式 | 显示内容 | 分辨率要求 |
|------|---------|---------|-----------|
| C-HUD（组合型） | 小塑料片 | 车速、导航箭头 | 640×240 |
| W-HUD（挡风玻璃型） | 挡风玻璃 | 车速、ADAS提示 | 1920×540 |
| AR-HUD（增强现实型） | 挡风玻璃大面积 | 导航箭头叠加路面、危险目标框选 | 2560×1440 |

### 3.6.2 AR-HUD渲染要求

```
AR-HUD渲染挑战

  感知延迟要求
  └── 从摄像头采集到AR叠加显示 ≤ 25ms（否则视觉漂移）

  失真校正
  └── 挡风玻璃曲率校正（非平面投影变换）

  亮度适应
  └── 白天亮度 ≥ 15,000 nit（阳光直射）

  内容类型
  ├── 导航：下一个转弯箭头贴合道路显示
  ├── ADAS：前车距离、车道偏离警告
  └── 限速：实时识别并叠加道路限速标志
```

## 小结

本章覆盖了座舱SoC多媒体与显示子系统的完整设计：
- **ISP**：RAW→YUV完整图像处理流水线，支持多路并行
- **VPU**：4K/8K硬件编解码，支持H.265/AV1
- **显示控制器**：4～6屏同驱，安全显示路径隔离
- **360环视**：鱼眼去畸变+拼接，AR泊车辅助
- **AR-HUD**：低延迟渲染，挡风玻璃AR叠加
