## 12.2 PCB 层叠设计

### 12.2.1 典型层叠结构（10层板）

```
10层 PCB 层叠参考（座舱域控主板）

  Layer  1：信号层（SIG1）  —— 关键高速信号（优先层）
  Layer  2：地平面（GND）   —— 完整地（L1参考平面）
  Layer  3：信号层（SIG2）  —— 次要高速信号 / 差分对
  Layer  4：电源层（PWR1）  —— VDD_CORE / VDD_MEM
  Layer  5：信号层（SIG3）  —— 内层差分（LPDDR走线区）
  Layer  6：地平面（GND2）  —— 完整地（L5/L7参考平面）
  Layer  7：信号层（SIG4）  —— 内层差分（PCIe/USB）
  Layer  8：电源层（PWR2）  —— VDD_IO / VDDQ
  Layer  9：地平面（GND3）  —— 完整地（L10参考平面）
  Layer 10：信号层（SIG5）  —— 低速信号（GPIO/SPI/I2C）

核心设计原则：
  ├── 高速差分线走内层（L3/L5/L7），屏蔽辐射
  ├── 电源层紧邻地层（L4-L5之间层间距 < 0.1mm，增大电容）
  ├── 顶/底层放连接器焊盘与BGA扇出过孔
  └── 总厚度典型值：1.6mm / 2.0mm（含阻焊层）

12层板（高密度方案）：
  增加 L3-L4 GND + SIG 对，用于 LPDDR5 信号完全内层化
  适用于 LPDDR5 速率 ≥ 6400 Mbps 场景
```

### 12.2.2 阻抗控制

```
特征阻抗控制目标（座舱SoC典型）

  单端信号：
  ├── 通用IO（GPIO/SPI）：50Ω ± 10%
  ├── USB 2.0 单端信号：  45Ω ± 10%
  └── RF 信号（GNSS/RF）：50Ω ± 5%

  差分信号：
  ├── LPDDR5 差分：    100Ω ± 10%（内层带状线）
  ├── PCIe Gen4/5：    85Ω ± 10%（内层带状线）
  ├── USB 3.2 / USB4： 90Ω ± 10%
  ├── Automotive ETH： 100Ω ± 10%（1000BASE-T1差分）
  ├── MIPI CSI-2/DSI：  100Ω ± 10%（外层微带线）
  └── LVDS：           100Ω ± 10%

阻抗计算关键参数：
  介质材料 FR4：Er = 3.8~4.5（高频需选低损耗材料 M6 / Megtron 6）
  走线宽度、间距、介质厚度 → 由 SI 工具（HyperLynx/Polar）计算
  阻抗测量：TDR（时域反射计）抽样验证，允差 ±5~10%
```

## 12.3 高速信号完整性设计

### 12.3.1 LPDDR5 布线规则

```
LPDDR5 PCB 布线设计规则（速率 6400 Mbps）

  一、BGA 扇出（Fanout）：
  ├── 推荐 HDI（高密度互联）工艺，0.5mm Pitch BGA
  ├── 过孔类型：微盲孔（Micro-via）Φ0.1mm
  └── BGA区域下方禁止切割地平面（完整参考平面）

  二、等长匹配（Length Matching）：
  ├── 同组（Byte Lane）内数据线等长：±25ps（约±2.5mm）
  ├── 组间（Byte Lane间）等长：±100ps（约±10mm）
  ├── CLK vs DQS 等长：CLK ≤ DQS（CLK超前DQS 0~50ps）
  └── CS/CA 信号等长：同 CLK ±200ps

  三、差分对设计（CLK/DQS）：
  ├── 差分对内间距：≤ 5W（W=线宽）
  ├── 走线弯曲：等长弯折（S型绕线），禁止直角
  └── 差分对不跨分割区（避免参考平面切割）

  四、端接与拓扑：
  ├── 拓扑：点对点（Point-to-Point）或fly-by
  ├── ODT：SoC内建片上终端，无需外部终端电阻
  └── 去耦电容：紧邻VDD/VDDQ引脚（0402 100nF + 0201 10nF）
```

### 12.3.2 PCIe 差分布线

```
PCIe Gen4（16 Gbps/通道）布线规则

  差分对设计：
  ├── 差分阻抗：85Ω ± 10%（内层带状线）
  ├── 对内等长：±10mil（约±0.25mm）
  ├── TX/RX 通道间无须严格等长（协议层均衡）
  └── 最小弯曲半径：≥ 3× 线宽

  参考平面：
  ├── 差分线全程参考完整地平面
  ├── 跨分割处：PCIe信号下方必须有连续地平面桥接
  └── 过孔反焊盘：相邻地过孔（反焊盘孔）减少谐振

  去耦电容（AC耦合）：
  ├── TX端：100nF ±10%（0201封装）
  ├── 放置于距连接器 < 300mil（TX端靠近发送端）
  └── PCIe Gen5 需使用低ESL（< 1nH）电容

  连接器选型：
  ├── M.2 Type-M（存储/5G模组）：PCIe Gen4 x4
  ├── PCIe x1/x4 板卡：TE / Molex PCI Express连接器
  └── 插卡频繁拔插场景需选 高可靠导向结构
```

## 12.4 电源完整性设计

### 12.4.1 PDN 阻抗目标

```
PDN（电源分配网络）阻抗分析

  目标阻抗（Target Impedance）计算：
  Z_target = Vripple / Itransient
  示例：VDD_CORE = 0.8V，允许纹波 = 1% = 8mV，峰值电流 = 40A
  → Z_target = 8mV / 40A = 0.2 mΩ（典型高性能SoC要求）

  PDN 各层贡献（从低频到高频）：
  ┌─────────────────────────────────────────────────────────┐
  │  频率范围    │ 阻抗来源      │ 控制手段                   │
  ├─────────────┼──────────────┼───────────────────────────┤
  │  DC ~ 10kHz │ VRM（电压调整）│ 调节环路带宽优化            │
  │  10k ~1MHz  │ 大容量去耦电容 │ 10μF~100μF MLCC（0402-0603）│
  │  1M~100MHz  │ 中容量去耦电容 │ 100nF~1μF MLCC（0201-0402）│
  │  100M~1GHz  │ 小容量去耦电容 │ 1nF~10nF MLCC（0201）      │
  │  > 1GHz     │ 封装/芯片内电容│ 芯片内 On-die Cap         │
  └─────────────┴──────────────┴───────────────────────────┘

  PDN 仿真工具：
  ├── Ansys SIwave：完整PDN阻抗仿真与优化
  ├── Cadence Clarity：3D全波PDN仿真
  └── HyperLynx PI：快速 PDN 扫描（适合 DDR 优化）
```

### 12.4.2 去耦电容选型与布局

```
去耦电容布局原则

  1. 位置：尽量靠近SoC的VDD引脚（< 1mm）
  2. 过孔：电容焊盘两侧各一个低阻抗接地过孔
  3. 并联策略：
     ├── 多个电容并联降低总 ESL（电感）
     ├── 0201：ESL ≈ 0.3nH；0402：ESL ≈ 0.5nH；0603：ESL ≈ 0.8nH
     └── 推荐混合容值：1μF + 100nF + 10nF（多谐振覆盖）

  MLCC 选型注意事项：
  ├── 介质类型：X7R（±15%/+125°C）用于去耦；C0G（±30ppm）用于精密滤波
  ├── 直流偏置降额：X7R 100nF/10V，在 1V 偏压下实际容值约为额定的 60%
  └── 浪涌电流耐受：选用额定电压 ≥ 2× 工作电压的 MLCC

  大容量储能电容（VRM出口）：
  ├── 固态铝电解或聚合物钽电容：100μF ~ 1mF
  ├── ESR 目标：< 10mΩ
  └── 温度额定：-40°C ~ +125°C（车规级）
```

## 12.5 EMC/EMI 设计

### 12.5.1 辐射控制策略

```
CISPR 25 Class 5 辐射限值合规策略

  主要辐射源识别：
  ├── SoC 内部时钟（DDR时钟/PCIe参考时钟）
  ├── DC-DC 开关电源（PWM纹波 + 谐波）
  ├── 高速差分信号（MIPI/LVDS/USB）共模辐射
  └── 以太网（100/1000BASE-T1）差模转共模辐射

  抑制措施：
  ┌─────────────────────────────────────────────────────────┐
  │  层面        │ 措施                    │ 效果               │
  ├─────────────┼────────────────────────┼───────────────────┤
  │  SoC芯片     │ 扩频时钟（SSC）±0.5%   │ 峰值降低 10~15dB   │
  │  PCB布线     │ 高速走内层 + 地屏蔽     │ 辐射降低 20~30dB   │
  │  连接器      │ 共模扼流圈（100~1000Ω）│ HF 共模抑制 20dB   │
  │  结构设计    │ 铝合金屏蔽腔（6面）     │ 全频段降低 30~50dB │
  │  接口滤波    │ π 型 EMI 滤波器        │ 传导辐射降低 40dB  │
  └─────────────┴────────────────────────┴───────────────────┘

  信号缝合电容（Stitching Capacitor）：
  ├── 跨分割区过孔旁放置 100nF 缝合电容
  └── 间距：< λ/20（最高关注频率对应波长的 1/20）
```

### 12.5.2 电源 EMI 滤波

```
车载 DC-DC 开关电源 EMI 滤波设计

  典型噪声频率：开关频率 × 谐波（1~100MHz）

  共模滤波（CM Filter）：
    VBAT ──┬── L_CM（共模扼流圈 10~100μH）──┬── 到负载
           │                              │
          Cy1（100nF）                   Cy2（100nF）
           │                              │
          GND                            GND
  差模滤波（DM Filter）：
    VBAT ── L_DM（差模电感 1~10μH）── 到负载
               ├── Cx（10μF，X电容）

  π 型 EMI 滤波器结构：
    输入 ──C1──L──C2── 输出（二阶低通，截止频率远低于开关频率）

  磁珠（Ferrite Bead）选型：
  ├── 用于高频噪声（> 10MHz）的隔离
  ├── 阻抗：100Ω @ 100MHz（最常用）
  └── 额定电流 ≥ 实际电流 × 1.5×（防饱和）
```

## 12.6 热设计

### 12.6.1 热阻分析

```
座舱SoC 热阻网络（结温 → 环境）

  T_junction（芯片结温）
       │  θ_jc（结到壳热阻，芯片封装决定）
  T_case（芯片封装上表面）
       │  θ_TIM（导热界面材料热阻）
  T_heatsink（散热器底面）
       │  θ_hs（散热器到腔体热阻）
  T_case_outer（铝合金外壳内壁）
       │  θ_conv（自然对流/强迫对流）
  T_ambient（环境温度，+85°C 车内高温）

热阻典型值（座舱SoC域控）：
  ├── θ_jc（BGA封装）：0.3 ~ 0.5 °C/W
  ├── θ_TIM（相变导热垫，λ=5W/mK）：0.1 ~ 0.3 °C/W
  ├── θ_heatsink（铝合金散热片）：0.5 ~ 2.0 °C/W
  └── θ_conv（无风扇自然对流）：5 ~ 15 °C/W

结温计算示例：
  TDP = 15W，T_ambient = 85°C
  T_junction = 85 + 15 × (0.4+0.2+1.0+8.0) = 85 + 144 = 229°C ❌
  → 必须降低系统热阻或降低环境温度或DVFS限制功耗
  目标：T_junction ≤ 125°C（Grade 2 设计上限）
```

### 12.6.2 TIM 与散热结构

```
导热界面材料（TIM）选型

  类型          │ 导热系数    │ 压缩性  │ 适用场景
  ─────────────┼────────────┼────────┼──────────────────
  导热硅脂      │ 2~10 W/mK  │ 无需   │ 研发验证、小批量
  相变导热垫    │ 3~8 W/mK   │ 0.5mm  │ 量产首选（工艺稳定）
  导热凝胶      │ 4~6 W/mK   │ 自流动  │ BGA腔体不平整场景
  液态金属      │ 70~80 W/mK │ 极薄   │ 高功耗极限散热（需绝缘）
  石墨烯片      │ 10~15 W/mK │ 0.1mm  │ 轻薄设计（手机已量产）

铝合金外壳散热设计：
  ├── 材料：ADC12（压铸铝）或 A6063（挤压铝）
  ├── 表面处理：铝阳极氧化（发射率 ε ≈ 0.9，增强辐射散热）
  ├── 肋片设计：间距 3~5mm，高度 5~15mm（自然对流优化）
  └── 仿真工具：Ansys Icepak / Flotherm（热流体仿真）
```

## 12.7 BOM 管理与车规器件选型

### 12.7.1 车规器件选型原则

```
车规器件选型要求

  温度等级：
  ├── 所有器件均需满足 -40°C ~ +105°C（Grade 2）
  ├── 电源模块/连接器：-40°C ~ +125°C（Grade 1）
  └── 严禁使用商规（0°C ~ +70°C）器件

  认证要求：
  ├── 主动器件（IC）：AEC-Q100 认证
  ├── 被动器件（电阻/电容/电感）：AEC-Q200 认证
  ├── 半导体分立器件：AEC-Q101 认证
  └── 模组级器件：可接受 IATF 16949 供应商 + 车规测试报告

  可靠性要求：
  ├── MTTF（平均无故障时间）：整机 ≥ 15 年（或 15000h@85°C）
  ├── 潮湿敏感等级（MSL）：JEDEC J-STD-020 MSL 1~3
  └── Pb-Free：RoHS 合规（无铅焊接，AEC-Q006认证）
```

### 12.7.2 PPAP 要求

```
PPAP（生产件批准程序，AIAG标准）

  PPAP Level 3（OEM通常要求）文件清单：
  ├── 01 设计记录（图纸/BOM）
  ├── 02 设计变更授权文件（ECR/ECO）
  ├── 03 客户工程批准
  ├── 04 DFMEA（设计失效模式影响分析）
  ├── 05 过程流程图
  ├── 06 PFMEA（过程失效模式影响分析）
  ├── 07 控制计划
  ├── 08 测量系统分析（MSA，Gage R&R）
  ├── 09 初始过程研究（Cpk ≥ 1.67）
  ├── 10 合格实验室记录
  ├── 11 外观批准报告（AAR）
  ├── 12 初始样品（30件）测试报告
  ├── 13 样品
  ├── 14 批量生产保证书
  ├── 15 资格试验记录（如需）
  └── 16 PSW（零件提交保证书）

  关键量产指标：
  ├── Cpk ≥ 1.67（初始样品）→ ≥ 1.33（量产稳定）
  ├── FPY（直通率）：≥ 99.5%
  └── PPM：目标 < 50 PPM（车规一级供应商要求）
```
