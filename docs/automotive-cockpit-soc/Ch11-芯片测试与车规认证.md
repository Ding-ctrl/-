# 第11章 芯片测试与车规认证

## 11.1 车规认证体系概述

### 11.1.1 AEC-Q100 可靠性认证

**AEC-Q100**（Automotive Electronics Council Qualification 100）是车规IC的强制性可靠性认证标准，由奥迪、博世、克莱斯勒等联合制定，涵盖从晶圆到封装器件的全流程测试。

```
AEC-Q100 温度等级划分

  Grade 0：-40°C ~ +150°C（发动机舱）
  Grade 1：-40°C ~ +125°C（底盘/传动区域）
  Grade 2：-40°C ~ +105°C（一般乘客舱）
  Grade 3：-40°C ~  +85°C（乘客舱受保护区）
  Grade 4：  0°C ~  +70°C（驾驶室内部）

  座舱SoC典型选用：Grade 2（-40°C ~ +105°C）
  安全岛MCU：     Grade 1（-40°C ~ +125°C）

AEC-Q100 测试项目群（Stress Test Qualification Flow）
  ├── 加速温度寿命（HTOL）：125°C × 1000h，同时施加最大工作电压
  ├── 早期失效率（ELFR）：推算出货物料的早期失效率（FIT）
  ├── 高温储存（HTSL）：150°C × 1000h，无偏置
  ├── 温度循环（TC）：-65°C ↔ +150°C，1000次循环
  ├── 湿热偏置（THB）：85°C/85%RH × 1000h
  ├── 高压蒸汽老化（HAST/uHAST）：130°C/85%RH/96h（无偏置196h）
  ├── 封装完整性（Physical Dimension / Bond Pull / Die Shear）
  └── ESD/Latch-up（人体模型 HBM、充电器件模型 CDM、IEC 61000-4-2）
```

### 11.1.2 ISO 26262 Part 11 半导体应用

ISO 26262 Part 11 专门针对半导体器件（SoC/MCU等），定义了硬件安全需求的工作流程：

```
ISO 26262 Part 11 核心活动

  ┌──────────────────────────────────────────────────────────┐
  │  Step 1：获取安全需求（HSR）                                │
  │  ├── 客户提供 TSC（技术安全概念）                           │
  │  └── 芯片厂商解析出 HW安全需求（HSR）                       │
  ├──────────────────────────────────────────────────────────┤
  │  Step 2：硬件架构设计与安全分析                              │
  │  ├── FMEA（故障模式影响分析）                               │
  │  ├── FMEDA（+诊断分析，计算DC/SPFM/LFM指标）                │
  │  └── FTA（故障树分析，顶层随机故障率 < 10 FIT @ ASIL-D）      │
  ├──────────────────────────────────────────────────────────┤
  │  Step 3：诊断覆盖率（DC）达标                               │
  │  ├── ASIL-B：SPFM ≥ 90%，LFM ≥ 60%                       │
  │  └── ASIL-D：SPFM ≥ 99%，LFM ≥ 90%                       │
  ├──────────────────────────────────────────────────────────┤
  │  Step 4：输出 Safety Manual + FMEDA Report                 │
  │  └── OEM/Tier1 用于系统级 FMEDA 集成                        │
  └──────────────────────────────────────────────────────────┘

关键安全指标：
  SPFM（Single-Point Fault Metric）= 1 - λSP / λTotal
  LFM（Latent Fault Metric）       = 1 - λLF_undetected / λLF_total
  PMHF（Probabilistic Metric for HW Failures）< 10 FIT（ASIL-D）
```

## 11.2 可测试性设计（DFT）

### 11.2.1 扫描链设计

**扫描链**（Scan Chain）是最核心的数字逻辑测试方法，通过串联触发器形成移位寄存器，在ATE上加载/采集测试向量：

```
扫描链工作模式

  正常工作模式（Functional Mode）：
    D → [FF] → Q  （触发器正常功能）

  测试移位模式（Shift Mode，SE=1）：
    Scan_In → [FF0] → [FF1] → ... → [FFn] → Scan_Out
    （ATE串行加载测试激励）

  测试捕获模式（Capture Mode）：
    施加待测组合逻辑激励 → 时钟边沿捕获响应到FF

扫描链关键设计参数（座舱SoC典型值）：
  ├── 扫描触发器数量：5,000,000 ~ 15,000,000 个
  ├── 扫描链数量：    200 ~ 1000 条（并行减少测试时间）
  ├── 每链FF数量：    3000 ~ 15000 个
  ├── 扫描移位频率：  20~100 MHz（ATE速率限制）
  ├── 测试覆盖率目标：≥ 99%（FCC，Fault Coverage Credit）
  └── 压缩比（ATPG Compression）：50× ~ 200×（EDT/LFSR技术）

ATPG（Automatic Test Pattern Generation）工具：
  Synopsys TetraMAX / Cadence Encounter Test
  支持 Full-Scan、Partial-Scan、XOR Compression
```

### 11.2.2 JTAG / IEEE 1149.x 边界扫描

```
JTAG 接口信号
  TCK  ─ 测试时钟（最高10~30 MHz）
  TMS  ─ 测试模式选择（TAP控制器状态机）
  TDI  ─ 测试数据输入
  TDO  ─ 测试数据输出
  TRST ─ 测试复位（可选）

TAP（Test Access Port）状态机：
  Test-Logic-Reset → Run-Test/Idle
  → Select-DR-Scan → Capture-DR → Shift-DR → Exit1-DR → ...
  → Select-IR-Scan → Capture-IR → Shift-IR → Exit1-IR → ...

边界扫描（Boundary Scan）用途：
  ├── PCB板级互连测试（短路/开路检测）
  ├── Flash编程（BSDL文件驱动JTAG批量烧录）
  ├── 内部寄存器访问（调试/配置）
  └── 多芯片菊花链连接（Daisy Chain）

IJTAG（IEEE 1687）：
  ├── 网络描述语言：ICL（Instrument Connectivity Language）
  ├── 程序描述语言：PDL（Procedural Description Language）
  ├── 支持层次化片上仪器访问（MBIST/热传感器/PLL等）
  └── 相比JTAG，访问效率提升 10× 以上
```

### 11.2.3 BIST 内建自测试

**MBIST（Memory BIST）** 针对片上SRAM/ROM/eDRAM：

```
MBIST 测试算法

  March C- 算法（最常用，覆盖SA/CF/TF/AF故障）：
  ┌────────────────────────────────────────────────────────┐
  │  M0：↑{w0}               写全0                          │
  │  M1：↑{r0,w1}            升序读0写1                     │
  │  M2：↑{r1,w0}            升序读1写0                     │
  │  M3：↓{r0,w1}            降序读0写1                     │
  │  M4：↓{r1,w0}            降序读1写0                     │
  │  M5：↑{r0}               升序读0                        │
  └────────────────────────────────────────────────────────┘

  故障覆盖类型：
  SA0/SA1（固定故障），TF（转换故障），
  CF（耦合故障），AF（地址故障），NPSF（图案敏感故障）

MBIST 控制器结构：
  ├── 地址生成器（Address Generator）
  ├── 数据背景生成器（Data Background Generator）
  ├── 故障注入与检测电路
  └── BIST完成/通过/失败状态寄存器

座舱SoC片上SRAM修复：
  ├── 行冗余（Row Redundancy）：替换坏行
  ├── 列冗余（Column Redundancy）：替换坏列
  └── ECC（Error Correction Code）：1-bit纠错，2-bit检错
```

**LBIST（Logic BIST）** 针对随机逻辑电路：

```
LBIST 原理（基于LFSR伪随机测试）

  LFSR（Linear Feedback Shift Register）生成伪随机测试向量
    → 施加到被测电路（CUT，Circuit Under Test）
    → 响应压缩到 MISR（Multiple Input Signature Register）
    → 比较特征值（Signature）与金标（Golden Signature）

  LBIST 优势：
  ├── 无需ATE向量存储（片上自测试）
  ├── 适用于在线安全测试（ISOOSI / ISO 26262要求）
  └── 支持上电BIST（Power-On BIST）和周期性BIST（Periodic BIST）

  ISO 26262 安全岛LBIST要求：
  ├── 诊断覆盖率（DC）：≥ 60%（ASIL-B）、≥ 90%（ASIL-D）
  └── 测试时间窗口：通常在上电初始化阶段执行，< 200ms
```

Wafer Sort 测试流程

  └─────────────────────────────────────────────────────────────┘

典型CP测试良率（车规SoC）：
  ├── 先进工艺（3~5nm）首流片：50~70%
  └── 量产成熟期：90~97%

### 11.3.2 封装后测试（Final Test / FT测试）

```
Final Test 测试流程

  封装完成 → ATE（Automatic Test Equipment）Handler送料
                │
                ├── 高温测试（HT Site）：125°C
                │   Full MBIST/LBIST + 功能测试 + AC测试
                │
                ├── 常温测试（RT Site）：25°C
                │   AC/DC完整测试 + 接口速度测试
                │
                └── 低温测试（Cold Site，可选）：-40°C
                    关键DC参数 + 时序裕量验证

ATE 设备（座舱SoC典型）：
  ├── Advantest T2000 / V93000：高端SoC测试
  ├── Teradyne UltraFLEX：通用数字/混合信号测试
  └── 测试资源要求：256~512 DUT并行测试通道，GPU图形输出验证通道

车规FT测试特殊要求：
  ├── 100% 高温全功能测试（Grade 2须在 105°C 环境测试）
  ├── Automotive HTOL老化筛选（根据可靠性要求决定）
  └── 唯一芯片序列号（UID）烧录与溯源管理
```

## 11.4 可靠性测试

### 11.4.1 HTOL 高温工作寿命测试

```
HTOL（High Temperature Operating Life）测试

  目的：加速老化筛选，预测芯片寿命（Arrhenius加速模型）
  条件：T_test = 125~150°C，VDD = 最大工作电压+10%
  时长：1000小时（AEC-Q100 Grade 2，77颗样品）

  Arrhenius 加速因子：
    AF = exp[Ea/k × (1/T_use - 1/T_stress)]
    其中 Ea = 0.7eV（典型值），k = 8.617×10⁻⁵ eV/K
    示例：T_stress=125°C，T_use=85°C → AF ≈ 52×
    → 1000h @ 125°C 等效 52000h @ 85°C（约6年）

HTOL 监测项目：
  ├── 功能测试：每168h一次完整功能测试
  ├── 漏电流监测：IDD漂移 < ±20%
  ├── 阈值电压漂移（Vth Shift）：NBTI/PBTI效应
  └── 接口时序余量（Setup/Hold裕量）退化监测

失效标准（AEC-Q100）：
  0 failures in 77 samples → confidence level 90%，FIT < 59
```

### 11.4.2 ESD 与 Latch-up 测试

```
ESD（静电放电）测试模型与限值

  HBM（人体模型，JEDEC JS-001）：
  ├── 等效电路：100pF + 1.5kΩ（模拟人体手触碰芯片）
  ├── 车规 AEC-Q100 要求：Class 1C（≥ ±1000V）
  └── 高端推荐：Class 2（≥ ±2000V）

  CDM（充电器件模型，JEDEC JS-002）：
  ├── 模拟芯片自身带电后对地放电
  ├── 典型耐受：C1 Class（≥ ±250V）
  └── 封装面积越大，CDM耐受能力越低（风险越高）

  IEC 61000-4-2（系统级ESD）：
  ├── 接触放电：±8kV
  ├── 空气放电：±15kV
  └── 外部接口必须配置 TVS 二极管保护

Latch-up 测试（JEDEC JESD78E）：
  ├── 触发条件：过压/过流注入 > 100mA
  ├── 测试温度：85°C（AEC-Q100 要求）
  ├── 判定标准：无触发或触发后通过电源复位可恢复
  └── 防护措施：Guard Ring、N+/P+隔离注入、双阱工艺
```

### 11.4.3 EMC 电磁兼容性测试

```
车规 EMC 测试标准

  辐射发射（RE，Radiated Emission）：
  ├── CISPR 25 Class 5（最严格）：30MHz~1GHz
  ├── 峰值限值：40~52 dBµV/m（频段相关）
  └── 测量距离：1m（CISPR 25）或 3m（可选）

  传导发射（CE，Conducted Emission）：
  ├── CISPR 25 电源线/信号线传导骚扰
  └── 限值：30~60 dBµV（频段相关）

  辐射抗扰度（RI，Radiated Immunity）：
  ├── ISO 11452-2（天线测试法）：1V/m~100V/m
  └── ISO 11452-5（带状线法）：高频段

  传导抗扰度（CI，Conducted Immunity）：
  ├── ISO 7637-2：电源线脉冲（Pulse 1/2a/2b/3a/3b/4/5）
  └── ISO 16750-2：电压范围/跌落/浪涌耐受

座舱域控EMC设计要点：
  ├── PCB 6层及以上（完整地平面）
  ├── 高速信号（MIPI/LVDS/eMMC）控制差分线间距
  ├── 铝合金屏蔽腔体（屏蔽效能 > 40dB @ 1GHz）
  ├── 连接器滤波：磁珠/共模扼流圈/π型滤波器
  └── 电源线：百纳法级滤波电容 + 差模电感
```

## 11.5 FMEDA 故障模式影响与诊断分析

```
FMEDA 分析流程（ISO 26262 Part 5）

  输入：
  ├── 硬件架构图（功能块划分）
  ├── FIT 数据库（IEC 62380 / SN 29500 / MIL-HDBK-217F）
  └── 安全目标（来自 HARA / TSR）

  Step 1：硬件元素分解
    SoC 模块级（CPU核/GPU/NPU/存储控制器/接口...）

  Step 2：故障模式枚举（针对每个硬件元素）
    安全相关故障（S）/ 非安全故障（NS）
    已检测（Detected）/ 未检测（Undetected）

  Step 3：FIT率分配与故障分类
    λSP（单点故障）：无任何诊断机制保护
    λRF（残余故障）：诊断措施存在但覆盖不完全
    λDP（双点感知故障）：需要两个独立故障才能违反安全目标
    λDL（双点潜伏故障）：第一个故障潜伏，等待第二个触发

  Step 4：计算安全指标
  ┌──────────────────────────────────────────────────────────┐
  │  SPFM = 1 - (λSP + λRF) / λS                            │
  │  LFM  = 1 - λDL_undetected / λDL_total                  │
  │  PMHF = Σ(λSP + λRF) + Σ(λDL × Tlifetime/2)            │
  └──────────────────────────────────────────────────────────┘
    ASIL-B：SPFM ≥ 90%，LFM ≥ 60%，PMHF < 100 FIT
    ASIL-D：SPFM ≥ 99%，LFM ≥ 90%，PMHF < 10 FIT

  输出：
  ├── FMEDA 报告（提供给 OEM/Tier1）
  └── Safety Manual（芯片安全使用说明书）
```

## 11.6 测试流程总览

```
座舱SoC 从设计到出货完整测试链

  设计阶段：
  ├── DFT 规划：扫描覆盖率目标、MBIST/LBIST控制器集成
  ├── 形式验证（Formal Verification）：关键控制逻辑无漏洞
  └── 仿真覆盖率：行覆盖率/分支覆盖率/功能覆盖率 ≥ 99%

  晶圆制造阶段：
  ├── 在线参数监控（PCM，Process Control Monitor）
  └── 晶圆级可靠性（WLR）测试：TDDB、HCI、EM、SM

  封装与测试阶段：
  ├── CP（Wafer Sort）：良率筛选，eFuse修复
  ├── FT（Final Test）：三温全功能，速度分选
  └── SLT（System Level Test，可选）：完整系统板级功能验证

  可靠性验证（EVT/DVT阶段）：
  ├── AEC-Q100 全项目认证（HTOL/TC/THB/HAST/ESD/LU）
  ├── FMEDA 完成，Safety Manual 发布
  └── ISO 26262 Part 11 认证报告

  量产出货：
  ├── 出货测试（OST，Outgoing Sort Test）
  ├── 防静电包装（MBB/ESD Bag/Dry Pack）
  └── 全程溯源（Lot/Wafer/Die 坐标→封装序列号→出货批次）
```

> ⚠️ **认证提示**：车规认证周期通常为 12~18 个月，需在 SoC 立项时同步启动 DFT 规划与 FMEDA 工作，避免设计变更返工导致认证延期。
