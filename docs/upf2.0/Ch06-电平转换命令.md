# Ch06 - 电平转换命令

## 概述

当信号在不同电压的电源域之间传递时，需要进行**电平转换 (Level Shifting)**。如果不做转换，可能导致逻辑错误、过高的漏电流，甚至损坏器件。

---

## 6.1 为什么需要电平转换？

### 跨电压域信号问题

```
场景 1: 高电压 → 低电压 (HL)

  PD_CPU (0.9V)        │     PD_GPU (0.75V)
                       │
  VDD_CPU = 0.9V       │     VDD_GPU = 0.75V
                       │
  ┌───┐                │     ┌───┐
  │ FF│── 0.9V 信号 ───┼────→│ FF│ ← 输入电压超过 VDD_GPU！
  └───┘                │     └───┘
                       │
  问题：0.9V 信号驱动 0.75V 域的输入
  → 接收端 PMOS 无法完全关断
  → 增加漏电流
  → 长期可靠性降低（NBTI/HCI 加速）


场景 2: 低电压 → 高电压 (LH)

  PD_GPU (0.75V)        │     PD_CPU (0.9V)
                        │
  VDD_GPU = 0.75V       │     VDD_CPU = 0.9V
                        │
  ┌───┐                 │     ┌───┐
  │ FF│── 0.75V 信号 ───┼────→│ FF│ ← 输入摆幅不足！
  └───┘                 │     └───┘
                        │
  问题：0.75V 信号的高电平可能不满足接收端的 VIH 阈值
  → 逻辑功能可能错误
  → 增加短路电流 (Crowbar Current)
  → 时序裕量减小
```

---

## 6.2 set_level_shifter

### 命令语法

```tcl
set_level_shifter ls_name
    -domain domain_name
    [-elements {element_list}]
    [-applies_to {inputs | outputs | both}]
    [-rule {low_to_high | high_to_low | both}]
    [-threshold value]
    [-no_shift]
    [-force_shift]
    [-location {self | parent | fanout | automatic}]
    [-name_prefix prefix]
    [-name_suffix suffix]
    [-source source_domain]
    [-sink sink_domain]
    [-input_supply_set supply_set]
    [-output_supply_set supply_set]
```

### 参数详解

| 参数 | 含义 | 芯片上的影响 |
|------|------|------------|
| `-domain` | 应用电平转换的域 | 该域边界处插入 LS Cell |
| `-elements` | 指定信号 | 精确控制哪些信号需要 LS |
| `-applies_to` | 方向 | 输入/输出/双向信号 |
| `-rule low_to_high` | 低→高转换 | 插入 LH (Low-to-High) LS Cell |
| `-rule high_to_low` | 高→低转换 | 插入 HL (High-to-Low) LS Cell |
| `-rule both` | 双向转换 | 两个方向都需要 LS |
| `-threshold` | 电压差阈值 | 电压差小于阈值时不插入 LS |
| `-no_shift` | 免除转换 | 指定信号不需要 LS |
| `-force_shift` | 强制转换 | 即使同电压也要插入 LS |
| `-location` | 放置位置 | LS Cell 放在哪个域侧 |

### 对实际芯片的作用

#### 6.2.1 电平转换单元的电路原理

```
Low-to-High Level Shifter (LH-LS):

  输入: 0 ~ 0.75V (低压域)
  输出: 0 ~ 0.9V  (高压域)

                VDD_HIGH (0.9V)
                 │         │
              ┌──┴──┐   ┌──┴──┐
         ┌───┤ P1   │   │ P2  ├───┐
         │    └──┬──┘   └──┬──┘   │
  input ─┤       │  ╲ ╱   │      ├── output (0.9V swing)
  (0.75V)│       │   ╳    │      │
         │    ┌──┴──┐╱ ╲┌──┴──┐   │
         └───┤ N1   │   │ N2  ├───┘
              └──┬──┘   └──┬──┘
                 │         │
                VSS       VSS

  工作原理：
  - 输入为 0.75V (高) → N1 导通 → 拉低左侧 → P2 导通 → 输出 0.9V
  - 输入为 0V (低)    → N2 导通 → 拉低右侧 → P1 导通 → 输出 0V
  - 输出摆幅完全是 0 ~ VDD_HIGH


High-to-Low Level Shifter (HL-LS):

  输入: 0 ~ 0.9V  (高压域)
  输出: 0 ~ 0.75V (低压域)

               VDD_LOW (0.75V)
                 │
              ┌──┴──┐
  input ─────┤ INV  ├──── output (0.75V swing)
  (0.9V)     │      │
              └──┬──┘
                 │
                VSS

  工作原理（简化）：
  - 0.9V 输入驱动以 0.75V 供电的反相器
  - 输出被限制在 0 ~ 0.75V 范围内
  - 实际电路更复杂，需要保护措施
```

#### 6.2.2 Level Shifter 在芯片上的放置

```
PD_CPU (0.9V)    │域边界│    PD_GPU (0.75V)
                 │      │
  ┌───┐          │      │       ┌───┐
  │FF │──signal──┼─[LS]─┼──────→│FF │
  └───┘          │      │       └───┘
                 │      │
  ┌───┐          │      │       ┌───┐
  │FF │──signal──┼─[LS]─┼──────→│FF │
  └───┘          │      │       └───┘
                 │      │

[LS] 的放置选项：

1. location = self (在源域侧)
   - LS Cell 放在 PD_CPU 域内
   - LS 需要双供电：VDD_CPU 和 VDD_GPU
   
2. location = parent (在父域)  
   - LS Cell 放在 PD_TOP (常开域) 内
   - 始终有电，可靠性好
   
3. location = fanout (在目标域侧)
   - LS Cell 放在 PD_GPU 域内
   - LS 需要双供电：VDD_CPU 和 VDD_GPU
```

#### 6.2.3 Level Shifter 对时序的影响

```
无 Level Shifter 的路径：
  FF_src ──→ [combinational] ──→ FF_dst
  延迟：正常组合逻辑延迟

有 Level Shifter 的路径：
  FF_src ──→ [combinational] ──→ [LS] ──→ [combinational] ──→ FF_dst
  延迟：正常延迟 + LS延迟(~0.1-0.5ns) + 额外走线延迟

LS 的典型延迟：
┌──────────────────┬───────────────┬─────────────┐
│ 电压差           │ LS 延迟 (典型) │ 对时序影响    │
├──────────────────┼───────────────┼─────────────┤
│ 0.9V ↔ 0.75V    │ ~0.1-0.2ns    │ 中等         │
│ 1.0V ↔ 0.5V     │ ~0.3-0.5ns    │ 较大         │
│ 1.8V ↔ 0.9V     │ ~0.2-0.4ns    │ 较大         │
└──────────────────┴───────────────┴─────────────┘

→ 跨域路径的时序约束需要考虑 LS 延迟
→ 关键路径应尽量避免跨电压域
```

### 使用示例

```tcl
# 示例 1: CPU → GPU 所有输出信号需要 HL 电平转换
set_level_shifter ls_cpu_to_gpu \
    -domain PD_CPU \
    -applies_to outputs \
    -rule high_to_low \
    -location self

# 示例 2: GPU → CPU 所有输出信号需要 LH 电平转换
set_level_shifter ls_gpu_to_cpu \
    -domain PD_GPU \
    -applies_to outputs \
    -rule low_to_high \
    -location parent

# 示例 3: 双向规则（自动判断方向）
set_level_shifter ls_auto \
    -domain PD_CPU \
    -applies_to both \
    -rule both

# 示例 4: 指定电压差阈值（差值小于 50mV 不插入 LS）
set_level_shifter ls_threshold \
    -domain PD_CPU \
    -applies_to outputs \
    -rule both \
    -threshold 0.05

# 示例 5: 免除特定信号的电平转换
set_level_shifter ls_no_clk \
    -domain PD_CPU \
    -elements {clk_out} \
    -no_shift
```

## 6.3 隔离与电平转换的组合

在实际设计中，跨域信号常常**同时需要隔离和电平转换**：

```
场景：PD_CPU (0.9V, 可关断) → PD_GPU (0.75V, 可关断)

需要处理：
1. PD_CPU 关断时的隔离
2. 0.9V → 0.75V 的电平转换

方案 A: 分别插入 ISO + LS（两个单元）

  PD_CPU ──→ [ISO Cell] ──→ [LS Cell] ──→ PD_GPU
               (0→0.9V)       (0.9V→0.75V)
  
  面积：2 个特殊单元
  延迟：ISO 延迟 + LS 延迟

方案 B: 使用 Combo Cell（一个复合单元）

  PD_CPU ──→ [ISO+LS Combo Cell] ──→ PD_GPU
                (隔离+电平转换)
  
  面积：~1.3 个特殊单元 (节省)
  延迟：比方案 A 短 (路径更短)

→ EDA 工具在综合时会自动选择最优方案
```

```tcl
# UPF 中的描述
set_isolation iso_cpu \
    -domain PD_CPU \
    -clamp_value 0 \
    -applies_to outputs

set_level_shifter ls_cpu \
    -domain PD_CPU \
    -applies_to outputs \
    -rule high_to_low

# EDA 工具会自动合并为 Combo Cell（如果库中有）
```

## 6.4 高级电平转换主题

### 6.4.1 使能控制型电平转换器 (Enable-controlled LS)

在可关断域的场景中，Level Shifter 需要特殊处理：

```
问题：当源域关断时，LS 的输入变为不确定状态

  PD_CPU (OFF)      │     PD_GPU (ON)
  VDD_CPU = 0V      │     VDD_GPU = 0.75V
                    │
  ┌───┐             │     ┌───────┐
  │ FF│── ??? ──────┼────→│  LS   │──→ ???
  └───┘             │     └───────┘
                    │
  → LS 输入为浮空/中间电平
  → LS 输出可能振荡或产生不确定值
  → 需要带使能控制的 LS

解决方案：Enable-controlled Level Shifter

  PD_CPU (OFF)      │     PD_GPU (ON)
                    │
  ┌───┐      ┌──────┼──────────┐
  │ FF│──────┤ ELS   │          │
  └───┘      │ Cell  │  iso_en  │──→ 确定的输出
             │       │  (enable)│
             └──────┼──────────┘
                    │
  iso_en=0 (隔离模式): 输出 = clamp 值（0 或 1）
  iso_en=1 (正常模式): 输出 = 电平转换后的数据
  
  → 同时完成隔离和电平转换功能
  → 等效于 ISO + LS 的 Combo Cell
```

### 6.4.2 特殊信号的电平转换

```
时钟信号的电平转换：

  跨电压域的时钟需要特殊的 LS：
  - 时钟 LS 必须满足严格的占空比要求
  - 时钟 LS 延迟不能引入过大的 skew
  - 通常使用专用的 Clock Level Shifter Cell
  
  ┌──────────────────────────────────────────────┐
  │ 普通 LS:  延迟 ~0.1-0.3ns, 占空比失真 ~2-5% │
  │ 时钟 LS:  延迟 ~0.05-0.1ns, 占空比失真 <1%  │
  └──────────────────────────────────────────────┘

复位信号的电平转换：

  异步复位信号跨电压域时：
  - 必须使用电平转换
  - 可能需要同步器 (Reset Synchronizer)
  - LS 必须在两个域都有电时工作
  
  注意：复位信号通常不需要隔离（复位引脚通常有确定的行为）
```

```tcl
# 时钟信号使用专用 LS（如果工具支持）
set_level_shifter ls_clk \
    -domain PD_GPU \
    -elements {clk_gpu} \
    -applies_to inputs \
    -rule high_to_low

# 复位信号的电平转换
set_level_shifter ls_rst \
    -domain PD_GPU \
    -elements {rst_n_gpu} \
    -applies_to inputs \
    -rule high_to_low
```

### 6.4.3 电平转换的面积优化策略

```
优化策略一：利用 -threshold 减少不必要的 LS

  两个域的电压差很小时（如 0.9V 和 0.85V）：
  → 电平转换可能不必要（在噪声容限内）
  → 使用 -threshold 跳过

  set_level_shifter ls_opt \
      -domain PD_A \
      -applies_to outputs \
      -rule both \
      -threshold 0.1   ← 电压差 < 100mV 时不插入 LS

优化策略二：合并 ISO 和 LS 为 Combo Cell

  两个独立单元 → 一个复合单元
  面积节省 ~20-30%
  延迟降低 ~30-50%
  → EDA 工具会自动优化（如果库中有 Combo Cell）

优化策略三：利用 -no_shift 免除已知安全的信号

  某些信号即使跨电压域也是安全的：
  - 低频控制信号（噪声容限足够）
  - 已经在 IP 内部做了电平转换的信号

  set_level_shifter ls_exempt \
      -domain PD_GPU \
      -elements {slow_ctrl_signal} \
      -no_shift
```

### 6.4.4 多电压域交叉场景

```
当设计中有 3 个或更多电压域时，需要全面规划 LS：

  PD_CPU (0.9V)  ←──→  PD_GPU (0.75V)  ←──→  PD_DDR_IO (1.1V)
       │                    │                       │
       └────── HL ──────────┘                       │
       └────── LH ──────────┘                       │
                             └────── LH ────────────┘
                             └────── HL ────────────┘
       └──────────────── LH ────────────────────────┘
       └──────────────── HL ────────────────────────┘

  电压对              方向           LS 类型
  ────────────────────────────────────────────
  CPU→GPU      0.9V → 0.75V    High-to-Low
  GPU→CPU      0.75V → 0.9V   Low-to-High
  GPU→DDR_IO   0.75V → 1.1V   Low-to-High
  DDR_IO→GPU   1.1V → 0.75V   High-to-Low
  CPU→DDR_IO   0.9V → 1.1V    Low-to-High
  DDR_IO→CPU   1.1V → 0.9V    High-to-Low

  → 每一对跨电压域的信号路径都需要 LS
  → 域越多，LS 需求呈 N×(N-1) 增长
  → 架构阶段就要最小化跨电压域信号
```

## 6.5 本章小结

| 要点 | 说明 |
|------|------|
| `set_level_shifter` | 在跨电压域信号路径上插入电平转换单元 |
| LH / HL / Both | 三种转换方向，根据源域和目标域电压关系选择 |
| 时序影响 | LS 引入 0.1-0.5ns 额外延迟，关键路径需考虑 |
| 放置位置 | 可选源域侧、目标域侧或父域 |
| Combo Cell | 隔离 + 电平转换合一，节省面积和延迟 |
| Threshold | 电压差很小时可跳过 LS，减少面积开销 |
