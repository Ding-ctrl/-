# Ch06 - 电平转换命令

## 概述

当信号在不同电压的电源域之间传递时，需要进行**电平转换 (Level Shifting)**。如果不做转换，可能导致逻辑错误、过高的漏电流，甚至损坏器件。

---

## 6.1 为什么需要电平转换？

### 跨电压域信号问题

```
场景 1: 高电压 → 低电压 (HL)

  PD_CPU (0.9V)        │     PD_GPU (0.75V)
                       │
  VDD_CPU = 0.9V       │     VDD_GPU = 0.75V
                       │
  ┌───┐                │     ┌───┐
  │ FF│── 0.9V 信号 ───┼────→│ FF│ ← 输入电压超过 VDD_GPU！
  └───┘                │     └───┘
                       │
  问题：0.9V 信号驱动 0.75V 域的输入
  → 接收端 PMOS 无法完全关断
  → 增加漏电流
  → 长期可靠性降低（NBTI/HCI 加速）


场景 2: 低电压 → 高电压 (LH)

  PD_GPU (0.75V)        │     PD_CPU (0.9V)
                        │
  VDD_GPU = 0.75V       │     VDD_CPU = 0.9V
                        │
  ┌───┐                 │     ┌───┐
  │ FF│── 0.75V 信号 ───┼────→│ FF│ ← 输入摆幅不足！
  └───┘                 │     └───┘
                        │
  问题：0.75V 信号的高电平可能不满足接收端的 VIH 阈值
  → 逻辑功能可能错误
  → 增加短路电流 (Crowbar Current)
  → 时序裕量减小
```

---

## 6.2 set_level_shifter

### 命令语法

```tcl
set_level_shifter ls_name
    -domain domain_name
    [-elements {element_list}]
    [-applies_to {inputs | outputs | both}]
    [-rule {low_to_high | high_to_low | both}]
    [-threshold value]
    [-no_shift]
    [-force_shift]
    [-location {self | parent | fanout | automatic}]
    [-name_prefix prefix]
    [-name_suffix suffix]
    [-source source_domain]
    [-sink sink_domain]
    [-input_supply_set supply_set]
    [-output_supply_set supply_set]
```

### 参数详解

| 参数 | 含义 | 芯片上的影响 |
|------|------|------------|
| `-domain` | 应用电平转换的域 | 该域边界处插入 LS Cell |
| `-elements` | 指定信号 | 精确控制哪些信号需要 LS |
| `-applies_to` | 方向 | 输入/输出/双向信号 |
| `-rule low_to_high` | 低→高转换 | 插入 LH (Low-to-High) LS Cell |
| `-rule high_to_low` | 高→低转换 | 插入 HL (High-to-Low) LS Cell |
| `-rule both` | 双向转换 | 两个方向都需要 LS |
| `-threshold` | 电压差阈值 | 电压差小于阈值时不插入 LS |
| `-no_shift` | 免除转换 | 指定信号不需要 LS |
| `-force_shift` | 强制转换 | 即使同电压也要插入 LS |
| `-location` | 放置位置 | LS Cell 放在哪个域侧 |

### 对实际芯片的作用

#### 6.2.1 电平转换单元的电路原理

```
Low-to-High Level Shifter (LH-LS):

  输入: 0 ~ 0.75V (低压域)
  输出: 0 ~ 0.9V  (高压域)

                VDD_HIGH (0.9V)
                 │         │
              ┌──┴──┐   ┌──┴──┐
         ┌───┤ P1   │   │ P2  ├───┐
         │    └──┬──┘   └──┬──┘   │
  input ─┤       │  ╲ ╱   │      ├── output (0.9V swing)
  (0.75V)│       │   ╳    │      │
         │    ┌──┴──┐╱ ╲┌──┴──┐   │
         └───┤ N1   │   │ N2  ├───┘
              └──┬──┘   └──┬──┘
                 │         │
                VSS       VSS

  工作原理：
  - 输入为 0.75V (高) → N1 导通 → 拉低左侧 → P2 导通 → 输出 0.9V
  - 输入为 0V (低)    → N2 导通 → 拉低右侧 → P1 导通 → 输出 0V
  - 输出摆幅完全是 0 ~ VDD_HIGH


High-to-Low Level Shifter (HL-LS):

  输入: 0 ~ 0.9V  (高压域)
  输出: 0 ~ 0.75V (低压域)

               VDD_LOW (0.75V)
                 │
              ┌──┴──┐
  input ─────┤ INV  ├──── output (0.75V swing)
  (0.9V)     │      │
              └──┬──┘
                 │
                VSS

  工作原理（简化）：
  - 0.9V 输入驱动以 0.75V 供电的反相器
  - 输出被限制在 0 ~ 0.75V 范围内
  - 实际电路更复杂，需要保护措施
```

#### 6.2.2 Level Shifter 在芯片上的放置

```
PD_CPU (0.9V)    │域边界│    PD_GPU (0.75V)
                 │      │
  ┌───┐          │      │       ┌───┐
  │FF │──signal──┼─[LS]─┼──────→│FF │
  └───┘          │      │       └───┘
                 │      │
  ┌───┐          │      │       ┌───┐
  │FF │──signal──┼─[LS]─┼──────→│FF │
  └───┘          │      │       └───┘
                 │      │

[LS] 的放置选项：

1. location = self (在源域侧)
   - LS Cell 放在 PD_CPU 域内
   - LS 需要双供电：VDD_CPU 和 VDD_GPU
   
2. location = parent (在父域)  
   - LS Cell 放在 PD_TOP (常开域) 内
   - 始终有电，可靠性好
   
3. location = fanout (在目标域侧)
   - LS Cell 放在 PD_GPU 域内
   - LS 需要双供电：VDD_CPU 和 VDD_GPU
```

#### 6.2.3 Level Shifter 对时序的影响

```
无 Level Shifter 的路径：
  FF_src ──→ [combinational] ──→ FF_dst
  延迟：正常组合逻辑延迟

有 Level Shifter 的路径：
  FF_src ──→ [combinational] ──→ [LS] ──→ [combinational] ──→ FF_dst
  延迟：正常延迟 + LS延迟(~0.1-0.5ns) + 额外走线延迟

LS 的典型延迟：
┌──────────────────┬───────────────┬─────────────┐
│ 电压差           │ LS 延迟 (典型) │ 对时序影响    │
├──────────────────┼───────────────┼─────────────┤
│ 0.9V ↔ 0.75V    │ ~0.1-0.2ns    │ 中等         │
│ 1.0V ↔ 0.5V     │ ~0.3-0.5ns    │ 较大         │
│ 1.8V ↔ 0.9V     │ ~0.2-0.4ns    │ 较大         │
└──────────────────┴───────────────┴─────────────┘

→ 跨域路径的时序约束需要考虑 LS 延迟
→ 关键路径应尽量避免跨电压域
```

### 使用示例

```tcl
# 示例 1: CPU → GPU 所有输出信号需要 HL 电平转换
set_level_shifter ls_cpu_to_gpu \
    -domain PD_CPU \
    -applies_to outputs \
    -rule high_to_low \
    -location self

# 示例 2: GPU → CPU 所有输出信号需要 LH 电平转换
set_level_shifter ls_gpu_to_cpu \
    -domain PD_GPU \
    -applies_to outputs \
    -rule low_to_high \
    -location parent

# 示例 3: 双向规则（自动判断方向）
set_level_shifter ls_auto \
    -domain PD_CPU \
    -applies_to both \
    -rule both

# 示例 4: 指定电压差阈值（差值小于 50mV 不插入 LS）
set_level_shifter ls_threshold \
    -domain PD_CPU \
    -applies_to outputs \
    -rule both \
    -threshold 0.05

# 示例 5: 免除特定信号的电平转换
set_level_shifter ls_no_clk \
    -domain PD_CPU \
    -elements {clk_out} \
    -no_shift
```

## 6.3 隔离与电平转换的组合

在实际设计中，跨域信号常常**同时需要隔离和电平转换**：

```
场景：PD_CPU (0.9V, 可关断) → PD_GPU (0.75V, 可关断)

需要处理：
1. PD_CPU 关断时的隔离
2. 0.9V → 0.75V 的电平转换

方案 A: 分别插入 ISO + LS（两个单元）

  PD_CPU ──→ [ISO Cell] ──→ [LS Cell] ──→ PD_GPU
               (0→0.9V)       (0.9V→0.75V)
  
  面积：2 个特殊单元
  延迟：ISO 延迟 + LS 延迟

方案 B: 使用 Combo Cell（一个复合单元）

  PD_CPU ──→ [ISO+LS Combo Cell] ──→ PD_GPU
                (隔离+电平转换)
  
  面积：~1.3 个特殊单元 (节省)
  延迟：比方案 A 短 (路径更短)

→ EDA 工具在综合时会自动选择最优方案
```

```tcl
# UPF 中的描述
set_isolation iso_cpu \
    -domain PD_CPU \
    -clamp_value 0 \
    -applies_to outputs

set_level_shifter ls_cpu \
    -domain PD_CPU \
    -applies_to outputs \
    -rule high_to_low

# EDA 工具会自动合并为 Combo Cell（如果库中有）
```

## 6.4 本章小结

| 要点 | 说明 |
|------|------|
| `set_level_shifter` | 在跨电压域信号路径上插入电平转换单元 |
| LH / HL / Both | 三种转换方向，根据源域和目标域电压关系选择 |
| 时序影响 | LS 引入 0.1-0.5ns 额外延迟，关键路径需考虑 |
| 放置位置 | 可选源域侧、目标域侧或父域 |
| Combo Cell | 隔离 + 电平转换合一，节省面积和延迟 |
| Threshold | 电压差很小时可跳过 LS，减少面积开销 |
