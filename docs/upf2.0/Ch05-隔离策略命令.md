# Ch05 - 隔离策略命令

## 概述

当一个电源域关断时，该域输出的信号会变成**不确定状态**（浮空或中间电平），这会导致接收端的逻辑错误甚至短路电流。**隔离策略**就是在域边界插入特殊单元，将不确定信号钳位到确定的逻辑值。

---

## 5.1 为什么需要隔离？

### 问题场景

```
PD_CPU (关断)          │     PD_TOP (常开)
                       │
  VDD_CPU = 0V         │     VDD = 0.9V
                       │
  ┌───┐                │     ┌───┐
  │ FF│──── output ────┼────→│ FF│
  └───┘                │     └───┘
       │               │          │
       └─ 不确定电平 ──┘          └─ 接收到不确定值！
          (floating)                   
                                      
问题 1: 接收端 PMOS/NMOS 同时半导通 → 短路电流
问题 2: 下游逻辑产生不可预测的行为
问题 3: 可能触发 latch-up（闩锁效应）
```

### 解决方案：隔离单元

```
PD_CPU (关断)          │     PD_TOP (常开)
                       │
  ┌───┐         ┌──────┼──────┐     ┌───┐
  │ FF│── out ──┤ ISO  │      ├────→│ FF│
  └───┘         │ Cell │      │     └───┘
                │      │      │         │
     VDD_CPU=0V │ iso_en│      │         └─ 确定的 0 或 1
                └──────┼──────┘            (clamp value)
                       │
  ISO Cell 由常开电源供电 (VDD = 0.9V)
  → 即使 PD_CPU 关断，ISO Cell 仍能输出确定值
```

## 5.2 set_isolation

### 命令语法

```tcl
set_isolation isolation_name
    -domain domain_name
    [-elements {element_list}]
    [-isolation_power_net net_name]
    [-isolation_ground_net net_name]
    [-isolation_supply_set supply_set_name]
    [-clamp_value {0 | 1 | latch}]
    [-applies_to {inputs | outputs | both}]
    [-name_prefix prefix]
    [-name_suffix suffix]
    [-source source_domain]
    [-sink sink_domain]
    [-diff_supply_only {TRUE | FALSE}]
    [-no_isolation]
    [-force_isolation]
```

### 参数详解

| 参数 | 含义 | 芯片上的影响 |
|------|------|------------|
| `-domain` | 应用隔离的域 | 在该域边界插入隔离单元 |
| `-elements` | 指定隔离的信号 | 精确控制哪些信号需要隔离 |
| `-isolation_power_net` | 隔离单元的供电 | 必须是常开电源 (Always-On VDD) |
| `-isolation_ground_net` | 隔离单元的接地 | 通常是全局 VSS |
| `-clamp_value 0` | 钳位到逻辑 0 | 关断时输出固定低电平 |
| `-clamp_value 1` | 钳位到逻辑 1 | 关断时输出固定高电平 |
| `-clamp_value latch` | 锁存最后值 | 关断时保持最后一个有效值 |
| `-applies_to outputs` | 应用于输出端口 | 在域的输出信号上插入 ISO |
| `-applies_to inputs` | 应用于输入端口 | 在域的输入信号上插入 ISO |
| `-applies_to both` | 双向应用 | 输入输出都插入 ISO |
| `-diff_supply_only` | 仅跨电压域隔离 | 同电压域不插入 ISO，减少面积 |
| `-no_isolation` | 免除隔离 | 指定信号不需要隔离 |
| `-force_isolation` | 强制隔离 | 即使同电压域也要插入 ISO |

### 对实际芯片的作用

#### 5.2.1 隔离单元的电路结构

```
Clamp-to-0 隔离单元 (AND type):

           VDD (Always-On)
            │
         ┌──┴──┐
  data ──┤      │
         │ AND  ├── output
  iso_en─┤      │
         └──┬──┘
            │
           VSS

功能表：
  iso_en = 1 (正常工作): output = data
  iso_en = 0 (隔离模式): output = 0 (钳位到0)


Clamp-to-1 隔离单元 (OR type):

           VDD (Always-On)
            │
         ┌──┴──┐
  data ──┤      │
         │ OR   ├── output
  iso_en─┤      │
    (inv) └──┬──┘
            │
           VSS

功能表：
  iso_en = 0 (正常工作): output = data
  iso_en = 1 (隔离模式): output = 1 (钳位到1)


Latch 隔离单元:

           VDD (Always-On)
            │
         ┌──┴──────┐
  data ──┤  MUX/   │
         │  Latch  ├── output
  iso_en─┤         │
         └──┬──────┘
            │
           VSS

功能表：
  iso_en = 1 (正常工作): output = data (透明)
  iso_en = 0 (隔离模式): output = last_data (锁存最后值)
```

#### 5.2.2 隔离单元在芯片上的放置

```
                    域边界
  PD_CPU (可关断)      │     PD_TOP (常开)
  VDD_CPU (switchable) │     VDD (always-on)
                       │
  ┌────────────────┐   │   ┌───────────────┐
  │                │   │   │               │
  │  ┌───┐  ┌───┐ │   │   │  ┌───┐  ┌───┐│
  │  │FF │──│Buf│─┼───┼─(ISO)─│Buf│──│FF ││
  │  └───┘  └───┘ │   │   │  └───┘  └───┘│
  │                │   │   │               │
  │  ┌───┐  ┌───┐ │   │   │  ┌───┐  ┌───┐│
  │  │FF │──│Buf│─┼───┼─(ISO)─│Buf│──│FF ││
  │  └───┘  └───┘ │   │   │  └───┘  └───┘│
  │                │   │   │               │
  └────────────────┘   │   └───────────────┘

  (ISO) = 隔离单元
  - 物理上放置在 PD_TOP 域内（靠近边界）
  - 由 VDD (always-on) 供电
  - iso_en 信号来自 PMU（常开逻辑）
```

**放置位置的选择：**

| 放置位置 | 优点 | 缺点 |
|----------|------|------|
| 在接收域 (sink) 侧 | ISO 单元有电，可靠钳位 | 接收域布局面积需考虑 ISO |
| 在发送域 (source) 侧 | 离输出端近，走线短 | 域关断后 ISO 本身无电 |
| **推荐：接收域侧** | ✅ 常开供电，可靠性最佳 | - |

### 使用示例

```tcl
# 示例 1: CPU 域输出信号钳位到 0
# 芯片影响：在 PD_CPU 所有输出端口处插入 AND 型 ISO Cell
set_isolation iso_cpu_out \
    -domain PD_CPU \
    -isolation_power_net VDD \
    -isolation_ground_net VSS \
    -clamp_value 0 \
    -applies_to outputs

# 示例 2: 特定信号钳位到 1（如 ready 信号需要高电平表示忙）
set_isolation iso_cpu_ready \
    -domain PD_CPU \
    -elements {u_cpu/ready_out} \
    -isolation_power_net VDD \
    -isolation_ground_net VSS \
    -clamp_value 1 \
    -applies_to outputs

# 示例 3: 总线信号锁存最后值（避免协议违规）
set_isolation iso_cpu_bus \
    -domain PD_CPU \
    -elements {u_cpu/axi_*} \
    -isolation_power_net VDD \
    -isolation_ground_net VSS \
    -clamp_value latch \
    -applies_to outputs

# 示例 4: 免除隔离（已知安全的信号）
set_isolation iso_cpu_no \
    -domain PD_CPU \
    -elements {u_cpu/clk u_cpu/rst_n} \
    -no_isolation
```

## 5.3 use_interface_cell (UPF 2.0 增强)

### 命令语法

```tcl
use_interface_cell cell_name
    -domain domain_name
    -lib_cells {lib_cell_list}
    [-strategy strategy_name]
    [-port_map {upf_port lib_pin}] ...
```

### 命令定义

指定在域边界使用的具体库单元类型，可以是**组合了隔离和电平转换功能的复合单元**。

### 对实际芯片的作用

在先进工艺中，EDA 工具提供了**组合单元 (Combo Cell)**，将隔离和电平转换合并在一个物理单元中：

```
单独的 ISO + LS：           Combo Cell (ISO + LS)：
                            
  ┌─────┐   ┌─────┐         ┌──────────────┐
  │ ISO │───│ LS  │         │  ISO + LS    │
  │ Cell│   │ Cell│         │  Combo Cell  │
  └─────┘   └─────┘         └──────────────┘
  面积: 2 个单元              面积: ~1.5 个单元 ← 节省面积
  延迟: ISO + LS              延迟: 更短 ← 更好的时序
```

## 5.4 隔离策略的设计考量

### 5.4.1 Clamp Value 的选择

```tcl
# 选择 clamp_value 需要考虑下游逻辑的功能需求：

# 1. 总线信号 → 通常 clamp 到 0
#    原因：0 表示无有效传输，总线仲裁器可正确处理
set_isolation iso_bus -domain PD_CPU -clamp_value 0

# 2. 握手信号 ready → 可能 clamp 到 0 (表示"未就绪")
set_isolation iso_ready -domain PD_CPU \
    -elements {ready_out} -clamp_value 0

# 3. 中断信号 → 通常 clamp 到 0 (避免虚假中断)
set_isolation iso_irq -domain PD_CPU \
    -elements {irq_out} -clamp_value 0

# 4. 某些协议信号 → latch (保持协议状态一致性)
set_isolation iso_proto -domain PD_CPU \
    -elements {valid_out grant_out} -clamp_value latch
```

### 5.4.2 隔离使能信号时序

```
关键时序要求：

1. 下电时：先开启隔离，再关断电源
   
   iso_en  ─────────┐                    ─────
                     └────────────────────
   
   power_en────────────────────┐          ─────
                               └──────────
   
                     ↑                    ↑
                  先隔离              后断电
   
2. 上电时：先开启电源，再关闭隔离

   power_en─────────┐                    ─────
                     └────────────────────
                     
   power_ack────────────────────┐         ─────
                                └─────────
                                
   iso_en  ─────────────────────────┐     ─────
                                    └─────
                                    ↑
                              电源稳定后
                              才关闭隔离
```

## 5.5 高级隔离主题

### 5.5.1 总线协议感知的隔离设计

不同总线协议对隔离值有不同要求：

```
AXI 协议隔离策略：

  信号           建议 clamp_value    原因
  ─────────────────────────────────────────────
  AWVALID        0                  无效写地址
  WVALID         0                  无效写数据
  BREADY         0                  不接收响应
  ARVALID        0                  无效读地址
  RREADY         0                  不接收读数据
  
  AXI 总线 —— 所有 VALID 信号 clamp 到 0
  → 表示无有效传输
  → 总线仲裁器可正确处理
  → 不会产生虚假交易

AHB 协议隔离策略：

  信号           建议 clamp_value    原因
  ─────────────────────────────────────────────
  HTRANS[1:0]    00 (IDLE)          空闲传输
  HBUSREQ        0                  不请求总线
  HLOCK          0                  不锁定总线
  
APB 协议隔离策略：

  信号           建议 clamp_value    原因
  ─────────────────────────────────────────────
  PSEL           0                  不选中从设备
  PENABLE        0                  不使能传输
  PWRITE         0                  无写操作
```

### 5.5.2 多位信号的隔离优化

```
对于多位总线信号，可以优化隔离单元的使用：

方式一：逐位隔离（默认）
  data_out[31:0] → 32 个独立的 ISO Cell
  面积: 32 × ISO_Cell_Area
  
方式二：使能隔离（面积优化）
  ┌────────────────────────┐
  │ data_out[31:0]         │
  │      │                 │
  │   ┌──┴──┐              │
  │   │ AND │──→ [AND] ──→ │ data_iso[31:0]
  │   │ gate│   每位与     │
  │   └──┬──┘   iso_en     │
  │      │      进行 AND   │
  │   iso_en               │
  └────────────────────────┘
  
  如果 clamp_value 全为 0，可以用使能门控替代
  → 一个使能信号控制整个总线
  → 面积可能更优

方式三：分组隔离
  高位 data_out[31:16] → clamp 0（不关键）
  低位 data_out[15:0]  → latch（需保持状态）
```

```tcl
# UPF 中的分组隔离示例
set_isolation iso_data_high \
    -domain PD_CPU \
    -elements {u_cpu/data_out[31:16]} \
    -clamp_value 0 \
    -applies_to outputs

set_isolation iso_data_low \
    -domain PD_CPU \
    -elements {u_cpu/data_out[15:0]} \
    -clamp_value latch \
    -applies_to outputs
```

### 5.5.3 隔离验证 Checklist

```
隔离设计完成后的验证检查项：

□ 1. 覆盖率检查
     ✓ 所有跨域输出信号都有隔离策略
     ✓ 没有遗漏的跨域信号（特别是 inout 端口）
     ✓ 隐式跨域信号（如通过 SRAM 共享的信号）

□ 2. 功能正确性
     ✓ clamp_value 对下游逻辑无副作用
     ✓ 总线协议不会因 clamp 值而违规
     ✓ 中断信号不会产生虚假触发
     ✓ 握手信号的隔离值不会导致死锁

□ 3. 时序正确性
     ✓ iso_enable 在断电前有效（满足 setup time）
     ✓ iso_enable 在上电后才释放（满足 hold time）
     ✓ iso_enable 由常开域逻辑生成

□ 4. 供电正确性
     ✓ ISO Cell 连接到常开电源
     ✓ ISO Cell 在关断期间有电
     ✓ ISO Cell 的驱动能力足够

□ 5. 仿真验证
     ✓ Power-Aware 仿真中无 X 传播到常开域
     ✓ 关断域输出在断电后被正确钳位
     ✓ 上电恢复后隔离正确释放
```

## 5.6 本章小结

| 要点 | 说明 |
|------|------|
| `set_isolation` | 在域边界插入钳位单元 → 防止关断域输出不确定信号 |
| clamp_value | 0/1/latch → 决定隔离时的输出值，需根据功能选择 |
| ISO Cell 供电 | 必须由常开电源供电 → 保证关断时仍能正常工作 |
| 放置位置 | 推荐在接收域侧 → 可靠性最佳 |
| 使能时序 | 下电先隔离再断电，上电先通电再解除隔离 |
