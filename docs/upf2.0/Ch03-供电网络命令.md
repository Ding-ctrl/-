# Ch03 - 供电网络命令

## 概述

供电网络命令描述了**电源从芯片引脚到各个电源域的分配路径**。这些命令直接决定了芯片上电源网格 (Power Grid) 的拓扑结构。

---

## 3.1 create_supply_port

### 命令语法

```tcl
create_supply_port port_name
    [-domain domain_name]
    [-direction {in | out}]
```

### 命令定义

定义一个电源/地的端口，是电源进入或离开某个层次的入口/出口。

### 参数详解

| 参数 | 含义 | 芯片上的影响 |
|------|------|------------|
| `port_name` | 端口名称 | 对应芯片封装引脚或模块接口 |
| `-domain` | 所属电源域 | 确定端口属于哪个电压岛 |
| `-direction in` | 输入端口 | 电源从外部流入（PAD → 内部） |
| `-direction out` | 输出端口 | 电源从内部输出（开关输出） |

### 对实际芯片的作用

```
封装（Package）                       芯片（Die）
┌─────────────────┐           ┌─────────────────────────┐
│                 │           │                         │
│   VDD Pin ──────┼── Bump ──┼──→ create_supply_port VDD│
│                 │           │       (direction: in)    │
│   VSS Pin ──────┼── Bump ──┼──→ create_supply_port VSS│
│                 │           │       (direction: in)    │
│                 │           │                         │
└─────────────────┘           └─────────────────────────┘
```

**在顶层**：`create_supply_port` 对应芯片的**电源 PAD / Bump**，是外部电源进入芯片的物理入口。

**在子模块层次**：对应模块的**电源接口引脚**，是电源在层次间传递的逻辑接口。

### 使用示例

```tcl
# 顶层电源端口 → 对应芯片 VDD/VSS PAD
create_supply_port VDD  -domain PD_TOP -direction in
create_supply_port VSS  -domain PD_TOP -direction in
create_supply_port VDDQ -domain PD_TOP -direction in  # DDR 专用电源

# 子模块电源端口 → 模块的电源接口
create_supply_port VDD_CPU -domain PD_CPU -direction in
```

## 3.2 create_supply_net

### 命令语法

```tcl
create_supply_net net_name
    [-domain domain_name]
    [-resolve {pg_type | unresolved}]
    [-reuse]
```

### 命令定义

定义一个电源网络，代表芯片上的一条电源/地走线网络。

### 参数详解

| 参数 | 含义 | 芯片上的影响 |
|------|------|------------|
| `net_name` | 网络名称 | 芯片上一组电源金属走线的逻辑名 |
| `-domain` | 所属电源域 | 该网络服务于哪个电压岛 |
| `-resolve pg_type` | 使用 PG type 解析 | 确定网络是 Power 还是 Ground |
| `-reuse` | 复用已有网络 | 在层次化设计中引用已定义的网络 |

### 对实际芯片的作用

每个 `create_supply_net` 最终对应芯片上的一组**电源金属走线**：

```
芯片截面视图（供电网络的物理实现）

        create_supply_net VDD        create_supply_net VDD_CPU
              │                              │
              ▼                              ▼
┌─────────────────────────────────────────────────────────┐
│ M9  ═══════VDD═══════════════════VDD══════════════════  │ ← Power Ring
│ M8  ───────VSS──────────────────VSS───────────────────  │ ← Ground Ring
│ M7  ║  ║  ║  ║  ║  ║  ║  ║  VDD_CPU  ║  ║  ║  ║  ║   │ ← Power Strap
│ M6  ─  ─  ─  ─  ─  ─  ─  ─  VSS  ─  ─  ─  ─  ─  ─   │ ← Ground Strap
│ M5  ║  ║  ║  ║  ║  ║  ║  ║  VDD_CPU  ║  ║  ║  ║  ║   │
│ M4  ─  ─  ─  ─  ─  ─  ─  ─  ─  ─  ─  ─  ─  ─  ─  ─  │
│     ...                                                 │
│ M1  ┬──VDD──┬──VSS──┬──VDD──┬──VSS──┬  ← Std Cell Rail│
│     │       │       │       │       │                   │
│     ▼       ▼       ▼       ▼       ▼                   │
│   [Cell]  [Cell]  [Cell]  [Cell]  [Cell] ← Standard Cell│
└─────────────────────────────────────────────────────────┘
```

**关键理解：**

- `VDD` 网络 → 芯片上从 PAD 到标准单元 VDD Rail 的完整电源供电路径
- `VDD_CPU` 网络 → CPU 域的供电路径，可能经过电源开关
- `VSS` 网络 → 接地路径，通常全局共享
- 每个网络最终都是多层金属的 Power Grid/Mesh 结构

### 使用示例

```tcl
# 全局电源网络 → 芯片上的全局 VDD 网格
create_supply_net VDD -domain PD_TOP

# 全局地线网络 → 芯片上的全局 VSS 网格  
create_supply_net VSS -domain PD_TOP

# CPU 域的可控电源 → 经过 Power Switch 后的 Virtual VDD
create_supply_net VDD_SW_CPU -domain PD_CPU
# 这条网络在物理上连接 Power Switch 输出到 CPU 域内的标准单元

# GPU 域的可控电源
create_supply_net VDD_SW_GPU -domain PD_GPU
```

## 3.3 create_supply_set (UPF 2.0 新增)

### 命令语法

```tcl
create_supply_set supply_set_name
    [-function {function_name supply_net_name}] ...
```

### 命令定义

将一组相关的供电网络（power, ground, nwell, pwell 等）打包成一个**供电集合**，简化供电关系的描述。

### 参数详解

| 参数 | 含义 | 芯片上的影响 |
|------|------|------------|
| `supply_set_name` | 集合名称 | 一组供电网络的逻辑封装 |
| `-function power` | 指定 power 网络 | 集合中的 VDD 来源 |
| `-function ground` | 指定 ground 网络 | 集合中的 VSS 来源 |
| `-function nwell` | 指定 nwell 偏置网络 | 对应 N 阱的偏置电压 |
| `-function pwell` | 指定 pwell 偏置网络 | 对应 P 阱的偏置电压 |

### 对实际芯片的作用

Supply Set 本身不直接映射到芯片上的新结构，而是对**已有供电网络的逻辑分组**，简化描述和提高可复用性。

```
Supply Set 概念示意：

  SS_CPU = {
      power  → VDD_SW_CPU   ← CPU 域的 VDD 网格
      ground → VSS          ← 共享的 VSS 网格
      nwell  → VDD_SW_CPU   ← N 阱偏置（通常同 VDD）
      pwell  → VSS          ← P 阱偏置（通常同 VSS）
  }
```

**芯片上的意义：**

在先进工艺（如 FinFET）中，N 阱和 P 阱的偏置电压可能需要独立控制（用于减少漏电流），Supply Set 提供了描述这种需求的能力。

```
先进工艺中的阱偏置：

  ┌──────── VDD_CPU ──────────┐
  │                           │
  │  ┌─PMOS─┐    ┌─PMOS─┐    │  ← N-well (VNW) 偏置
  │  └───────┘    └───────┘    │
  │                           │
  │  ┌─NMOS─┐    ┌─NMOS─┐    │  ← P-well (VPW) 偏置
  │  └───────┘    └───────┘    │
  │                           │
  └──────── VSS ──────────────┘
  
  Supply Set 可以独立控制 VNW 和 VPW
  → 实现 Forward/Reverse Body Biasing
  → 在芯片上需要额外的偏置电源网络
```

### 使用示例

```tcl
# 定义 CPU 域的供电集合
create_supply_set SS_CPU \
    -function {power VDD_SW_CPU} \
    -function {ground VSS}

# 带阱偏置的供电集合（先进工艺）
create_supply_set SS_CPU_BB \
    -function {power VDD_SW_CPU} \
    -function {ground VSS} \
    -function {nwell VNW_CPU} \
    -function {pwell VPW_CPU}
```

## 3.4 connect_supply_net

### 命令语法

```tcl
connect_supply_net net_name
    [-ports {port_list}]
    [-pins {pin_list}]
    [-cells {cell_list}]
    [-pg_type pg_type_value]
```

### 命令定义

将供电网络连接到端口、引脚或单元，建立电源的拓扑连接关系。

### 参数详解

| 参数 | 含义 | 芯片上的影响 |
|------|------|------------|
| `-ports` | 连接到供电端口 | 建立 PAD → 内部网络的电源连接 |
| `-pins` | 连接到特定引脚 | 将电源直接连到某些单元的电源引脚 |
| `-cells` | 连接到特定单元 | 指定单元的供电来源 |
| `-pg_type` | 按 PG 类型连接 | 批量连接同类型的所有引脚 |

### 对实际芯片的作用

```
connect_supply_net 建立的物理连接：

封装引脚               芯片内部
┌──────┐          ┌──────────────────────────────┐
│ VDD  │──Bump──→│ VDD Port ──→ VDD Net ──→     │
│ Pin  │         │                    ↓         │
└──────┘         │              Power Grid      │
                 │                    ↓         │
                 │              Std Cell VDD Rail│
                 └──────────────────────────────┘
                 
connect_supply_net VDD -ports {VDD}
  → 将外部 VDD 引脚连接到内部 VDD 网络
  → 芯片上：PAD → Bump → Power Ring → Power Grid
```

### 使用示例

```tcl
# 将顶层 VDD 端口连接到 VDD 网络
# 芯片上：VDD PAD 连接到全局电源网格
connect_supply_net VDD -ports {VDD}
connect_supply_net VSS -ports {VSS}

# 将 PG 引脚按类型连接
# 芯片上：所有标准单元的 VDD 引脚连接到 VDD 网络
connect_supply_net VDD -pg_type primary_power
connect_supply_net VSS -pg_type primary_ground
```

## 3.5 set_domain_supply_net

### 命令语法

```tcl
set_domain_supply_net domain_name
    -primary_power_net power_net
    -primary_ground_net ground_net
```

### 命令定义

为指定电源域设置主要的供电网络。这决定了该域内所有标准单元的默认供电来源。

### 对实际芯片的作用

```tcl
set_domain_supply_net PD_CPU \
    -primary_power_net VDD_SW_CPU \
    -primary_ground_net VSS
```

**芯片影响：**

```
PD_CPU 域的供电关系：

                    Power Switch
  VDD (Always On) ═══╡ SW_CPU ╞═══ VDD_SW_CPU ═══╗
                      │  │  │                      ║
                      └──┘──┘                      ║
                                                   ║
                              PD_CPU 域             ║
                    ┌──────────────────────┐       ║
                    │  VDD Rail ═══════════╪═══════╝
                    │    │    │    │    │   │
                    │  ┌─┴┐ ┌─┴┐ ┌─┴┐ ┌─┴┐ │
                    │  │FF│ │FF│ │FF│ │FF│ │  ← 所有 FF 的 VDD
                    │  └──┘ └──┘ └──┘ └──┘ │    连接到 VDD_SW_CPU
                    │  VSS Rail ═══════════╪═══ VSS
                    └──────────────────────┘
```

- PD_CPU 域中所有标准单元的 VDD 引脚都连接到 `VDD_SW_CPU`
- `VDD_SW_CPU` 是 Power Switch 的输出（Virtual VDD）
- 当 Switch 关断时，`VDD_SW_CPU` 被切断，整个域断电

## 3.6 供电网络的完整拓扑示例

```tcl
# ===== 完整的供电网络定义 =====

# 1. 顶层端口（芯片 PAD）
create_supply_port VDD  -direction in -domain PD_TOP
create_supply_port VSS  -direction in -domain PD_TOP
create_supply_port VDDQ -direction in -domain PD_TOP   # DDR I/O 电源

# 2. 全局供电网络
create_supply_net VDD  -domain PD_TOP      # 全局 VDD
create_supply_net VSS  -domain PD_TOP      # 全局 VSS
create_supply_net VDDQ -domain PD_TOP      # DDR I/O VDD

# 3. 可切换供电网络
create_supply_net VDD_SW_CPU -domain PD_CPU  # CPU 域的 Virtual VDD
create_supply_net VDD_SW_GPU -domain PD_GPU  # GPU 域的 Virtual VDD

# 4. 连接端口到网络
connect_supply_net VDD  -ports {VDD}
connect_supply_net VSS  -ports {VSS}
connect_supply_net VDDQ -ports {VDDQ}

# 5. 为各域设置供电
set_domain_supply_net PD_TOP \
    -primary_power_net VDD \
    -primary_ground_net VSS

set_domain_supply_net PD_CPU \
    -primary_power_net VDD_SW_CPU \    # ← 经过 Switch 的电源
    -primary_ground_net VSS

set_domain_supply_net PD_GPU \
    -primary_power_net VDD_SW_GPU \    # ← 经过 Switch 的电源
    -primary_ground_net VSS
```

**对应的芯片物理拓扑：**

```
                    ┌─ VDD PAD ─┐   ┌─ VSS PAD ─┐   ┌─ VDDQ PAD ─┐
                    │           │   │           │   │             │
                    └─────┬─────┘   └─────┬─────┘   └──────┬──────┘
                          │               │                │
                    ══════╪═══════════════╪════════════════╪═══ Power Ring
                          │               │                │
              ┌───────────┼───────────────┼────────────────┼──────────┐
              │           │               │                │          │
              │     ┌─────┴──┐      ┌─────┴──┐       ┌────┴───┐     │
              │     │ VDD Net│      │VSS Net │       │VDDQ Net│     │
              │     └───┬────┘      └────────┘       └────────┘     │
              │         │                                            │
              │    ┌────┴────┐     ┌─────────┐                      │
              │    │PD_TOP   │     │         │                      │
              │    │(PMU,Bus)│     │         │                      │
              │    └─────────┘     │         │                      │
              │         │          │         │                      │
              │   ┌─────┴─────┐   │   ┌─────┴─────┐                │
              │   │ SW_CPU    │   │   │ SW_GPU    │                │
              │   │ (Switch)  │   │   │ (Switch)  │                │
              │   └─────┬─────┘   │   └─────┬─────┘                │
              │         │         │         │                      │
              │   ┌─────┴─────┐   │   ┌─────┴─────┐                │
              │   │PD_CPU     │   │   │PD_GPU     │                │
              │   │VDD_SW_CPU │   │   │VDD_SW_GPU │                │
              │   └───────────┘   │   └───────────┘                │
              │                   │                                 │
              └───────────────────┴─────────────────────────────────┘
```

## 3.7 本章小结

| 命令 | 芯片对应物 | 关键理解 |
|------|-----------|---------|
| `create_supply_port` | 电源 PAD/Bump 或模块电源接口 | 电源的入口/出口 |
| `create_supply_net` | 电源金属走线网络 (Power Grid) | VDD/VSS 的物理走线 |
| `create_supply_set` | 供电网络的逻辑分组 | UPF 2.0 简化描述用 |
| `connect_supply_net` | 电源拓扑连接 | PAD → Grid → Cell 的连接关系 |
| `set_domain_supply_net` | 域与电源的绑定 | 决定域内单元接哪路电源 |
