# Ch04 - 电源开关命令

## 概述

电源开关 (Power Switch) 是低功耗芯片设计中最核心的物理结构之一。它控制着芯片上某个区域的**电源通断**，是实现电源关断 (Power Gating) 技术的关键。

---

## 4.1 create_power_switch

### 命令语法

```tcl
create_power_switch switch_name
    -domain domain_name
    -input_supply_port {port_name supply_net}
    -output_supply_port {port_name supply_net}
    -control_port {port_name [net_name]}
    -on_state {state_name input_port {boolean_expr}}
    [-ack_port {port_name [net_name] [{ack_expr}]}]
    [-ack_delay {ack_port_name delay}]
    [-off_state {state_name {boolean_expr}}]
    [-error_state {state_name {boolean_expr}}]
```

### 命令定义

创建一个电源开关，控制从输入供电网络到输出供电网络的电源通断。

### 参数详解

| 参数 | 含义 | 芯片上的影响 |
|------|------|------------|
| `-domain` | 所属电源域 | 开关物理上放置在哪个域的区域 |
| `-input_supply_port` | 输入电源端口 | 连接到 Always-On VDD (永远有电) |
| `-output_supply_port` | 输出电源端口 | 连接到域内 Virtual VDD (可切断) |
| `-control_port` | 控制信号端口 | 来自 PMU 的开关使能信号 |
| `-on_state` | 导通状态定义 | 开关管导通时的条件 |
| `-ack_port` | 应答信号端口 | 开关管完全导通/关断的反馈信号 |
| `-ack_delay` | 应答延迟 | 开关响应时间（影响电源切换时序） |
| `-off_state` | 关断状态定义 | 开关管关断时的条件 |

### 对实际芯片的作用

#### 4.1.1 MTCMOS 电源开关原理

`create_power_switch` 在芯片上对应 **MTCMOS (Multi-Threshold CMOS) 开关管**：

```
Header Switch (PMOS型)：
                    
  Always-On VDD ═══════════════════════════
                    │        │        │
                  ┌─┴─┐    ┌─┴─┐    ┌─┴─┐
         ctrl ───┤PMOS│───┤PMOS│───┤PMOS│── ctrl
                  └─┬─┘    └─┬─┘    └─┬─┘
                    │        │        │
  Virtual VDD  ═══════════════════════════ → 到域内标准单元
                                              (可被切断)


Footer Switch (NMOS型)：

  Virtual VSS  ═══════════════════════════ → 域内标准单元
                    │        │        │
                  ┌─┴─┐    ┌─┴─┐    ┌─┴─┐
         ctrl ───┤NMOS│───┤NMOS│───┤NMOS│── ctrl
                  └─┬─┘    └─┬─┘    └─┬─┘
                    │        │        │
  Always-On VSS ═══════════════════════════
```

**关键芯片级细节：**

1. **开关管是高阈值 (HVT) 晶体管** → 关断时漏电流极小
2. **通常使用数百到数千个并联的开关管** → 保证足够的导通电流
3. **开关管尺寸影响 IR Drop** → 太小导致压降过大，太大浪费面积
4. **Daisy-chain 控制** → 开关管依次导通，避免浪涌电流 (Inrush Current)

#### 4.1.2 开关管的物理放置

```
芯片布局中的 Power Switch 放置：

方式一：Ring Style（环形放置）
┌─────────────────────────────┐
│ [SW][SW][SW][SW][SW][SW][SW]│
│ [SW]                   [SW] │
│ [SW]    PD_CPU 域      [SW] │
│ [SW]    标准单元区域    [SW] │
│ [SW]                   [SW] │
│ [SW][SW][SW][SW][SW][SW][SW]│
└─────────────────────────────┘

方式二：Column Style（列式放置）
┌─────────────────────────────┐
│ [SW]    [SW]    [SW]    [SW]│
│  ║       ║       ║       ║  │
│  ║ Cells ║ Cells ║ Cells ║  │
│  ║       ║       ║       ║  │
│ [SW]    [SW]    [SW]    [SW]│
│  ║       ║       ║       ║  │
│  ║ Cells ║ Cells ║ Cells ║  │
│  ║       ║       ║       ║  │
│ [SW]    [SW]    [SW]    [SW]│
└─────────────────────────────┘

方式三：Distributed（分布式放置）
┌─────────────────────────────┐
│ Cells [SW] Cells [SW] Cells │
│ Cells Cells [SW] Cells Cells│
│ [SW] Cells Cells Cells [SW] │
│ Cells [SW] Cells [SW] Cells │
│ Cells Cells [SW] Cells Cells│
└─────────────────────────────┘
```

#### 4.1.3 Daisy-chain 导通控制

```
Daisy-chain 控制避免浪涌电流：

PMU                                          ACK
  │                                           ▲
  ▼                                           │
ctrl ──→ [SW_1] ──→ [SW_2] ──→ ... ──→ [SW_N] ──→ ack
          │  ▲      │  ▲               │  ▲
          │  │      │  │               │  │
     VDD ─┘  └─ VVDD  └─ VVDD    VDD ─┘  └─ VVDD

时序：
t0: ctrl = 1 → SW_1 开始导通
t1: SW_1 完全导通 → SW_2 开始导通
t2: SW_2 完全导通 → SW_3 开始导通
...
tN: SW_N 完全导通 → ack = 1 (告知 PMU 域已上电)

→ 通过逐步导通，限制瞬时电流 (di/dt)
→ 避免电源网络上的电压扰动 (Ground Bounce)
```

### 使用示例

```tcl
# 基本电源开关
create_power_switch SW_CPU \
    -domain PD_CPU \
    -input_supply_port  {vin  VDD} \
    -output_supply_port {vout VDD_SW_CPU} \
    -control_port       {ctrl cpu_power_en} \
    -on_state           {on_state vin {ctrl}} \
    -ack_port           {ack cpu_power_ack {on_state}}

# 带多个控制端口的开关（用于分阶段导通）
create_power_switch SW_GPU \
    -domain PD_GPU \
    -input_supply_port  {vin  VDD} \
    -output_supply_port {vout VDD_SW_GPU} \
    -control_port       {ctrl1 gpu_pwr_en1} \
    -control_port       {ctrl2 gpu_pwr_en2} \
    -on_state           {full_on vin {ctrl1 && ctrl2}} \
    -on_state           {partial_on vin {ctrl1 && !ctrl2}} \
    -ack_port           {ack gpu_pwr_ack {full_on}}
```

## 4.2 map_power_switch

### 命令语法

```tcl
map_power_switch switch_name
    -domain domain_name
    -lib_cells {lib_cell_list}
    [-port_map {switch_port lib_cell_pin}] ...
```

### 命令定义

将 UPF 中定义的逻辑开关映射到工艺库中的**物理开关单元**。

### 参数详解

| 参数 | 含义 | 芯片上的影响 |
|------|------|------------|
| `-lib_cells` | 工艺库中的开关单元 | 指定使用哪种物理 Switch Cell |
| `-port_map` | 端口映射 | UPF 端口到库单元引脚的对应关系 |

### 对实际芯片的作用

```tcl
map_power_switch SW_CPU \
    -domain PD_CPU \
    -lib_cells {HEADERSW_X8 HEADERSW_X16} \
    -port_map {{vin  TVDD}   \      # VDD 输入
               {vout TVDDG}  \      # Virtual VDD 输出
               {ctrl SLEEP}  \      # 控制信号（低有效时为 sleep）
               {ack  TAWAKE}}       # 应答信号
```

**芯片影响：**

```
工艺库中的 Switch Cell 示意：

HEADERSW_X8:                    HEADERSW_X16:
┌──────────────┐               ┌──────────────┐
│  TVDD (VDD)  │               │  TVDD (VDD)  │
│       │      │               │       │      │
│    ┌──┴──┐   │               │  ┌──┴──┐┌──┴──┐
│ ───┤8xPMOS│  │               │──┤8xPMOS││8xPMOS│
│SLEEP└──┬──┘  │               │SL└──┬──┘└──┬──┘│
│       │      │               │       │      │
│  TVDDG(VVDD)│               │  TVDDG(VVDD)│
│              │               │              │
│  TAWAKE(ack) │               │  TAWAKE(ack) │
└──────────────┘               └──────────────┘
  驱动能力: 8x                   驱动能力: 16x
  面积: 较小                     面积: 较大
  IR Drop: 较高                  IR Drop: 较低
```

- **HEADERSW_X8**：较小的开关单元，适合域内逻辑面积小的场景
- **HEADERSW_X16**：较大的开关单元，导通电阻更低，IR Drop 更小
- EDA 工具会根据域内负载电流自动选择合适的驱动强度

## 4.3 电源开关的时序影响

### 上电序列 (Power-Up Sequence)

```
时序图：

PMU 信号         ┌─────────────────────────────
cpu_power_en ────┘

                      ┌─────── VDD_SW_CPU 逐渐上升
VDD_SW_CPU   ────────/
(Virtual VDD)   0V   ↑ Rush Current 区间

                           ┌──────────────────
cpu_power_ack ─────────────┘ (VDD_SW_CPU 稳定后)

                              ┌────────────────
restore ──────────────────────┘ (恢复 Retention 数据)

                                 ┌─────────────
clk_enable ──────────────────────┘ (最后才恢复时钟)

时间线：  t0   t1        t2       t3      t4
          │    │         │        │       │
          └─→  Switch    └─→ 电源  └→ 恢复 └→ 恢复
              导通开始       稳定    状态    时钟
```

### 下电序列 (Power-Down Sequence)

```
时序图：

clk_enable  ─────┐
                  └──────────────────────────── (先关时钟)

                  ┌──────────────────────────── 
save ─────────────┘ (保存 Retention 数据)

isolation_en ─────────────┌──────────────────── (开启隔离)
                          │
cpu_power_en ─────────────────────┐
                                  └──────────── (最后才断电)

                                      \_______
VDD_SW_CPU   ─────────────────────────/   0V   (电源逐渐关断)

时间线：  t0      t1       t2       t3     t4
          │       │        │        │      │
          └→ 关闭  └→ 保存  └→ 开启  └→ 关断 └→ 断电
             时钟    状态    隔离    Switch   完成
```

## 4.4 电源开关对芯片性能的影响

### IR Drop 分析

```
电源开关引入额外的 IR Drop：

  VDD (1.0V) ──→ Switch Cell ──→ VDD_SW (0.96V) ──→ Std Cell (0.94V)
                     │                  │
              ΔV₁ = 0.04V (Switch)  ΔV₂ = 0.02V (Grid)
              
  总 IR Drop = ΔV₁ + ΔV₂ = 0.06V (6%)
  
  ← 如果 Switch 驱动强度不够，ΔV₁ 会更大
  ← 影响域内单元的时序性能
  ← 需要在 STA 中考虑 Power Switch IR Drop
```

### 面积开销

| 参数 | 典型值 | 说明 |
|------|--------|------|
| Switch Cell 面积 | 域面积的 5-15% | 取决于域内电流需求 |
| IR Drop 预算 | < 5% VDD | 超过则影响时序 |
| 导通延迟 | 10-100ns | 取决于 Daisy-chain 长度 |
| 漏电流减少 | 90-99% | Power Gating 的核心收益 |

## 4.5 开关设计的高级主题

### 4.5.1 开关管尺寸估算方法

```
开关管总宽度估算公式：

  W_total = I_peak / (K × (VGS - Vth)²)

  其中：
  I_peak = 域内标准单元的峰值电流
  K      = 晶体管跨导参数 (工艺相关)
  VGS    = 栅源电压 (通常 = VDD)
  Vth    = 阈值电压

实际工程中的简化估算：

  开关管面积 ≈ 域内逻辑面积 × 5~15%

  ┌──────────────────────────┬──────────────┬──────────────┐
  │ 域内逻辑面积              │ IR Drop 预算  │ 推荐开关面积  │
  ├──────────────────────────┼──────────────┼──────────────┤
  │ < 0.1 mm²  (小型 IP)     │ < 5%         │ ~10% 逻辑面积│
  │ 0.1-1 mm²  (中型子系统)  │ < 5%         │ ~8% 逻辑面积 │
  │ > 1 mm²    (大型处理器)  │ < 3%         │ ~5% 逻辑面积 │
  └──────────────────────────┴──────────────┴──────────────┘
```

### 4.5.2 Rush Current (浪涌电流) 控制

```
上电时的浪涌电流问题：

  VDD ═══╡ Switch ╞═══ VDD_SW ═══╗
                                  ║
                    ┌─────────────╫─────────────┐
                    │  域内所有电容 ↓              │
                    │  C_total = C_cell + C_wire  │
                    │                             │
                    │  浪涌电流 = C_total × dV/dt │
                    └─────────────────────────────┘

  如果所有开关管同时导通：
  → I_rush = C_total × VDD / t_rise
  → 对于大型域：I_rush 可达数安培
  → 会导致：
     1. 电源网络压降 (全局 IR Drop)
     2. 地线弹跳 (Ground Bounce)
     3. 影响其他域的工作 (Supply Noise)

控制策略：

  策略一：Daisy-chain 逐步导通（最常用）
  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐
  │SW_1 ├─┤SW_2 ├─┤SW_3 ├─┤SW_N │
  └──┬──┘ └──┬──┘ └──┬──┘ └──┬──┘
     ↓       ↓       ↓       ↓
  先导通   后导通   后导通   最后导通
  → 电流分散在较长时间内

  策略二：多阶段导通 (Multi-stage)
  第一阶段：导通 50% 的开关管 → 预充电内部电容
  第二阶段：导通其余 50% → 完成上电
  → 使用多个 control_port 实现

  策略三：限流导通 (Current-limiting)
  使用小尺寸开关管先导通（高阻态）→ 慢速充电
  再用大尺寸开关管导通 → 低阻态正常工作
```

### 4.5.3 Header Switch vs Footer Switch 选择

```
Header Switch (PMOS):
  VDD ──→ [PMOS Switch] ──→ Virtual VDD
  
  优点：
  ✅ PMOS 导通电阻对温度不敏感（较稳定）
  ✅ 不影响地线网络（VSS 保持干净）
  ✅ 大多数标准单元库支持
  
  缺点：
  ❌ PMOS 驱动能力弱于 NMOS（面积较大）
  ❌ 需要更多的开关管面积

Footer Switch (NMOS):
  Virtual VSS ──→ [NMOS Switch] ──→ VSS
  
  优点：
  ✅ NMOS 驱动能力强（面积较小）
  ✅ 开关管面积可以更小
  
  缺点：
  ❌ 地线弹跳影响信号完整性
  ❌ 影响域内信号的参考电平
  ❌ 较少标准单元库直接支持

  业界主流选择：Header Switch (PMOS)
  原因：地线完整性对信号质量至关重要
```

### 4.5.4 多域共享开关的考量

```tcl
# 场景：多个小域共享一组 Power Switch

# 方案一：每个域独立开关（推荐）
create_power_switch SW_CORE0 -domain PD_CORE0 \
    -input_supply_port {vin VDD} \
    -output_supply_port {vout VDD_SW_CORE0} ...

create_power_switch SW_CORE1 -domain PD_CORE1 \
    -input_supply_port {vin VDD} \
    -output_supply_port {vout VDD_SW_CORE1} ...

# 方案二：共享开关（面积优化，但灵活性降低）
# → 需要额外的多路选择逻辑
# → 控制复杂度增加
# → 不推荐，除非面积极其紧张
```

## 4.6 本章小结

| 要点 | 说明 |
|------|------|
| `create_power_switch` | 定义逻辑开关 → 芯片上的 MTCMOS 开关管阵列 |
| `map_power_switch` | 映射到工艺库 → 确定物理开关单元的类型和尺寸 |
| Header vs Footer | PMOS 在 VDD 侧 vs NMOS 在 VSS 侧 |
| Daisy-chain | 逐步导通避免浪涌电流 → 影响上电延迟 |
| IR Drop | 开关管引入额外压降 → 影响域内时序 |
| 面积开销 | 开关管阵列占域面积 5-15% |
